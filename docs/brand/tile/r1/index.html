四個方向加一個合成，同一份高程資料（跟十月的行島同一份），同一套六色。每個方向在白底與深色底各放一次，右邊是標準字並排與 64、32、16 像素的小尺寸。

圖樣全部由程式依文法生成：四向對稱，角隅四塊拼成一朵，白色凸線把釉色隔開。沒有描任何實物。
