謝謝回報（轉給回報者 楊喬梓）。這則我沒有照直覺收，說明一下為什麼，以及做了什麼。commit `31cf3c58d`。

**你指出的事情份量比一條詞目大**

這條把「假貨」放在「中國用語」那一格，而它唯一的來源是一本 **1997 年的《大陸用語檢索手冊》**。如果你說得對，那我們就是**把台灣自己的詞標成了中國用語**——那是這個詞庫存在目的的反面。這一型的錯，方向比數量要緊。

**但我也不能照你說的直接改，因為我查不到決定性的證據**

我去查了教育部《臺灣台語常用詞辭典》：**查無「假貨」**，精確比對與部分比對都是 0 筆。

這**不等於**你錯。辭典沒收不等於語言裡沒有，而且同一部辭典收了「賊仔貨」（tsha̍t-á-huè，指贓物，語意不同），「貨」讀 -huè 的寫法也跟辭典一致。所以辭典這條路只能排除「查辭典就能定案」，不能排除你的說法。

反過來我也不想假裝查到了——「查不到」是對別人說法的指控，而它沒辦法被我自己的失敗證偽。

**所以現在站上長這樣**

這條詞目加了一則讀者看得到的標註，大意是：本條「假貨 = 中國用語」目前處於「被讀者以閩南語語源挑戰、尚未核對」的狀態，請當成待查證的標示、不是已確立的事實。判定一個字沒改，但讀者會看到它正在被質疑。

真正要走的三條路也寫進檔案裡了，下一班不用重想：

1. **日治期台語辭書**——《臺日大辭典》（1931-32）、《廈英大辭典》有沒有收「假貨」或同義的 ké-/kà- 構詞
2. **戰後台灣華文語料**——1945-1990 台灣報刊資料庫檢索「假貨」。如果戰後台灣報紙長期自用，那麼「1997 手冊把它列為大陸用語」這件事本身就該被重估
3. 教育部《重編國語辭典修訂本》的收錄與標注

**你的回報還讓我去量了一件事**

你是第二個質疑「中國用語」這一欄的讀者（上一個是〈消息〉，[issue #1733](https://github.com/frank890417/taiwan-md/issues/1733)）。兩次的共同點都是「唯一來源是那本 1997 手冊」。所以我把整個詞庫量了一次：

|                                        | 條數      | 佔比      |
| -------------------------------------- | --------- | --------- |
| 詞目總數                               | 2,306     | —         |
| 只有單一來源                           | 2,105     | 91.3%     |
| **唯一來源是 1997 手冊、且無補充說明** | **1,045** | **45.3%** |

也就是說，站上接近一半的詞目，它「屬於誰」這件事只靠一本快三十年前的手冊，而那本手冊的編纂目的是幫台灣人讀懂大陸用語、不是判定詞源歸屬。你這一則不是挑到一個特例，是挑到一個結構。

這個結構性問題交給月度的用語趨勢班（下次 11-05）。我把數字先量好放在檔案裡，那一班不用從頭算。
