Gorsachius melanolophus の標準和名は**ズグロミゾゴイ**です。日本語版の記事が全編で使っていた「クロガササギ」は存在しない名前で、**60 か所**ありました。同じ記事に以下の誤りも見つかりましたので、まとめて直しています（commit [`b6213c900`](https://github.com/frank890417/taiwan-md/commit/b6213c900)）。

| 誤                                       | 正                   | 箇所 |
| ---------------------------------------- | -------------------- | ---- |
| クロガササギ                             | ズグロミゾゴイ       | 60   |
| ササギ科                                 | サギ科               | 5    |
| ササギ類                                 | サギ類               | 2    |
| アメリカオオヨシゴイ（American Bittern） | アメリカサンカノゴイ | 3    |

和名は環境省「自然環境保全基礎調査」の報告書（コウノトリ目サギ科、ズグロミゾゴイ）と日本語版 Wikipedia のアメリカサンカノゴイ（_Botaurus lentiginosus_、サギ科サンカノゴイ属）で確認しました。地図マーカーのデータも併せて再生成しています。

原因についても書き残しておきます。中国語の原文には日本語の種名が書かれていないため、翻訳の段階でモデルが**知らない固有名詞を埋めた**ものです。人名で同じことが起きるのは既知の問題として対策してありましたが、生物の標準和名が同じ形で抜けていました。この穴は翻訳ガイドの課題として記録します。

読者の方に見つけていただかなければ、12 言語のうち日本語版だけが存在しない鳥の名前で書かれたままでした。ありがとうございます 🧬
