# Feedback — idea · 「向後兼容」台灣怎麼說？台灣用語是「向下相容」

**回報者**：劉恩哲
**時間**：2026-11-01T17:44:31.089837+00:00

**回報內容**
詞語解釋：向下相容（downward compatibility），又稱向後相容（backward compatibility）、回溯相容。在電腦中指在一個程式、庫或硬體更新到較新版本後，用舊版本程式建立的文件或系統仍能被正常操作或使用（包括輸入資料）、在舊版本庫的基礎上開發的程式仍能正常編譯執行，或較舊版的硬體仍可在新版使用的情況。

⚠️差異比較
中國用語：向下兼容、向後兼容、回溯兼容；臺灣用語：向下相容、向後相容、回溯相容。

謝謝劉恩哲 🙏 你指出的那一點是對的，而且正好戳到這個詞庫最該避免的錯法。

`data/terminology/向後兼容.yaml` 原本台灣欄寫「向下相容」、中國欄寫「向後兼容」，把**方向詞**（向後／向下／回溯）跟**相容／兼容**這兩件事混在同一格，讀起來變成「台灣說向下、中國說向後」。兩岸真正分歧的是「相容」與「兼容」這個字，方向詞兩邊都有。

已修正（commit [`5730fd9e4`](https://github.com/frank890417/taiwan-md/commit/5730fd9e4)）：

```yaml
display:
  taiwan: 向後相容 / 向下相容 / 回溯相容
  china: 向後兼容 / 向下兼容 / 回溯兼容
english: backward compatibility
```

另外補一件值得寫下來的事。2026-07-10 那輪 LLM 詞庫複審其實也標了這一條 `MAPPING_WRONG`，但它給的建議是「台灣『向後兼容』／中國『向下兼容』」——照著做會把台灣欄換成對岸的「兼容」，正好是這個詞庫存在目的的反面。模型預設拿中國語料當基準，所以審查主權敏感的用語時，模型的建議是線索不是答案。這次是讀者的眼睛接住的。

轉換器那邊實際攔得住含「兼容」字串的是 `相容.yaml` 那條通則規則，本條提供的是這個詞自己的對照頁：https://taiwan.md/terminology/向後兼容/
