已修正，commit `53bb79557`。

回報的三處場館資訊都成立。對照[園區官網的場館介紹頁](https://www.paulchiangartcenter.org/buildings-and-contributors)逐棟查過之後改成：

| 原本寫                           | 現在寫                                                                                     |
| -------------------------------- | ------------------------------------------------------------------------------------------ |
| 承翰館：主展覽廳                 | 承翰館（第三展覽廳）：以雕塑〈13.5 坪〉為原型，被暱稱為「教堂」                            |
| 信義館：第二展廳                 | 信義館（第一展覽廳）：園區全面完工前是江賢二的臨時工作室                                   |
| 勤誠館：改建自江賢二的舊工作室   | 勤誠館（第二展覽廳）：由江賢二的舊畫室擴建而成，館內「冥想空間」是常設展                   |
| 筑弘亭會館：讓駐村藝術家短期住宿 | 筑弘亭會館：榮譽館長與交流藝術家短居的地方，一樓是德布西咖啡，也是全園區唯一可以飲食的場域 |

「勤誠館是第二展覽廳」這點回報得對。不過官網同時寫明勤誠館「由江賢二的舊畫室擴建而成」，而信義館是「園區全面完工前的臨時工作室」，兩棟都有工作室的線，所以沒有整個對調，是把展廳序號跟工作室來歷併進同一列寫清楚。

駐村那條也照官網改了：園區自己把邀請創作者短居寫成計畫，正文原本那句「邀請年輕藝術家駐村」改成「讓創作者來這裡短居交流」。

新增腳註 43 指向官網場館頁、德布西咖啡頁與參觀資訊頁。
