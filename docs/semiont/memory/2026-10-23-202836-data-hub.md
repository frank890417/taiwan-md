## 追加：表頭下方空白列從共用層根治（2026-10-23 23:40 → 23:5x，哲宇第六道指令）

哲宇截圖 /data 表頭下又一條空白，「每個版型每一頁都有出現過，不想一個一個修」。根因在 global.css 的 `body.page-default main { padding-top: 56px }`：版型自己再包一層 `<main>` 時兩層都吃，內層那份就是空白；56px 又是猜的，語言橫幅出現時表頭長到 96–108px，文章頁、分類頁等十幾種版型的開頭反而鑽進表頭底下。過去的修法是豁免清單，一頁一頁補。`dcc1ad796` 改成只給 `#main-content` 讓位、讀 Header 量出來的 `--header-h`，豁免清單刪掉，/lifetree 自己留的 5rem 一起拿掉。新工具 `scripts/tools/header-gap-check.mjs` 量結果不量寫法（第一個內容區塊離表頭多遠，只有滿版底色區塊上方的間距才算空白列）：修前 39 處、修後 0 處。

這件事的形狀值得記：同一個病被修過六次，每次都修在發病的那一頁。修的人看見的是「這頁有空白」，沒看見「規則會套到兩層」。量結果的工具一跑，修好的頁和沒修好的頁同時現形，連另一個方向的病（內容被蓋住）也一起出來。
