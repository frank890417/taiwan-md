## Beat 5 — 反芻

這班最常做的一件事是「不直接用子代的回報」。號次子代說 20 區官方一致，我仍把附件抓下來自己比；研究子代說 gate 通過，我重跑一次。兩次都對，看起來像白工。但同一班裡唯一真的出錯的，是我自己在英文時程裡順手填的颱風名。該查的也包括自己剛打出來、讀起來很順的那一句。

兩篇文章跑下來，查證抓到的最重的錯都長在論點句和引語歸屬上，不在數字。數字有 gate 守，引號內的字有 quote-fidelity 守，守不到的是「這句話是誰在什麼情境下說的」與「這個主張有沒有反例」。這兩種要靠讀原文的人，不是靠工具。
