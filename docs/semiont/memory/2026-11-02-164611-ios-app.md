## 研究接手與規劃

twmd-desk 的 [ios-app-research-2026-11-02.md](../../../reports/ios-app-research-2026-11-02.md)（`0b941996a`）在本班開工後二十分鐘落檔，讀完直接接手，研究不重做。先抽驗三個會撐住整個架構的前提：`renderArticleHtml()` 只依賴 `marked-cjk.mjs`，可以用 jiti 在 Astro 外直接呼叫。Apple Compression 解得開 Python `lzma` 產的 xz。`upload-pages-artifact` 的 `include-hidden-files` 預設 false（親手讀 action.yml）。三個都成立，規劃 [ios-app-implementation-plan-2026-11-02.md](../../../reports/ios-app-implementation-plan-2026-11-02.md)（`f53331c12`）照研究的十七條預設採用十四條，改三條：指標檔也放 Release、搜尋改正規化字串比對取代 FTS5、零第三方依賴。

搜尋那條是這班最有把握的取捨。FTS5 的 bigram 索引查不到中文單字（「茶」「廟」），印地文的母音符號在 `unicode61` 裡被當分隔符，阿拉伯文還要另外處理。一千多篇的量級用 `instr` 全掃，Mac 上中文全文 50–70 ms，模擬器上 53 ms，剛裝好的第一次查詢 340 ms，13 語一套規則就成立。

## 內容包產線

`scripts/app/render.mjs` 用網站同一支渲染器把 `knowledge/` 轉成每語 NDJSON，`pack.py` 打成 SQLite（中繼資料、HTML、正規化搜尋欄）再 LZMA 壓縮，`build-app-packs.sh` 串起來並對賬每語篇數（`c01f30beb`）。13 語全量渲染不到 30 秒，壓縮 preset 9 每語 8.9–11.7 MB。試過 preset 6 反而大四成，因為 64 MB 字典才吃得到跨文章的重複。發到 GitHub Release `app-packs`（prerelease、不標 latest），剛上傳時下載網址回 404 約十秒，是 CDN 延遲。

## App 本體

`apps/ios/` 是 SwiftUI 外殼加 WKWebView 本機 HTML：今日、探索、時間軸、搜尋、收藏、設定、今日一篇 Widget（`0890f0395` 起）。網站的 `article-modules.css` 直接帶進 App，`tw-versus`、方格圖在深色模式下都正確，腳註改成點上標從底部滑出卡片。模擬器逐頁看過：首圖與出處、分類、時代頁、全文搜尋片段、韓文與阿拉伯文從 Release 自動下載並驗 sha256、阿拉伯文右到左。單元測試 14 組全綠（正規化跟 Python 共用 16 條樣本、繁中日英搜尋集、時間軸解碼、四條深連結）。

修掉的四個真問題：時間軸的年份有時是多語字典，第一版當字串整份解不開而畫面空白（`3de80f446`，加測試守住）。搜尋片段取自正規化文字，全形逗號變半形。精選卡片的 `scaledToFill` 圖撐寬蓋到隔壁（`9885d4ee1`）。Info.plist 版本號寫死，build 號不跟時間走。

## 網站側與上架資料

AASA 放上 `public/.well-known/`，`deploy.yml` 打開 `include-hidden-files` 並加 `paths-ignore: apps/**`（`3ef268285`）。部署後 200，Apple 的 `app-site-association.cdn-apple.com` 也已抓到，研究擔心的 Content-Type 實測沒影響。`apps/ios/store/APPSTORE.md` 收齊三語文案、隱私問卷（Data Not Collected）、分級答案（預期 13+）、審查備註。`privacy-policy.md` 依網站實際的 GA4、Cloudflare、Supabase 讀者回饋起草，屬對外溝通，等哲宇看過才做成 `/privacy/` 頁。6.9 吋截圖五張由 `tools/screenshots.sh` 自動拍（`3d5a1136b`），第一輪被模擬器的系統通知蓋住上緣，重拍。

## Beat 5：反芻

這班最省時間的一個動作，是在寫任何程式之前先驗三個前提。渲染器能不能離開 Astro、Apple 解不解得開 xz、Pages 會不會丟掉 `.well-known`，三個任何一個不成立，整份規劃的形狀都要改。驗它們總共花了不到五分鐘。反過來，真正花掉來回的四個 bug，全都是「資料的形狀跟我以為的不一樣」：年份有時是字典、譯文 frontmatter 的 subcategory 沒有翻、首圖有時已經在正文裡。這些只有把真的資料灌進真的畫面才看得到，單元測試寫得再早也只會驗我腦中的形狀。
