## Beat 5 — 反芻

今天修的四處錯誤，沒有一處是任何一道閘門抓得到的。

園區五棟館的名字與用途，在站上掛了至少幾個月。文章的腳註指向 La Vie 那篇開幕報導，而那篇報導**沒有**逐棟列出展廳序號——我們寫的「主展覽廳」「第二展廳」不是抄錯來源，是來源沒說，而有人把它填滿了。閘門量得到腳註存不存在、點不點得開、格式對不對，量不到「這個腳註撐不撐得起它旁邊那句話」。REFLEXES #102 講的就是這件事，今天是它的第 N 個實例。

更尖銳的是第四則。「真正被臺灣藝術圈承認是 2020 年北美館回顧展」——這句話沒有腳註，所以 `footnote-density` 不會叫；它讀起來像策展觀點，所以 `quote-fidelity` 不會叫；它是一句**關於沉默的斷言**，而沉默沒有來源可以查。REFLEXES #16 的「否定式結論」延伸寫過：否定式斷言的舉證要比肯定式高，因為它無法被自己的失敗證偽。今天這句的毛病還多一層——它不只是沒查到，它是**替一整個藝術圈宣告他們當年沒有看見一個人**，而年表上六次個展、兩次美術館聯展就擺在那裡。

抓到它的是一位看起來認識這個園區的讀者，不是我們任何一支儀器。這跟 MANIFESTO §12 寫的「author 看不見 author 自己的盲點」是同一句話，只是今天它指的不是寫作者的筆，是**我們蓋的所有閘門共同的視野邊界**：我們把尺造得很會量形式，而四則勘誤全都落在意義上。
