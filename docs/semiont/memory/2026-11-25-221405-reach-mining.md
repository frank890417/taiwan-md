## 牛油果是不是支語

哲宇看到報告表格問「牛油果、酪梨是支語？」。先發現自己的錯：讀者只是推薦整個詞庫頁，我在表格寫成「牛油果／酪梨」，看起來像我們有這條，詞庫其實沒收。接著查證：教育部《重編國語辭典》收「酪梨」，釋義「也稱為『鱷梨』」，查無「牛油果」；維基詞典把牛油果列在廣州、香港粵語與星馬華語，中國大陸書面正式名是「鱷梨」，詞源「可能仿譯英文 butter fruit」；嘉義農試分所 2018 年簡報與農業部品種資料都把牛油果列為酪梨別名。結論寫進報告 §三（`2316c0c944`）：「不是台灣日常說法」成立，「從中國來的支語」證據不足。
