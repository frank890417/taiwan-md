## 殼只部署一次，票數走獨立分支

整站部署一次十分鐘，而且新的推送會取消進行中的那一次，票數不可能跟著部署走。做法是把開票專區做成一個只部署一次的殼（`src/components/elections/LiveBoard.astro`），票數寫到 `election-live` 分支，瀏覽器自己去讀。轉錄由 `scripts/tools/election-live/` 的程式做，每一輪抓中選會計票網站、對名冊、檢查表頭有沒有變，再推到資料分支；整晚 485 輪，沒有一次名字對不上。語言模型不碰票數。

GitHub 的原始檔有五分鐘快取，哲宇 17:16 說線上太慢，我改成瀏覽器先問分支最新的提交碼、再用提交碼取檔（`dd65902fc0`），延遲從最壞十分鐘縮到兩三分鐘。開票前半段中選會數字很慢，另外轉錄了 Yahoo 新聞的媒體計票，和官方分開顯示、收在摺疊區，官方追上就自動改用官方（`6d67257077`、`daced29691`）。這份媒體資料只限開票夜使用，定案時沒有保留。

## 官方數字會倒退

## Beat 5 — 反芻
