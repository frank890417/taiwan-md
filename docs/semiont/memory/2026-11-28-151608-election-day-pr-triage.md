## Beat 5 — 反芻

今天最該記的是早班那三條「指錯頁」裡有兩條是假的。早班的推理沒有錯：抓回來的頁面確實跟文中句子無關，依 Step 3.4 退回是照規矩走。錯在它把抓取工具的一次回傳當成網址的真相，然後把修正的工作交給投稿者。如果投稿者照留言去「找正確的那篇」，他會發現網址本來就對，那則留言就成了對他研究的一次錯誤指控。肯定式的結論我們有讀原文的習慣，否定式的「這條指錯頁」只靠一次抓取就成立，跟 REFLEXES #16 否定式結論那條延伸是同一個形狀，這次長在腳註審查上。

第二件是部署窗口。brief 寫了不准碰哪些檔，沒寫不准在什麼時間推，我就把「沒寫」讀成「可以」。開票日的 `main` 是一條一次只能跑一個部署的產線，任何 push 都在搶它。REFLEXES #68 的 CI 協調講的是 pre-push 等「近完成的部署」，可是那道判斷看不到「這次部署是別人今天絕對不能被取消的那一次」，那層資訊只住在另一個 session 的腦子裡。下一次跟主 session 同時動 `main`，第一次 push 前先問一句。
