> **30 秒概覽**：能源貧窮不是單純「用電太多」或「不會節電」，而是家庭沒有足夠資源取得安全、可負擔且有效率的能源服務。對住在老舊公寓、頂樓加蓋、通風不良房間，或使用二手高耗能冷氣的家庭來說，開冷氣可能造成帳單壓力，不開冷氣又可能提高熱傷害風險。台灣目前缺少全國一致的能源貧窮定義，但民間調查曾發現受助弱勢家庭能源支出占可支配收入的比例明顯偏高。[^1] 當高溫被政府視為跨部門風險，能源貧窮就不能再只是節電宣導，而應成為住宅、社福、衛生與氣候調適共同處理的公共問題。[^2]

# 能源貧窮不是「不夠節約」

能源貧窮最容易被誤解成家庭缺乏節電習慣：少開冷氣、少用熱水、隨手關燈，帳單就會下降。但這種說法忽略了家庭真正能選擇的範圍。住在隔熱良好、窗戶有遮陽、冷氣效率高的住宅，與住在西曬、漏水、通風差、使用老舊家電的住宅，即使室內外溫度相同，也不會有相同的能源需求。

因此，能源貧窮至少包含三個層次。第一是**支付能力**：能源帳單占收入的比例過高，迫使家庭在食物、醫療、交通與用電之間取捨。第二是**能源服務品質**：家庭即使繳得起帳單，也可能住在過熱、過冷、潮濕或通風不良的空間。第三是**取得能力**：租屋者、獨居長者、身心障礙者或沒有前期資金的家庭，可能無法自行更換冷氣、改善窗戶或申請複雜補助。

台灣青年氣候聯盟整理過去研究時指出，台灣尚未形成公認的能源貧窮定義，並引用工研院與家扶合作調查，指出受助弱勢家庭能源支出平均可能占可支配收入的 18%。這個數字不應直接外推為全台人口比例，但它提醒我們：若只用總用電量判斷家庭是否節能，可能把「因為住宅與設備太差而被迫高支出」的家庭誤認為浪費者。[^1] 國立臺灣大學的研究也把能源負擔放回居住條件與弱勢家庭的交互關係中理解，而不是只把問題歸因於個人消費選擇。[^8]

# 為什麼夏季能源貧窮特別危險

過去談能源貧窮，政策與研究常以冬季取暖為主要想像。台灣卻面臨另一種季節性風險：夏季高溫。弱勢家庭可能不是「沒有能源需求」，而是有需求卻不敢使用。當室內溫度升高，家庭可能選擇縮短冷氣時間、把冷氣設定得過高，或只讓兒童與長者進入有冷氣的房間。這些都是帳單壓力下的適應行為，而不是單純的消費偏好。

國民健康署明確提醒，室內空氣不流動、熱能無法排出時，室內也會發生熱傷害。老人與兒童的體溫調節能力較弱，應特別注意室內高溫。官方建議定時補充水分、維持通風，並在使用冷氣時將溫度設定於 26 至 27°C。[^3] 這些建議對有冷氣、能正常通風且有能力支付電費的家庭較容易做到；對住在頂樓、鐵皮加蓋或窗戶無法開啟的家庭，則需要建築與設備投資才能真正落實。

高溫風險也具有累積性。房屋在白天吸收熱量，夜間若無法散熱，長者可能在睡眠期間持續暴露於高溫。冷氣濾網堵塞、室外機散熱不良，則會讓同樣的降溫效果需要更多電力。這表示「熱安全」不能只用某一個時刻的氣溫衡量，而要看住宅在一整天如何吸熱、蓄熱與散熱。

# 一間老屋如何把高溫變成高帳單

老舊住宅的能源困境通常不是單一設備造成。牆面與屋頂隔熱不足，會讓冷氣負載增加。窗戶沒有遮陽，會讓西曬熱量直接進入室內。老舊冷氣效率較低，啟動後仍不一定能穩定降溫。濾網與室外機長期未清潔，也會使設備耗電與故障風險上升。若家庭沒有前期資金，就可能只能持續支付高額運轉成本，卻沒有能力改善造成成本的根源。

能源貧窮因此與住宅權、租屋權及建築治理相連。房屋所有人可以決定是否更換窗戶、加裝遮陽或改善外牆。租屋者卻可能擔心改造費用無法回收，也可能沒有權限施工。補助若只給設備購買者，便可能排除最需要改善、但沒有房屋決定權的家庭。

# 補助為什麼不一定等於可及

中央與地方近年都有家電汰換、住宅節能或隔熱補助。政策設計通常希望以有限經費換取節電、減碳與家庭支出下降，但「符合資格」與「能夠完成申請」之間仍有差距。

以經濟部能源署的住宅家電補助申請頁為例，申請人需要準備身分文件、存摺、電費單或用電證明、發票、保固卡與廢四機回收聯單。補助也受年度預算與審查條件限制。[^5] 對有穩定銀行帳戶、能先支付新機費用並保存完整文件的人，這是一套可處理的程序；對沒有前期資金、家電是房東所有、或由社工與親友協助生活的人，則可能形成實質門檻。

台北市 2026 年住宅社區創能儲能及節能補助提供了一個較完整的地方案例：除了社區創能、儲能與玻璃隔熱膜，也針對列冊低收入戶補助一級能效冰箱與冷氣汰換。公告並設定冰箱與冷氣補助上限，顯示地方政府開始把弱勢家戶設備效率納入淨零與公正轉型。[^6] 但這類方案仍需處理三個問題：補助是否涵蓋租屋者、是否能支付安裝與拆機成本，以及計畫額滿或期限截止後，下一次支持何時出現。

桃園市的高溫敏感族群降溫節能補助則把 0 至 6 歲幼童與 65 歲以上長者納入目標，補助冷氣清洗、玻璃隔熱膜與老舊冷氣汰換。這類政策的意義在於，它不只按照低收入資格辨識需求，也嘗試用年齡與高溫敏感性找到可能被忽略的家庭。[^7] 然而，若要避免福利斷裂，年齡、收入、住宅條件與健康風險仍應能在社福與衛生系統間合理銜接，而不是要求家庭反覆證明自己值得被幫助。

# 從節電宣導走向居住熱安全

傳統節電宣導的核心訊息是「少用一點」，能源貧窮政策則必須增加另一個問題：「如何用更少的能源，得到足夠的安全與舒適？」兩者並不矛盾，但政策工具不同。

| 政策層次 | 傳統節電做法           | 居住熱安全做法                               |
| -------- | ---------------------- | -------------------------------------------- |
| 設備     | 鼓勵關燈、調高冷氣溫度 | 汰換高耗能冷氣、清洗濾網、改善室外機散熱     |
| 建築     | 宣導遮陽與通風         | 補助窗戶遮陽、隔熱膜、屋頂與外牆隔熱         |
| 社福     | 依低收入資格發放補助   | 由社工、衛生所與社區主動辨識高溫風險家戶     |
| 資訊     | 提供節電知識           | 提供簡化申請、到府能源診斷與用電改善建議     |
| 評估     | 計算節省多少度電       | 同時衡量熱傷害、室內溫度、帳單負擔與生活品質 |

第一個轉向是**從事後補貼轉為前端診斷**。社工、里辦公處、居家服務員或衛生所人員，可以在訪視時記錄住宅是否頂樓、西曬、無法通風、冷氣故障或家電老舊。這些資料不必用來貼標籤，而是用來安排能源診斷與改善順序。

第二個轉向是**從單戶設備轉為住宅與社區尺度**。一台高效率冷氣可以降低用電，但無法解決整棟建築屋頂吸熱、公共區域悶熱或電力容量不足。社區若能共同改善遮陽、屋頂、電梯與公共用電，可能比逐戶要求家庭自行投資更有效率。

第三個轉向是**把高溫納入防災與健康治理**。環境部 2025 年首度試辦抗高溫調適對策演練，以雙北連續三日超過 38°C、發布紅燈預警為情境，讓中央部會與地方政府共同處理重點族群照護、民生能源與社區調適。[^2] 這項演練也指出，高溫當時尚未被完整納入《災害防救法》的天然災害範疇，意味著制度仍需明確化：何時啟動、誰來聯絡獨居長者、哪些場所成為降溫據點，以及停電時如何維持這些服務。

# 能源轉型不能把成本轉給最弱的人

能源轉型常用減碳、供電穩定與產業競爭力來衡量，但如果低收入家庭因電價、設備與住宅條件而無法維持基本熱安全，轉型就可能產生新的不平等。這不是反對節電或提高能源效率，而是要求政策同時回答「誰先得到改善」與「誰承擔轉型成本」。

台灣青年氣候聯盟整理的能源貧窮討論，已提醒政策應結合客觀與主觀指標，不能只看電費占比或總用電量。也要納入建築條件、設備效率、人口結構、熱舒適與福祉。[^1] 公共電視的專題報導則把能源負擔放入弱勢家庭的實際生活脈絡，說明能源轉型若缺少分配設計，可能讓原本承受較高居住與設備成本的人再承擔新的負擔。[^9] 這種方法對台灣尤其重要，因為一個家庭可能因為怕熱而用電較高，也可能因為付不起電費而用電異常偏低；兩者都不能單靠帳單判斷。

地方政府的高溫演練與節能補助，提供了政策試驗的空間。中央則需要建立共同的最低標準，包括弱勢家戶熱安全指標、補助申請的無障礙設計、租屋者與房東的責任分配，以及能源診斷資料的隱私保護。若各縣市各自推出短期方案，家庭可能因戶籍、申請時間與資訊能力不同而得到完全不同的保護。

# 一套可執行的台灣方案

台灣不必一開始就建立複雜的單一能源貧窮分數，而可以先從可操作的服務流程開始。中央過去透過縣市共推住商節電計畫支持地方節能治理，這提供了把能源診斷、社福轉介與住宅改善接在既有行政網絡上的制度入口。[^10]第一步是由地方政府建立「居住熱安全轉介」：當社工、衛生所、消防、居家照顧或社區組織發現家戶有高溫風險，就能轉介能源診斷，而不是只提供一次性的電費補助。

第二步是把改善措施分成三個成本層級。低成本包括清洗冷氣、調整遮陽、改善通風與提供溫度計。中成本包括隔熱膜、窗簾、室外機散熱與節能家電。高成本則包括屋頂、外牆、窗戶與社區公共空間改造。這樣可以避免所有家庭都被要求購買昂貴設備，也能讓有限預算先處理最危險的住宅。

第三步是把成效從「節省多少電」擴大為「是否降低風險」。政府可以追蹤室內高溫時數、熱傷害就醫、家戶能源支出負擔、設備故障率與住戶主觀熱舒適，而不是只以總節電量決定計畫成功與否。節電量下降但熱傷害增加，不能被稱為成功；家庭用電略增、但因高效率設備而獲得安全降溫，也不應被簡化成失敗。

這套制度還需要一個可被地方工作者使用的最低資料集。家庭不必被迫揭露所有消費細節，但至少應能在取得同意後記錄住宅樓層、屋頂型態、主要熱源、冷氣與冰箱年限、室內通風、居住人口中是否有高溫敏感者，以及最近一季能源支出是否造成生活取捨。資料應以服務改善為目的，與社福個案資料分層保存，並讓家戶知道哪些資料會被誰使用。若資料只被拿來判定「值得不值得補助」，就會增加污名；若資料能用來安排清洗、修繕、隔熱與轉介，才可能把能源政策變成預防性的公共服務。

地方政府也可以建立「熱安全服務包」：在熱浪警示前，先由社區據點、居家服務與衛生所聯絡高風險家戶。警示期間提供可步行抵達的降溫場所、飲水、充電與緊急聯絡。警示後再檢查冷氣、電扇、窗戶與電費負擔是否出現新的問題。這種服務不應只在災害或急診發生後才啟動，而要成為夏季例行的社區照顧工作。對偏鄉與離島而言，服務包還應納入維修人力、零件運送與停電備援，否則再好的補助也可能在設備故障時失去作用。

# 結語：讓安全降溫成為基本生活能力

能源貧窮的核心，不是要求弱勢家庭更有意志力，而是承認居住條件與能源服務本身存在不平等。當老屋吸熱、高耗能家電、前期購買成本、補助申請門檻與極端高溫交疊時，一張電費帳單就會同時呈現收入、住房、健康與氣候風險。

台灣已經開始累積地方隔熱補助、家電汰換、高溫演練與社區節能的政策工具。下一步不是再增加一句「請節約用電」，而是把這些工具串成一套以人為中心的居住熱安全制度：主動找到風險家庭，先改善最耗能的住宅條件，讓補助能被租屋者與無法預付費用的人使用，並用健康與生活品質檢驗能源轉型是否公平。

當一個家庭可以在高溫中安心開冷氣、而不必在健康與帳單之間二選一，能源政策才真正從「供給管理」走向公共福祉。

政策評估也應保留住戶的聲音。地方政府可在服務前後詢問室內是否更容易降溫、是否減少因電費而縮短冷氣時間、設備是否更可靠，以及住戶是否知道下一次高溫警示時可以求助的場所。這些回饋不應取代能源支出與健康資料，而應與量化指標並列，讓政府知道計畫究竟改善了生活，還是只完成了採購與核銷。若補助使家庭獲得設備，卻沒有解決租屋限制、維修責任與後續電費，政策就需要重新設計，而不是把結果歸咎於住戶沒有配合，並持續公開檢討與修正。
