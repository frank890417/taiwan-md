# 支語誤判学：なぜ一つの言葉が台湾語と中国語の両方になるのか

> **30秒概覧：** 教育部『重編國語辭典修訂本』の「土豆」の項目は同時に三つの意味を与えています。落花生の別名、大陸地域のジャガイモ、そして葫蘆茶という植物の別名です。一方、『國語辭典簡編本』の「両岸常用詞語対照表」では「土豆」を「ジャガイモ」の項目の大陸用語として掲載し、同じ欄に洋芋と山藥蛋も列挙しています。二つの官方資料を並べてみれば、「これは支語か否か」という問いに単一の答えが存在しない理由が明らかになります。

---

## 一つの言葉、三つの意味

まず辞典がどのように記述しているかを見てみましょう。教育部『重編國語辭典修訂本』の「土豆」の項目の釈義は以下の通りです。「『落花生』の別名。『落花生』の項を参照。大陸地域ではジャガイモを指す。『葫蘆茶』の別名。多年生半灌木。単身複葉。総状花序、花は淡紫色。莢果は五～八節を有す。」[^1]

この一項目には三つのことが同時に成立しています。台湾では「土豆」は落花生を指し、これが日常用語です。対岸では「土豆」はジャガイモを指します。そして植物学の分類では、「土豆」は葫蘆茶の別名です。

言い換えれば、同じ言葉が三つの異なる指涉体系の中でそれぞれ一つの位置を占めています。どのリストであっても「どのような文脈で」という欄が欠けていれば、これらの意味の一つを全体として扱う可能性があります。

## 官方対照表はどのような形をしているか

もう一つの官方資料は教育部『國語辭典簡編本』の付録「両岸常用詞語対照表」です。その資料出典は非常に明確に記載されています。一つは中華語文知識庫の「両岸差異用詞」、もう一つは『両岸毎日一詞・一般名詞対照表』で、両者とも中華文化総会の許可を得て提供されています。[^2]

この表の形式は二欄です。左側が「台湾用語」、右側が「大陸用語」です。第1ページで見られる例には以下のようなものが含まれます。

| 台湾用語   | 大陸用語                       |
| ---------- | ------------------------------ |
| 便當       | 盒飯                           |
| 部落格     | 博客                           |
| 筆電       | 手提電腦／筆記本／筆記型電腦   |
| 保固       | 保修                           |
| ジャガイモ | 洋芋／山藥蛋／ジャガイモ／土豆 |
| パンダ     | 熊貓／パンダ／大熊貓           |
| ボウリング | ボウリング／地滾球             |
| マンゴー   | マンゴー／檬果／杧果           |

この形式を理解すれば、その目的が「対照」であり「禁止」ではないことが分かります。これは両側がそれぞれ一つの言い方を持つと想定し、両側を並べて、照会する人が相手側でどのように言うかを知ることができるようにしています。これは「これらの言葉を見たら統一戦線の影響を受けている」というリストとは、完全に異なるものです。[^2]

## 同じ項目、複数の言い方

表の「ジャガイモ」の欄には四つの大陸用語が列挙されています。洋芋、山藥蛋、ジャガイモ、土豆です。これは対岸でも同じものに対して複数の言い方があり、そのうちの一つ「ジャガイモ」は台湾でも同じように使われていることを意味しています。

「パンダ」の欄はさらに問題を明確にしています。大陸用語の欄に列挙されているのは「熊貓／パンダ／大熊貓」で、三つの言葉が共存し、そのうち「パンダ」は台湾の用法と完全に一致しています。もしあるリストが「熊貓」だけを中国用語として選び、「パンダ」を台湾に残すなら、同じ項目の中に存在しない境界線を作り出すことになります。[^2]

「マンゴー」の欄に列挙されているのは「マンゴー／檬果／杧果」で、三者は同じ果物の異なる表記法であり、差異は異体字と地域的習慣にあり、政治的立場ではありません。「ボウリング」の欄には「地滾球」が現れ、これは対岸の一部地域での言い方で、台湾の「ボウリング」と並列されています。[^2]

これらの例は同じ結論を指しています。対照表が記録しているのは「差異」であり、「敵味方」ではありません。これを判定ツールとして使用すれば、一欄に複数の言葉がある大量のケースに遭遇し、各欄について「どれが本当か」を再度判定する必要があります。

## 判定がなぜ失準するのか

上記の二つの資料から、判定を失準させる三つのメカニズムを整理することができ、ネット論争を引用する必要もなく検証できます。

第一は一語多義です。「土豆」は台湾では落花生、対岸ではジャガイモで、辞典は両方の意味を同じ項目に入れています。この言葉を見て「これは支語だ」と言うことは、台湾での元々の用法を無視することと同じです。[^1]

第二は同じ概念に複数の言い方があることです。「ジャガイモ」の項目には四つの言い方が列挙されており、あるリストがそのうち一つだけを認識すれば、他の三つを「中国用語ではない」と誤判定します。逆に、台湾で元々使われている「ジャガイモ」を中国用語と誤判定する可能性もあります。[^2]

第三は異体字と地域変種です。「マンゴー／檬果／杧果」「パンダ／熊貓／大熊貓」は同じものの異なる表記法や異なる呼び方で、これらを二つの陣営に分割すれば、リストはますます長くなり、ますます使いにくくなります。[^2]

三つのメカニズムに共通点があります。それらはすべて「言葉」のレベル以下で発生しています。言葉を判定するには、まずそれがどのような文脈で、何を指し、誰が使用しているのかを知る必要があり、これらの情報はリストには含まれていません。

## 「是か非か」から「どのように使うか」へ

本稿は「支語は存在しない」または「支語を使用しても問題ない」と主張するものではありません。別のことを主張しています。文脈のないリストを使って言葉を判定すれば、誤り率は非常に高く、その誤りの方向がどちらかの側に立つとは限らないということです。

官方資料ができることは、検索可能な出発点を提供することです。教育部辞典はこの言葉がいくつの意味を持つかを教え、対照表は両側でどのように言うかを教えます。「使うべきか否か」は教えることができません。なぜなら、それは辞典の仕事ではないからです。

実際に操作可能な方法は、問題を「これは支語か」から「この言葉は台湾でどのように使われ、どこから来て、より正確な言い方があるか」に変えることです。前の問題の答えはリストのバージョンによって変わりますが、後の問題の答えは項目ごとに検証でき、検証後には自分が何を言っているかが分かります。
