> **30秒概観：** 2025年に公表された『台湾原住民族取用伝統姓名指引』は、16民族の伝統的名制を5つの構造に整理しました。個人名の後に続く部分は、父名・母名・氏族名・家屋名、あるいは子女の誕生に伴って変わる呼称である可能性があります。賽夏族の「豆」「風」「日」「絲」といった珍しい漢姓は、氏族名が漢式戸籍に入った後の歴史を留めています。これらの名を読むとき、まず「姓＋名」に分解しようとせず、それがどの親族・家屋・部落の関係を指しているかを見極めることが重要です。[^1]

夏曼・藍波安（シーマン・ラポガン／Syaman Rapongan）の長男が生まれる前、彼は Si Nozayin と呼ばれていました。子である藍波安（ラポガン）が生まれた後、彼は Syaman Rapongan と改め、「藍波安の父」を意味するようになりました。ここで姓名は固定されたラベルではなく、人が人生の段階に応じて変わり、家族によって呼び直される仕組みなのです。[^2]

次に賽夏族の「風」姓を見てみましょう。一見すると珍しい漢姓ですが、その裏には `baba:i` 氏族、親族協力、祖霊祭祀集団、婚姻禁忌がつながっている可能性があります。これを単に「珍しい字」と見なすだけでは、氏族制度と戸籍登記が重なり合った歴史を見逃すことになります。[^3] [^4]

## まず姓を探さず、名が誰を指しているかを見る

台湾原住民族には、全民族共通の「姓が前、名が後」というルールはありません。現行指引が整理した5つの名制は、構造を理解するための地図であり、各民族の人々に当てはめるための定型テンプレートではありません。同じ民族内でも、地域・家族・現代的選択によって実践が異なる場合があります。[^1] [^2]

> 📝 **キュレーターメモ：** 漢式姓名ではまず「あなたの姓は？」と尋ねがちです。原住民族の伝統的名制では、しばしば別の問いに先に答えます：あなたは誰の子か、どの家屋から来たか、どの氏族とつながっているか、今人生のどの段階にいるか。

原住民族委員会は16民族の伝統的名制を以下の5つに整理しています。同じ二段・三段の並びでも、異なる民族に置かれると社会的意味がまったく異なることがあります。[^2]

| 名制構造         | よくある並び方       | 公式に例示される民族・コミュニティ           | 後段が通常記録しているもの                                            |
| ---------------- | -------------------- | -------------------------------------------- | --------------------------------------------------------------------- |
| 親子連名制       | 個人名＋親名         | 泰雅、賽德克、太魯閣、阿美、噶瑪蘭、撒奇萊雅 | 父名や母名などの親名。個人を直系親族の文脈に置く。[^2]                |
| 親子聯名氏族名制 | 個人名＋親名＋氏族名 | 一部の阿美族コミュニティ、賽夏族             | 親名に加え、氏族の識別と社会的位置。[^2] [^5]                         |
| 家屋名制         | 個人名＋家屋名       | 排灣、魯凱、卑南                             | 家屋の帰属・継承・社会関係。[^1] [^2]                                 |
| 氏族名制         | 個人名＋氏族名       | 布農、鄒、邵、卡那卡那富、拉阿魯哇           | 家族歴史、婚姻禁忌、集団識別。[^2]                                    |
| 親從子名型       | 呼称＋長子名         | 雅美族                                       | 父母や祖父母が長子の誕生に伴い改称。名が人生の段階に応える。[^1] [^2] |

## Miru、Kaliting、Pacidal：名の各セグメントが異なる事柄を語る

泰雅族アーティストの米路・哈勇（ミル・ハユン／Miru Hayung）の名では、Miru が個人名、Hayung が父名です。公式紹介では Miru が絵画・読書に関連し、Hayung が松を指す可能性があるとされています。これは個人名と親名が結ばれた例です。[^2]

阿美族歌手・司会者の阿洛・卡力亭・巴奇辣（アド・カリティン・パチダル／Ado’ Kaliting Pacidal）には3つの座標があります：Ado’ が個人名、Kaliting が母の名、Pacidal が氏族名。原民会の資料によれば、Pacidal には太陽の意があり、氏族の守護神と結びついています。[^2]

排灣族の Ljaucu・Zingrur（リャウツ・ジングルル）の Zingrur は家屋名です。家屋名は個人の属する家を識別し、家屋継承や社会階序に関わることもあります。実家を離れる、異民族間通婚などの場合、排灣・魯凱・卑南族の家屋名も調整されることがあります。[^1] [^2]

布農族作家の拓跋斯・塔瑪匹瑪（トゥルブス・タマピマ／Tulbus Tamapima）の Tamapima は氏族名です。原民会記録では日常は個人名で呼び合い、初対面や議婚など婚姻禁忌を確認する場面で氏族名が完全に語られます。名はこうして「交際可・通婚不可」の境界を同時に保存しているのです。[^2]

## 「豆」「風」は奇字ではない：賽夏族漢姓にある氏族の手がかり

賽夏族社会は父系氏族を基盤とします。原民会によれば、18の氏族それぞれに名称があり、命名素材は動植物・自然現象・身体的現象から採られます。氏族はさらに相互扶助・祭祀集団・連族関係を形成し、特定の婚姻禁忌を守ります。[^3]

清領時代、賽夏族の氏族制度と漢姓観念が出会いました。氏族名は音訳や原意による字選びを経て、徐々に豆・趙・朱・風・高・潘・錢・根・樟・夏・蟹・日・絲・芎・狐・蟬・獅・血・膜といった漢姓を形成しました。その後、一部の字形が解・胡・詹に改められました。これらの字は、氏族名が漢式登記に入った際に残った手がかりであり、個人の氏族帰属を判定する道具として直接使うべきではありません。[^3]

## なぜ一つの氏族が複数の漢姓を残すのか

2019年の研究（2013年戸籍データに基づく）は、賽夏族の一部「氏族名－漢姓」対応を定量化可能なデータとして整理しました。研究では最初に対応した字を「本姓」、後続の異なる字形を「衍姓」と呼びます。これは当該研究の分析ツールであり、登記歴史を見るのに適していますが、部落・家族・戸政による個別認定に代わるものではありません。[^7]

| 2013年研究で採用された氏族名綴り | 対応漢姓と人数                    |  合計 | このデータが示すこと                                                 |
| -------------------------------- | --------------------------------- | ----: | -------------------------------------------------------------------- |
| `baba:i`                         | 風 905、楓 87、鄷 35、栢 1、東 23 | 1,051 | 風姓以外にも複数の字形が延伸；漢姓数が氏族数に直結しない。[^7]       |
| `tatawazay`                      | 豆 157、趙 789                    |   946 | 豆と趙が同研究で整理された一つの氏族対応に属する。[^7]               |
| `sawan (kas’ames)`               | 潘 408、錢 243、根 233            |   884 | 複数の漢姓が同一氏族または関連親族群の歴史的登記痕跡となり得る。[^7] |
| `minakes`                        | 樟 34、章 341                     |   375 | 近似または異なる字形が、氏族名転写と行政登記の過程に由来し得る。[^7] |
| `tanohila:`                      | 日 205、張 103                    |   308 | 語意・音訳・後続の登記選択が同時に作用し得る。[^7]                   |
| `titiyon`                        | 朱 1,008                          | 1,008 | 一部の氏族は当該研究データで単一の主要漢姓のみ呈示。[^7]             |

> ⚠️ **データ読解の注意：** 上表の年次は **2013年**、資料出典は2019年研究であり、現在の人口統計ではありません。表の価値は「一つの氏族が複数の漢姓に対応し得る」構造を示す点にあり、数字で誰かのアイデンティティを断定する点にはありません。[^7]

「豆」と「風」が書くに値するのは、それらが珍しいからではなく、一見すると一文字の姓に見えるものを、氏族・婚姻規範・祖霊祭祀集団・数度の戸籍制度変動が重なる長い時間へと引き戻すからです。

## 清領・和姓から単列族名へ：姓名制度はどうここまで来たか

原住民族の姓名は、白紙の表でゼロから設計されたものではありません。今日の証明書上の選択肢の裏には、異なる政権・異なる戸籍制度・原住民族運動が残した幾重もの痕跡があります。[^7] [^8]

| 時期           | 姓名制度の出来事                                                                                                    | 名前への影響                                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 清領時代       | 賽夏族氏族名が音訳や意訳で漢姓観念と結合。[^3]                                                                      | 豆・風・日・絲などの字が氏族の可視的手がかりとなる。                                                             |
| 1940年         | 研究記録によれば、賽夏族は日本時代の改姓名運動で97の和姓を採用；全面的和姓化から5年足らずで政権交代により終了。[^7] | 和姓が新たな分化をもたらしたが、旧漢姓と原氏族の混淆への影響は限定的との見方。                                   |
| 1945年12月     | 「台湾省人民回復原有姓名辦法」で3か月以内に「中国姓名を参照し自定姓名」を要求。[^7]                                 | 急速・全面的な漢式姓名登記が、多くの家族の姓名転換の背景となる。                                                 |
| 1995〜2006年   | 内政部と『姓名条例施行細則』が3度改正。[^7]                                                                         | 原住民族姓名登記が漢名強制から段階的に脱却し、ローマ字族名の併記が可能に。                                       |
| 2024年5月      | 『姓名条例』改正案が三読通過。[^8]                                                                                  | 原住民族が原住民族文字で単列姓名を使用可能；文化慣俗による改名かつ個人的事由でない場合、改名回数に算入されない。 |
| 2025年1月と4月 | 関連作業要点改正、『台湾原住民族取用伝統姓名指引』公布。[^1] [^9]                                                   | 行政手続きと文化慣俗の参照枠組みがより完全に、伝統的姓名の多元的構造を強調。                                     |

## 法律が扱うのは登記、文化が扱うのは関係

現行『姓名条例』は、原住民族姓名の登記は文化慣俗に依り、原住民族文字の使用や中文姓名・漢人姓名との併記を認めています。2024年改正後、原住民族文字を単列姓名とすることが可能になりました。文化慣俗による改名で個人的事由でない場合は、一般の改名回数に算入されません。[^8] [^10]

しかし法規は氏族知識をチェックボックス一つの選択肢に縮めていません。戸政の「台湾原住民族回復伝統姓名及更正姓名作業要点」では、中文または原住民族文字の伝統姓名回復、原住民族文字の併記、姓氏と父母名の更正申請が可能です。光復初期の戸籍設定で生じた親族姓氏の不整合などについては、申請人が日治期戸口調査簿・初設戸籍謄本等を提出できます。日治戸口調査簿がない場合は、2名以上の関連年長親族の証明でも足ります。[^9]

これら手続きの重要性は：一つの珍しい漢姓や族語単語だけでは、命名資格の証明になり得ない点にあります。伝統的姓名が文化慣俗に合うかは、依然として民族別・家族資料・部落知識・戸政調査の文脈に立ち返って判断されます。疑義があるときは、戸政実務で当該民族の専門家や耆老の協力を求めることができます。[^1] [^9]

## 中点は表現、関係こそがルール

「・」はしばしば原住民族名のシンボルと見なされますが、単なる表現手段の一つに過ぎません。戸政実務では原則として当事者が中点または空白で区切る選択を尊重します。より重要なのは、名の並びが当事者の属する民族の文化慣俗に合致することであり、傍観者が抱く「原住民族の名はこう見えるべき」というイメージに迎合することではありません。[^9] [^10]

伝統名の回復は歴史を巻き戻すことでもありません。日治期・戦後戸籍登記・異民族通婚・移住・長年の漢名使用が、各家族の伝統名制への回帰経路を異ならせています。研究者が『原住民族人名譜』を整理したのは、手がかりを失った家族が追索可能な資料を持てるようにするためです。最終的にどう名づけるかは、依然として部落知識と個人の選択を尊重すべきです。[^7] [^11]

名の後ろにいる人は、父・母・長子・氏族・家屋かもしれません。読者が「豆」「風」を単なる珍しい漢字姓ではなく、圧縮された関係地図として見るとき、原住民族姓名の並びルールが初めて真に姿を現すのです。
