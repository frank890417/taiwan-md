# 糖蔥：白い穴の中に隠された「抗争の糖」

> **30秒概観：** 糖蔥の中にネギはない。それはかつて、台湾の農民が植民地政府に対抗した「偽装武器」だった。日本統治時代、台湾で生産された蔗糖は厳しく管理され日本へ輸出され、地元の人々が砂糖を食べるには警察の検査を逃れなければならなかった。農民は糖蜜が冷却する際の延展性を利用し、繰り返し引き伸ばして中空の管状構造を作り出し、その外見はネギの白い部分に酷似していたため、野菜かごに混ぜれば検査を欺くことができた[^5][^6]。この「16大孔、16小孔」の精密な構造により、口に入れると即座に溶け、歯にくっつかないサクサクとした食感が生まれ、島の歴史の中で最も草の根の知恵に満ちた甘味となった[^14]。

2024年の宜蘭伝統芸術センター、「糖蔥文化館」の前に観光客の群れができていた。空気には濃厚なキャラメルの甘い香りと麦芽の清々しい香りが漂い、職人の卓創慶（たく・そうけい／チョウ・チュアンチン）氏が、重さ3キログラム、温度120度に達する褐色の糖餡を木杭にかけ、両手で素早く引き伸ばし、折り畳み、また引き伸ばす[^12][^20]。

空気が強制的に糖体に押し込まれるにつれ、現場から規則正しい「パチッ、パチッ」という音が響く。褐色の琥珀色をした透明な液体が、わずか10分足らずで奇跡的に真珠のような光沢を持つ象牙白へと変わり、最後に絹のような質感を持つネギ管として定型する[^20]。百年受け継がれてきたこの「甘味のマラソン」、一度の引き伸ばしごとに歴史の重みが込められている。

## 潮汕から台湾へ：甘味の越境移徙

糖蔥の歴史は、清朝時代の広東省潮州・汕頭一帯まで遡ることができる[^2][^4]。明朝の潮州知府・郭子章（かく・ししょう／グオ・ズーチャン）は『潮中雑紀』の中で「潮の葱糖、極めて白く極めて鬆（ゆるやか）なり、渣滓（かす）絶無し[^15]」と記している。閩粤移民の食文化の一部として、糖蔥は移民の波に乗って香港、福建へ伝わり、最後に台湾で根付いた[^2]。

古い潮汕の風習において、糖蔥は教育的な役割も果たしていた。学童が入学初日に糖蔥の薄餅で孔子像を祭るのは、その「中空」の構造が「聡慧通竅（賢さが通じる）」を寓意し、心が透き通って聡明で学びに励むことを象徴するためだ[^16][^17]。民間では入学最初の数日について、こんなユーモア溢れる民謡さえ伝わっている。「初日は糖蔥甘し、二日目は竹篦連（先生に叩かれ）、三日目は走去鎮（逃げ隠れ）、四日目は尋唔見（見つからない）[^16]。」

## 禁じられた甘味：農民の「偽装術」

台湾の糖業は日本統治時代に黄金期を迎えたが、その甘味は台湾人のものではなかった。当時、日本政府は甘蔗保護政策を実施し、すべての白糖は優先的に日本へ輸出されなければならず、地元の人々が私的に製糖したり砂糖を隠したりすることは違法とされた[^5]。

一口の甘味を守るため、台湾の農民は極限の創意工夫を凝らした。彼らは熬煮後の糖蜜を繰り返し引き伸ばすと、無数の微細な気孔が生じ、外見が白く中空になり、切り分ければまさにネギの白い部分そのものになることを発見した[^5][^6]。農民はこれらの「偽装ネギ」を本物の青ネギのかごに混ぜて運搬し、日本警察が巡回しても満かごの野菜しか見えない。中に貴重な糖分が隠されているとは気づかれなかった[^5]。この「抗争の糖」はこうして台湾民間で広く伝わり、「白糖蔥」や「富貴糖」という別名でも呼ばれるようになった[^1][^5]。

## 16+16の精密工芸：物理と化学の交響

糖蔥が魅力的なのは甘さのためではなく、その「一折れすれば砕け、口に入れれば即座に溶ける」独特の食感にある。この物理的特性は、極めて複雑な内部構造から生まれる。

糖蔥を作るには、白砂糖、水、麦芽糖を特定の比率で混合し、120℃から130℃まで精確に加熱する必要がある[^3]。糖餡を木杭にかけ繰り返し引き伸ばす際、内部の糖分子鎖が強制的に再配列され、数万個の微小な気泡が取り込まれる[^3]。

| 製作段階                 | 物理・化学変化                                   | 主要目的                                           |
| :----------------------- | :----------------------------------------------- | :------------------------------------------------- |
| **熬糖（糖を煮詰める）** | 蔗糖分子が120-130℃で部分的に転化                 | 糖蜜に十分な延展性と硬度を持たせる[^3]             |
| **冷却**                 | 糖餡が「ガラス状態」と「ゴム状態」の臨界点に入る | 糖体が半固体となる黄金の引き伸ばし期を捉える[^3]   |
| **拉糖（糖を引く）**     | 空気を取り込み、光学散乱の原理で雪白に変わる     | 多孔質構造を形成し、体積とサクサク感を増す[^1][^3] |
| **折疊（折り畳む）**     | 16回の折り畳みで蜂の巣構造を形成                 | 16大孔と16小孔の精密な支えを作る[^14]              |

合格した糖蔥の断面には必ず「16個の大孔、それぞれの大孔を16個の小孔が取り囲む」構造が備わっている[^14]。この精密な構造により、糖蔥は力を受けると極めて砕けやすく、噛み砕いた瞬間に気圧の解放がもたらす清々しい音が響く——これはどんな機械生産の菓子も真似できないものだ。

## 横断的糖芸：糖蔥と他の伝統菓子

台湾の廟会や老街では、様々な伝統糖芸を見かけることが多い。材料は似ていても、工芸と食感は全く異なる：

| 技芸名称   | 核心工程                            | 食感特徴                                             | 物理状態                     |
| :--------- | :---------------------------------- | :--------------------------------------------------- | :--------------------------- |
| **糖蔥**   | 高温熬糖 + 16回の折り畳み引き伸ばし | サクサク、歯にくっつかない、口に入れれば即座に溶ける | 硬く脆い中空管状[^18][^19]   |
| **龍鬚糖** | 熟糖膠 + 熟粉 + 万回の延展          | 柔らかく綿のよう、蚕糸のように繊細                   | 極細糸状、内部に餡[^18][^19] |
| **画糖**   | 熬糖 + 銅板鋳造描画                 | 硬く脆い、棒付きキャンディ類似                       | 平面図案状[^19]              |
| **吹糖**   | 糖塊を引き伸ばし + 吹き管で成形     | 薄く脆い、中空                                       | 立体造形（干支など）[^19]    |

## 老味を守る師傅たち

食品工業の発展に伴い、手間がかかり気候の制約を受ける手工芸の糖蔥引きは失伝の危機に瀕している。現在、台湾でなおこの工芸を守り続ける少数の師傅がいる：

- **宜蘭五結**：卓創慶（たく・そうけい／チョウ・チュアンチン）師傅、三代受け継ぐ、伝統芸術センターで連日「甘味のマラソン」を上演[^12]。
- **台南麻豆**：陳恆雄（ちん・こうゆう／チェン・ヘンション）師傅、徒手で糖を引くこと40年余り、これは体力と温度の戦いだと強調[^11]。
- **三峽老街**：卓師傅（同系継承）、古色古香の街並みの中でこの老味を守る[^7]。
- **淡水と嘉義**：亦、独学や家伝で湿気と温度の狭間で純手工芸製作を貫く老師傅がいる[^9][^13]。

## 結語：甘味の中の韌性

糖蔥の物語、その本質は「韌性（レジリエンス）」についての物語だ。それは圧迫の中で生まれ、欠乏の中で育ち、最後に精緻な食の波の中で、機械では決して代替できない一手の引き糖功夫によって生き延びてきた。あなたが糖蔥を一口噛み、その清々しい砕ける音を聞くとき、その甘さの中に百年前、台湾の農民が「甘味の抗争」の中で屈服を拒んだ草の根の知恵が隠されているのだ。
