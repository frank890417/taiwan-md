# 台湾の米食文化

> **30秒で概観：** 台湾人の年間米消費量は、1985年の85kgから2024年には42kgへと急落し、鶏肉が初めて米を凌駕して新たな主食となりました。しかし、端午（だんごくじつ）に粽子（ちまき）を包む文化や中元（ちゅうげん）で米粉を捧げる文化は継承されており、新竹の九降風（きゅうこうふう）の下で行われる米粉の工芸も地域の誇りとなっています。これは、稲作の島国が直面する食の西洋化への葛藤と適応の物語です。

2022年は一つの転換点でした。台湾人の年間肉類消費量は87.5kgに達し、穀類の87.4kgを初めて上回りました。これは、鶏肉が正式に米に取って代わり、台湾人の食卓における新主食となったことを意味します。1985年には一人当たり年間85kgの米を消費していましたが、2024年にはわずか42.1kgとなり、半減しました。

しかし、宜蘭（イーラン）三生（さんせい）の田畑では、農家は依然として良質な米を栽培しています。新竹（シンチュウ）の米粉工場では、九降風が髪の毛のように細い米線（びせん）を乾かしています。また、台湾の各家庭では、端午に粽子を包む技術が祖父母から孫へと受け継がれています。

> **📝 編集者のメモ**
> これは単なる食習慣の変化ではなく、農業文明全体の変革です。マクドナルドやドリンクスタンドが若者の胃袋を占める現代社会において、伝統的な米食文化はどのように新たな居場所を見つけようとしているのでしょうか？

## 稲作の島国の黄金時代

台湾の稲作の歴史は5000年前に遡りますが、真の「米食王国」は日治時代に始まります。1926年、農業専門家によって台湾の気候に適した「蓬萊米（ほうらいまい）」が育成され、これは島の運命を書き換えた一つの種子となりました。

蓬萊米は伝統的な在来米よりも粒が短く粘り強く、炊くと透明感があり、食感が適度な柔らかさを持っています。さらに重要なのは、その生産量が在来米より30%多かったため、この島は食糧不足から自給自足へと移行できた点です。

| 85kg → 42kg                                 | 87.5kg                       |
| :------------------------------------------ | :--------------------------- |
| 台湾人の年間米消費量の変化（1985年→2024年） | 2022年の一人当たり肉類消費量 |

戦後の台湾において、米は絶対的な主役でした。1960～70年代には、「台湾米」が日本へ輸出されることもあり、年間100万トン以上を輸出していました。当時の台湾人の一日は、朝食に粥と漬物、昼食にお弁当、夕食に白米とおかずという形で米なしでは語れませんでした。

あの時代、もし夕食に米を食べなければ、「ご飯を食べないのは本当に食べていないのと同じ」と祖母は言いました。麺類を食べていたとしてもです。米は単なる食べ物ではなく、「ちゃんとした食事」そのものの定義でした。

## 九降風の下の工芸：新竹の米粉

旧暦の9月になると、新竹では「九降風（きゅうこうふう）」が吹き始めます。これは時速70kmにも達する冷たく乾いた北東の季節風です。この風は農作物を枯らしますが、同時に独特な工芸品である米粉作りを可能にしました。

新竹の米粉の秘密は「七分風乾燥、三分日光干し」にあります。挽かれた米漿（こめじゃく）を髪の毛のように細い粉条（ふんじょう）に押し固め、竹簾の上に広げ、九降風の乾燥力によって自然乾燥させます。この工程には2～3日かかり、職人は経験に基づいて風向きや湿度を判断し、いつ粉を取り、いつ裏返すかを決定します。

> **💡 ご存知でしたか**
> 新竹米粉には「水粉（すいふん）」（短く粗いものでスープによく使われる）と「炊粉（すいはん）」（細長く炒めたり煮たりできるもの）の二種類があります。炊粉は蒸してから乾燥させるため保存期間が1年近くに及び、かつては台湾における重要な軍糧でした。

一皿の米粉炒めは、黄金色で半透明な粉条に青ネギ、豆芽（とうや）、エビ米を添えたもので、屋台の軽食であると同時に宴席にも欠かせません。しかし、新竹の米粉産業は縮小傾向にあります。1980年代には50以上の米粉工場がありましたが、現在では10余りしか残っていません。若者は天候に左右されるこの技術を引き継ぎたがらず、機械による大量生産の米粉が市場を席巻しています。

## 粽子（ちまき）：三角形に秘められた文化コード

毎年端午の前夜には、台湾では「南北粽の大戦」が勃発します。これは単なる味の争いではなく、その背景には異なる文化遺伝子が隠されています。

**北部粽：「南煮北蒸」の油飯派**
北部粽は、もち米と餡を半熟になるまで炒め、三角錐に包んで30分間蒸します。食べると油飯のような食感で、粒がはっきりと感じられ、餡には豚バラ肉、卵黄、香菇（しょうこ）、エビ米が入っています。竹の殻で燻製されており、かすかな燻製の香りがします。

**南部粽：生米を一緒に煮込む純粋派**
南部粽は、生の糯米に煮込んだ餡を包み、丸ごと沸騰したお湯の中で2～3時間煮込みます。もち米は調理過程で餡のエッセンスを吸収し、食感は柔らかく粘り強くなります。孟宗竹葉（もうそうちくよう）の香りが豊かで、ピーナッツが南部粽の魂であり、綿密でとろけるような食感が特徴です。

| 北部粽                               | 南部粽                             |
| :----------------------------------- | :--------------------------------- |
| 先に炒めてから蒸す、油飯のような食感 | 生米を茹でる、柔らかく粘り強い     |
| 竹の殻葉（燻製の香り）               | 孟宗竹葉（清々しい香り）           |
| 甘辛いソースを添える                 | 醤油ペースト＋ピーナッツ粉を添える |

しかし、最も台湾らしいのは祖母の手作り粽子かもしれません。これには標準的なレシピはなく、長年の直感に頼っています。粽子を包む前夜、家族全員がリビングに集まり、葉を洗い、餡を炒めながら粽子を包み、おしゃべりをします。この家庭のひとときそのものが文化なのです。

## もちと粿類：祝祭の甘い記憶

伝統的な麻糬（もち）作りは、力強さと美しさのパフォーマンスです。蒸した糯米を石臼に入れ、屈強な男性たちが交代で杵で叩き潰し、もう一人がひっくり返したり水をつけているのを手伝います。この打つリズムがモチの食感を決めます――打ちすぎると硬くなりすぎ、足りないと弾力が不足します。

客家（かくか）の人々の「糍粑（ちば）」、先住民の「小米麻糬（こみもち）」、台湾式の「花生麻糬（かしゅうましゅ）」は、それぞれ異なる民族の味覚的記憶を内包しています。中元祭や慶事、旧正月のご家族の集まりには、モチが欠かせません。

粿類は、台湾米食芸術の極致的な表現です。

1. **紅龜粿（こうきいこ）** — 赤色は吉祥を象徴し、亀の形は長寿を表し、中に甘い緑豆餡が入っています。
2. **草仔粿（そうざいこ）** — 艾草で色付けされ、翠玉のように緑色で春限定です。
3. **碗粿（わんごう）** — 蒸した米漿に肉燥を合わせたもので、台南の軽食代表格です。
4. **蘿蔔糕（らぼくこう）** — 白大根の千切りと米漿の完璧な融合で、旧正月には必須です。

一つ一つの粿には特定の季節や用途があり、完全な文化記号システムを成しています。

## 米食衰退の現代的危機

> **⚠️ 議論の視点**
> 米食消費の減少は「食の多様化」という進歩なのでしょうか、それとも「文化の喪失」という警告なのでしょうか？世代によって見解が分かれています。

データは嘘をつきません。台湾人は集団的に米飯に別れを告げようとしています。

**外食文化の衝撃**が最も致命的です。1990年代以降、ファストフードやチェーン店が台湾に進出しました。マクドナルドのハンバーガーやケンタッキーフライドチキンのほうが、伝統的な弁当よりも魅力的でした。若者は家でご飯を炊くよりも、タピオカミルクティーを並んで買うことを選びます。

**デリバリープラットフォームによる打撃**も致命的です。農林水産署副署長の姚志旺（よう・しおう）氏は、「米飯の弁当はデリバリー中に硬くなりやすく、イタリアンやハンバーガーの方が輸送が便利であるため、これが消費習慣に直接影響しています」と語っています。

**麺類の台頭**にも歴史的経緯があります。米軍援助時代（1951～1965年）、アメリカは大量の小麦粉を輸入し、政府は「麺類運動」を推進して人々がパンを食べるよう奨励し、「米だけが主食である」という概念を打ち破りました。この政策は予想以上に成功し、2024年には小麦粉の摂取量は米飯よりわずか6kgしか減っていません。

より深い原因は**生活ペースの加速**です。現代人は米を研ぐ時間も、炊飯器がスイッチを入れるのを待つ時間もありません。3分でインスタントラーメンを作り、電子レンジで弁当を温めることが日常になりました。美味しいご飯を炊くには忍耐が必要であり、それは現代社会において最も希少な資源となっています。

## 米食再生への新たな試み

危機に直面しながらも、台湾の米食産業は諦めていません。

**穀粉革命**が勃興しています。米粒を細かく挽いて粉にし、パンやケーキ、クッキーを作るほか、麺（板條）やライスヌードル（米苔目）の代用にも使われます。この「グルテンフリーベーキング」は現代人の健康ニーズに応え、米食に新たな生存空間を見出させています。

**ブランド化経営**も生き残りの道です。池上弁当、台東關山米（かんざんまい）、花蓮富里米などの地方ブランドは、産地直送や有機認証を通じて高品質なイメージを確立しました。一つの池上の米が一般の米の3～5倍で売られることもあり、消費者が買っているのは単なる米ではなく、「清浄な土地」の物語なのです。

**即食米食イノベーション**により、伝統的な味が利便性の高い生活に戻ってきました。冷凍粽子、即席米粉、電子レンジ対応米糕（こめがし）は、伝統的な風味を保ちつつ現代のニーズに対応しています。コンビニエンスストアの三角飯団や米粉弁当は、若い世代に再び米食と接点を持たせています。

さらに重要なのは**文化教育の定着**です。食農教育が学校に入り込み、子どもたちが実際に稲作をし、粽子を包み、麻糬を作ることで、米食文化全体の流れを体験しています。これらの子供たちが成長したとき、再び米飯を選ぶかもしれません。

## 記憶の中の味、未来の選択

| 米食再生を支持する意見 | 食の西洋化を受け入れる意見 |
| :--------------------- | :------------------------- |
| 農業文化の伝統維持     | 国際的な食の潮流への適応   |
| 食糧自給率の向上       | 食事選択の多様化           |
| 地元農業の保護         | 現代の生活ペースへの順応   |

台北のある夜市では、70歳の祖母が今も客家粄條（かくかきびょう）を現物で作り続けています。台中（たいちゅう）の伝統市場では、職人が毎朝4時に起きて碗粿を作っています。新竹の米粉工場では、九降風が毎年秋冬に定時通り出勤しています。

これらの光景は私たちに気づかせます。米食文化は単なる歴史ではなく、今も進行形で力強く生き続けているということです。

> **✦** 「本当に消えるのは米そのものではなく、米を囲んで築かれた儀式感――家族で食卓を囲む時間なのです。」

台湾人の年間米消費量が85kgから42kgに減少した背景には、一つの農業文明の変革があります。私たちは時代の流れを止めることはできませんが、何を保持し、何を継承するかを選ぶことができます。

一つひとつの粽子、一皿の米粉スープ、一つひとつのモチは、この土地の味覚的記憶の継続です。台湾の米食文化の未来は、過去の消費量に戻ることにあるのではなく、現代生活の中で新たな表現方法を見つけることにあるのかもしれません。

次に伝統市場を通りかかり、蒸籠から立ち上る湯気を嗅いだとき、それは五千年におよぶ稲作文明の香りです。私たちは足を止め、心を込めて味わう価値があります。
