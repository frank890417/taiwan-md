# 台湾の街角食

> **30秒概要：** 1987年3月、台中の春水堂で林秀慧という店員が粉球をミルクティーに入れました。特許は申請していませんでした。この思いつきの失敗が、3000億円規模の世界タピオカミルクティー帝国を生み出しました。台湾の街角食の歴史はまさにこのように——最も成功した発明はほとんど偶然であり、最も活気のある店舗は秘伝を公開しないと主張します。23.3万店舗、年間4000億円の産業規模、47万世帯が生計を支えるこの「理論上は存在しないはずの」ビジネスモデルは、台湾が最も真似できないソフトパワーです。

2024年の冬の夜、ドイツのビジネススクール教授が士林夜市のガニーマンジョン焼きの前に立ち、ガイドに困惑して言いました。「これらの店はブランド識別もなければ、標準化されたプロセスもなく、まともな看板もありません——ヨーロッパでやっていたら、このようなビジネスは早くも倒産してしまうでしょう。」

ガイドは答えませんでした。店の前には30人の行列ができました。

経営理論の観点から見ると、台湾の夜市は「成功する企業」の基本原則に反しています。ブランドも標準化も固定の場所もありません。しかし、まさにこの「存在しさえないはずのモデル」が毎年4000億円近い収益を生み出し、47万世帯を養い、台湾を世界で唯一「庶民の食べ物」を「文化的象徴」に輸出した事例にしました。

**これが核心の矛盾です。台湾の街角食が越に「専業的でなければならない」とされるほど、真に模倣できないものになります。**

## 田舎の労働者：すべての始まり

台湾の街角食の根は夜市ではなく、田舎にあります。

清代の乾隆時代、閩南族の人々が海を渡って台湾に移民し、平原を開拓しました。重労働のため農民たちは定時に定所で食事を取ることができず、労働者たちは竹籃を背負い、熱い食べ物を田んぼや港に運びました。これはロマンチックな食文化の伝統ではなく、純粋な経済的論理です。空腹を感じる人々は速やかに熱量を補充する必要があり、それも安く済ませなければなりません。

寺廟ももう一つの起源です。信仰の中心地で開催される迎神祭りでは、廟前の広場に人々が集まり、露店がそこに集まりました。これは外国人にとって不可解な台湾の現象を説明しています。なぜ最高の街角食は寺廟の近くにあるのでしょうか？神様の祝福ではなく、人々が先に集まり、露店がそれに従ってきたのです。

1908年、『台湾日報新報』に高雄の旗津天后宮前の広場の夜市が記録されています。これは台湾の夜市に関する最も古い文書記録です。本当のブレーンは1950年代に起きました。戦後の経済的困難の中で、小規模なビジネスが多くの人々の生活を支えるようになり、露店は市場の閉店後の空地に集まり、夜市が形成されました。

## 移民の融合実験室

台湾の街角食が本当に特別なのは、どの料理がどれほど美味しいかという点ではなく、それが**世界で最も密集した多文化食文化融合システム**であるという点です。

どの夜市に入っても、50メートルの中に以下のような食べ物が売っています。

- **閩南系**：ガニーマンジョン焼き、肉団子、まんじゅう（福建の移民が地元の材料を使って改良）
- **客家系**：麵条、客家の小料理、生姜のスープ（客家族の発酵技術）
- **外省系**：牛肉麺、ピーンアーノ、揚げパン（1949年以降各省から来た移民の郷愁の料理）
- **日本統治時代の遺産**：天ぷら、関東煮、かき氷（日本統治50年間の食文化の遺産）
- **原住民の基盤**：サツマイモ、小麦、野菜（島の土産の基本的食材）

さらに驚くべきは、これらの食文化が文化的衝突を起こす可能性があるにもかかわらず、台湾で共存していることです。夜市で閩南のガニーマンジョン焼きと外省の牛肉麺が同じ場所にあるのは奇妙ではありません。この「混血の方が純血よりも活気がある」という特性が台湾の街角食文化の遺伝子です。

## 四つの街角食、四つの生存の物語

### ガニーマンジョン焼き：戦争が生んだ台式の創造性

1661年3月、鄭成功が台南の鹿鳴門を攻略したとき、オランダ軍は怒りに駆られて市内のすべての穀倉を破壊し、鄭軍が飢餓で撤退するように誘発しました。鄭軍は手に入れたものを使って、安平海域のガニーマンジョン、サツマイモの粉、野菜を混ぜてパンを作り、腹を満たしました。「戦時の料理」は偶然にも美味しかったので、戦後民間で広まり、今日のガニーマンジョン焼きへと進化しました。

言語学者たちは、福建の泉州でも似たような「煎蠔」があることに気づきました。作り方はほぼ同じで、おそらくは泉州の移民が故郷の味を持ち込み、鄭成功の物語を付け加えたのではないかと推測されます。しかし、真実はどうであれ重要ではありません。ガニーマンジョン焼きは台式料理の基本的な論理を体現しています。手に入れたものを使い、地域に合わせて、シンプルな材料からすばらしい味を作り出すことです。

### 臭豆腐：8ヶ月の矛盾の哲学

1993年、ある洪姓の業者が『台湾光華雑誌』に対してインタビューを受け、臭豆腐の最大の秘密を明かしました。正真正銘の古い方法で作られた臭豆腐の滸は、野草、竹笋、野菜、カボチャなど数十種類の野菜を使い、塩で漬け込み、自然発酵させなければなりません。最初に作るには、使用する前に8ヶ月以上静置しなければなりません。

**8ヶ月。妊娩10ヶ月より1ヶ月短い。**

台湾の臭豆腐が外国のメディアの味覚を征服した鍵は、臭いの強度ではなく、発酵のレベルにあります。中国本土のバージョンは化学添加物を使って速やかに生産され、臭いは強く刺激的です。台湾のバージョンは長い時間自然発酵により、複雑なアミノ酸とエステル化合物を生成し、「臭くても香りのある」矛盾した感覚を生み出します。1995年、CNNのグルメ記者が士林夜市の露店の前で言いました。「他の場所の臭豆腐は嫌いですが、台湾のは好きです。」台湾の夜市の街角食の国際的な評価は、この瞬間から始まりました。

### 鼎邊糊：300年変わらない福州の遺伝子

1720年代、福州の漁師たちが基隆港に移住し、故郷の鼎邊糊の作り方を持ち込みました。台湾には福州の特定の水産物がありませんでしたが、彼らは手に入れたものを使い、基隆港のエビとタコで代用しました。「形は保持し、中身は地域化する」——これが台湾の移民食文化の最も典型的な適応戦略です。300年後の基隆の夜市でも、毎晩約2000村の鼎邊糊が売れています。それぞれの一口は、300年間の福州の遺伝子と台湾の海の味の融合です。

### 彰化の肉団子：清代労働者の熱量爆弾

彰化の肉団子の誕生には残酷な現実の背景があります。清代の彰化平原で大規模な開墾が行われ、労働者たちは高熱量で持ち運びやすく、長時間腹を満たす食べ物が必要でした。肉団子はサツマイモの粉で皮を作り（台湾特産）、豚肉と筍を詰めます。1つで半日の労働を支えるのに十分な熱量を提供し、事前に大量に作り、田んぼに運んで冷蔵せずにも味は変わりません。この「ニーズに基づいた設計」の街角食の論理は、グルメの創造性よりも機能性が高いです。

## 地域のDNA：移民の血脈の味の暗号

台湾の地域の街角食はグルメ観光の地図ではありません。それは移民史の一冊です。どの地域の特色の背後にも、ある族が特定の時代に「生き残る」ための証明があります。

**北部**：基隆の鼎邊糊の福州漁師の遺伝子。淡水のアーゲ（1960年代、楊桃嬤が余った油豆腐を使わないように発明した偶然の発明、「アーゲ」は日本語の油豆腐）；新竹の米線は九降風の天然乾燥による地理的利点

**中部**：彰化の肉団子は農業開墾の労働食です。逢甲夜市は革新的な街角食の誕生地であり、タコの焼き物の台式改造はここで生まれました。桃園の龍岩では今でも20軒以上の米線店があり、1950年代のクランやビルマの軍属が持ち込んだクランの味を台湾の漬物と豆芽で改造しています。

**南部**：台南の担仔麺は漁師の台風季の副業から始まりました。高雄の六合夜市の木瓜の牛乳は南台湾の熱帯産物を展示しています。

**東部**：花蓮のアミ族の野菜料理と麺。台東の池上の弁当は東部の良い米で作られた鉄道文化。

> **💡 知っていましたか？**
> 台南の街角食が甘いのはなぜでしょうか？二つの説があります。一つは日本統治時代、台南は糖の生産地であり、糖が容易に手に入りました。もう一つは、初期の農業労働者は速やかにエネルギーを補充する必要があり、糖は最も直接的な熱量の来源でした。どちらの説でも、同じ事実を指しています。台湾の街角食は「文化」のために生まれたのではなく、「生存」のために生まれたのです。

## タピオカミルクティー：偶然のグローバル帝国

1987年3月、台中の春水堂の四維店の店長、林秀慧が建国市場に買い物に行った時、子供の頃によく食べていた粉球をアイスティーに入れました。計画も市場調査も特許も申請していませんでした。

30年後の結果：

- **世界60カ国の市場**：ニューヨークからヨハネスバーグまでタピオカミルクティー専門店があります
- **年間3000億円の収益**：ティー、タピオカ、設備、包装材の5つの産業をつなぎます
- **ドイツのマクドナルドの逆輸入**：2005年からメニューにタピオカミルクティーを追加し、1日最大2000杯
- **2019年TikTokのブーム**：#BubbleTeaChallengeが10億回以上のビューを獲得

**マクドナルドが台湾の街角食を売り始めた時、それは台湾人がマクドナルドを真似した時ではなく、文化輸出の勝利です。**

タピオカミルクティーの成功の深い理由は次の通りです。QQのタピオカは他の飲み物にはない咀嚼の快感を提供します。甘さ、氷、トッピングのカスタマイズは個人的な好みを満たします。密封と太い吸い込み管は区別可能な文化的象徴になります。「一緒にタピオカミルクティーを飲びに行こうか？」は台湾人に最も一般的な社交の招待の言葉です。

この偶然の発明の背後には、もっと大きな台湾のパターンがあります。**台湾の街角食の最も重要な革新はほとんど計画されたものではありません。** 大腸の包みのようなものは1990年代の花蓮の客家の弁当箱から進化しました。士林夜市のタイマンジョンは1988年の「試してみよう」の考えから始まりました。逢甲夜市のタコの焼き物は日本の方法に台式のマヨネーズを混ぜた変な組み合わせです。

## 不可能なビジネスモデル

2023年の政府の統計によると、台湾全体の露店は23.3万店、従業員35.7万人、年間収益約3954億円です。

| 台湾の夜市の主要な数字（2023） |                   |
| ------------------------------ | ----------------- |
| 管理対象の夜市                 | 164 個            |
| 露店の総数                     | 23.3 萬攤         |
| 年間総収益                     | 約 3954 億元      |
| 従業人口                       | 47.2 萬人         |
| 台南市の夜市の数               | 49 個（全台最多） |

1つのガニーマンジョン焼き50元の原価を分析してみましょう。ガニーマンジョン15元、卵5元、野菜3元、サツマイモの粉2元、露店の賃料分担8元、ガス代2元、合計原価約35元、利益15元。人気の露店1晩に200村売れ、利益3000元、夫婦で月収5-8万元。

利益率は高くありませんが、回転率の良さがあります。さらに重要なのは、**露店の開業にかかる起動費は10-30万元で済む**、低いハードルが革新的な実験を奨励します。新しい味、新しい組み合わせ、成功すればコピーして広め、失敗しても大した損害はありません。この理由で、台湾の夜市はこれほど多様な商品を育むことができました。

## ミシュランが夜市の露店に出会った

2018年、ミシュランガイドが台湾に初めて進出しました。最も驚いたのは高級レストランではなく、36軒のBib Gourmand（必比登推薦）を受けたストリートの街角食でした。其中饒河、臨江街、南機場の3つの夜市ではそれぞれ4軒が上榜し、世界で最も高い密度の夜市の記録を樹立しました。

南機場夜市の「建宏牛肉麺」のオーナー夫人がインタビューで言いました。「ミシュランが来る前に、私たちはこのようにしていました。受賞するために何かを変えたわけではありません。」

この言葉は台湾の夜市の核心価値を表しています。**技術は評審のためではなく、明日また列を作る客のためにあります。**

しかし、ミシュランの影響も皮肉なものです。一部の老舗の露店は不満を漏らしています。受賞後、観光客が増え、地元の客が希釈されてしまいました。「夜市は地元の人のキッチンであり、観光客の遊園ではありません。」一位のベテラン露店の人はこう言いました。露店がミシュランの認証を追求し始めた時、それはまだ元の露店でしょうか？

## 三つの進行中の危機

**食の安全**：2013年の「毒のラーメン事件」が街角食産業に大きな打撃を与えました。多くの長寿の老店の評判は一瞬で崩れました。HACCPの認証と食材の追跡要求は強化されていますが、散露した露店の管理は依然として非常に困難です。

**伝承**：夜市の仕事は非常に辛いです。午後4時に準備を始め、深夜1時に閉店し、年に数日しか休みがありません。若者たちは会社員になる方が良いと思い、多くの露店は高齢化し、メニューが20年間変わらず、革新が停滞しています。

**チェーン化のパラドックス**：鼎太豊と永和豆漿は伝統的な街角食を標準化し、国際化しました。しかし、ある食べ物が200軒に店を出し、空港の免税店に進出した時、それはまだ元の「庶民の食べ物」でしょうか？チェーン化は品質を安定させますが、「店の前に師匠がいなければ閉店」という不確実性を失い去ります。そして、その不確実性こそが夜市の魂の一部です。

## 見られるためではなく

2024年の夏、饒河夜市のピーマンの老店のオーナーに「他の露店から客を奪われたくないですか？」と聞かれました。彼は3秒間考えて言いました。「私の客は毎日ここで私を待っている人です。初めて来た観光客ではありません。」

台湾の街角食は清代の移民が地元の食材を使って故郷の味を再現し始めた時から、今日の23万店舗が夜の中で灯をともしているまで、常にシンプルな論理を変えていません。美味しいものを作り、人々が歩き続けることができるようにすることです。

それは誰かが計画して世界に向かって歩み出したわけではありません。林秀慧が粉球をミルクティーに入れた時、文化輸出を創り出しているとは知りませんでした。楊桃嬤が余った油豆腐に冬粉を詰めた時、食材の無駄をなくしただけです。台湾の街角食の最も強力な競争力は、「台湾の光」の宣伝ではなく、閉店した後に明日また来るという強靱さです。

そのドイツの教授の困惑は、実は答えそのものでした。
