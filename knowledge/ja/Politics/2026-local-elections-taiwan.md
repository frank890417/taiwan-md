> **30秒概観：** 2026年11月28日、全土同日投票で9職位・約1.1万席 — 1994年民選以来第9回直轄市長選挙、22県市中13市で現職交代確実。過去と異なるのは環境：中共AI認知戦の工業化、検調取締り機構が半年前に始動、住民投票が大選に再結合の可能性。本稿は2026年選挙の総論 — 歴史的位置づけ、構造的圧力、制度的新変数 — 五年後にこの年がなぜ重要だったかを理解したい人のために書かれている。

2026年11月28日、土曜日午前8時ちょうど[^25]。

基隆和平島から屏東鵝鑾鼻まで、金門金城から台東蘭嶼まで、台湾全土22の直轄市と県（市）が同じ時間に投票所の扉を開く。直轄市長から村里長、議員から原住民族区民代表まで、**9職位同日投票**[^1]、総計**1.1万議席超の民選首長・民意代表**に影響[^2]。これが「九合一」という言葉の文字通りの意味 — 9種類の選挙を同日に実施することだ。

4年に一度、この儀式が繰り返される。1994年初の直轄市長民選、2010年五都昇格後の初九合一、2014年桃園昇格で布陣確定、2018年住民投票と大選結合で選務崩壊、2022年朝野対立下のポストコロナ選挙。それぞれが台湾民主主義の定期健診だ。

だが2026年のこの一戦は、過去のいずれとも異なる。

違いは候補者にない — 候補者の入れ替わりは民主主義の常態だ。違いは、この選挙が置かれた環境にある。

OpenAIが2026年2月に公表した報告で、中共が国家級AI認知戦システムを構築済みと判明[^3]。Citizen Lab同年、123以上の偽装ニュースサイトが多言語で偽情報を拡散中と暴露[^4]。検察機関は偽情報を2026年選挙取締り重点4項目の一つに指定（賄選・暴力、賭博盤、偽情報、外国介入）、取締り班が投票日半年前から始動[^5]。日本『読売新聞』報道：習近平政権が2028年頼清徳再選阻止を目標に、2026年地方選を「前哨戦」と位置づけ[^6]。

台湾の民主主義インフラがこのストレステストに耐えられるか、答えは投票日当日に明らかになるのではない。答えは選挙前の毎月、各機関、各市民ツール、各ファクトチェック組織、週末投票所に足を運ぶ各市民の上に、一寸一寸積み上げられていくものだ。

本稿は2026年選挙の「総論」である。選挙情報整理ではない（それは [/elections/2026/](/elections/2026/) 動的ページの役割）、この選挙のキュレーション narrativa、歴史的位置づけ、構造的圧力分析だ。五年後に読む人へ、2026年がなぜ台湾民主主義の重要節点だったかを伝えるために。

## 一、選挙基本情報：日程と規模

中選会2025年10月31日第622回委員会議決議の法定日程は以下の通り[^7]：

| 日付              | 手続                             |
| ----------------- | -------------------------------- |
| 2026/08/20        | 選挙公告発布（選挙正式開始）     |
| 2026/08/31-09/04  | 候補者登記                       |
| 2026/10/16 前     | 候補者名簿審定                   |
| 2026/10/23        | 候補者番号抽籤                   |
| 2026/11/12・11/17 | 候補者名簿公告（直轄市長優先）   |
| 2026/11/28（土）  | 投票日（投票時間は選挙公告準拠） |
| 2026/12/04        | 当選者名簿公告                   |

投票開始終了時刻は8月20日の選挙公告に明記；歴代地方選の慣例は午前8時〜午後4時[^25]。

9職位の定数規模（2022年應選11,023席基準の推定、正式定数は選挙公告準拠）[^1][^8]：

| 職位                     | 定数          |
| ------------------------ | ------------- |
| 直轄市長                 | 6             |
| 直轄市議員               | 380           |
| 県（市）長               | 16            |
| 県（市）議員             | 532           |
| 鄉（鎮、市）長           | 198           |
| 鄉（鎮、市）民代表       | 2,148         |
| 直轄市山地原住民区長     | 6             |
| 直轄市山地原住民区民代表 | 50            |
| 村（里）長               | 7,748         |
| **合計**                 | **約 11,084** |

投票用紙1枚では足りない — 各有権者は投票所で自身の選挙区資格に応じた複数の投票用紙を受け取り、直轄市長から村里長まで、それぞれ色が異なる。桃園復興、新北烏来、高雄那瑪夏など山地原住民区の有権者はさらに区長・区民代表の投票用紙が加わる。これが「九合一」の文字通りの複雑さだ。

選務機関にとっては4年に一度の物流地獄：投票用紙印刷、投票所設置、開票要員訓練、計票放送 — 全工程を同一労働日で完遂。台湾の選務システムは国際オブザーバーから長く「世界最速開票の民主国家の一つ」と評されてきたが、理由は技術でなく制度にある：手書き投票用紙、人手開票、唱票同時生中継、政党監票員立会い、選務職員「一人一票一動作」の標準作業手順[^9]。

## 二、歴史的位置づけ：30年座標上でこの選挙の位置を探る

2026年がなぜ重要か理解するには、台湾選挙史座標上の位置を理解する必要がある。

**1994年北高直轄市長民選後の9回目の直轄市長選挙**。1994年第3次修憲で『省県自治法』『直轄市自治法』通過、台北市長・高雄市長が官派から民選へ、途絶えた27年の民主の道が再接続。1994年から2026年、丸32年・9回の直轄市長改選 — この制度は一世代以上連続稼働している[^10]。同日投票の県（市）長は、1950年地方自治実施以来20回目。

**2010年五都昇格後の4回目の九合一**。2010年台北県が新北市昇格、台中県市合併昇格、台南県市合併昇格、高雄県市合併昇格、既存の台北市・高雄市と合わせ「五都」形成。2014年桃園昇格で今日の「六都」布陣確定。「九合一」という言葉が広く使われるようになったのは2014年から — それ以前は地方選挙は分散実施だった。全地方公職を同日にまとめたのは、2010年選挙制度大改革の成果だ。

**2024年大選後の初の中間テスト**。2024年1月総統選・立委選同日実施、民進党が総統職守るも国会過半数失い、立法院は「朝小野大」構図へ。その瞬間から2026年は各陣営にとって執政党への中間信任投票と見なされる。中央政府施政、立法院衝突、行政立法の綱引きが、有権者の地方首長・議員選択に反映されるか — 中間選挙の古典的命題だ。

**2028年大選の前哨戦**。日本『読売新聞』報道で中共が2026年地方選を頼清徳再選阻止の「前哨戦」と位置づけ[^6]。この位置づけが台湾有権者自身の解釈と合致するか否かにかかわらず、外部勢力はすでに2026年を2028年の予演として扱う。この外部ナラティブが逆に2026年選戦の議題設定に影響するか、注視に値する問題だ。

**2025年大罷免後の継続**。2025年市民団体が史上最大規模罷免行動発動、130万人連署[^11]。この運動の政治エネルギー、市民組織力、街頭動員経験が2026年にどう継続・転化するか、もう一つの観察線だ。罷免対象は個別立委だが、蓄積された市民意識は地方選挙の投票行動へ波及する。

この5つの歴史座標はいずれも未完結。2026年はこれらの物語の終点ではなく、次の節点だ。

## 三、なぜ今回は違うのか：3層の外部圧力

過去30年の台湾選挙には常に外部介入の影 — 1996年台海ミサイル危機、2000年「上海中央台」放送、2018年韓国瑜現象裏のネット工作疑惑。だが2026年が直面する外部圧力は次元が違う。主因はAI技術の飛躍で認知戦のコスト暴落、規模暴増、追跡難度暴騰。

### (1) AI認知戦：手工ネット工作から工業化へ

OpenAI 2026年2月報告で判明[^3]：中共が国家級AI認知戦システム構築済み、少なくとも1省内に300名以上の「ネット特戦」操作員、数千の偽アカウント、100種以上の戦術、台湾を主要攻撃目標の一つに指定。この報告の特異点は台湾側の告発でなく、OpenAIが自社API悪用パターン追跡中に複数アクター横断で系統的行動を特定した点だ。

台湾民主実験室DoubleThink Lab同時期、「中科天璣」内部文書分析公表[^12]、中国軍系シンクタンクがAI大規模言語モデルを影響力作戦フレームワークに組み込む手口暴露。9大要点：自動化ナラティブ生成、クロスプラットフォーム配信、地方議題への精密カスタマイズ、偽情報の地方フォーラム・コミュニティ注入、AI翻訳で非中国語圏浸透、音声合成で偽動画制作等。

このインフラが成熟すれば、各直轄市長選、各県（市）長候補、各地方議員が個別カスタマイズ攻撃の標的になり得る。**過去のネット工作は「台湾全体へ」**、未来のAI認知戦は**「特定選挙区・特定候補・特定議題へ」精密化**。

これはSFではない — 2026年選挙の現実的攻撃面だ。

### (2) 偽装ニュースサイト：偽メディアの工業的複製

Citizen Lab 2026年調査で123以上の偽装ニュースサイト判明、多言語・多プラットフォーム・多テーマに展開[^4]。設計ロジック：実在ニュースサイトのレイアウト複製、真偽混在コンテンツ随時生成、SEO最適化で検索エンジン収録、SNS偽アカウント拡散 — 「複数独立情報源からの報道」という錯覚を演出。

一部は台湾選挙ナラティブ専門 — 台湾ローカルメディアの装い、繁体字使用、あたかもローカル視点の政治評論を装う精巧な設計。一般有権者にとって「これは本物の台湾メディア」か「台湾メディアを模倣した偽装サイト」かを見分けるためのデジタルリテラシー要求は、過去より一段階高い。

### (3) 取締り機構の制度化：宣言から始動へ

検察体系が2026年選挙取締り重点を4類型に設定[^5]：

1. **賄選及暴力** — 伝統的買収・選挙暴力
2. **選挙賭博盤** — 賭けによる世論操作
3. **偽情報** — ディープフェイク映像、生成テキスト、カスタマイズ攻撃
4. **外国介入** — 越境協同操作、外部資金、海外ネット工作

AI生成偽情報を独立取締り重点に指定したのは台湾選挙取締り史上初 — 従来は「不実言論」「流言飛語」等の曖昧な法条に散在。2026年5月以降、宣言が始動機関へ：5月25日最高検察署「妨害選挙執行小組」発足、全国地検署同期設置、外国介入通報賞金最高2000万元[^5]；6月5日台北地検署「全国性重大ディープフェイク偽情報処理センター」設立、調査局・刑事局とディープフェイク鑑識・溯源窓口構築[^26]。

初件偵結はディープフェイクでなく賭博盤 — 6月、桃園地検署が初の越境仮想通貨選挙賭博盤偵結：境外予測プラットフォームPolymarketで「2026年台湾地方選挙」にステーブルコイン賭け、4名自白で緩起訴[^27]。6月末時点で台北地検署だけで妨害選挙情報37件受理[^28]。取締り機構が投票日半年前から稼働 — これ自体が2026年が過去と異なる証拠だ。

### (4) 実際の攻撃の様相：現在はアカウント育成・洗版、ディープフェイク未到来

2026年7月時点で、候補者標的のディープフェイク映像が立証された事例なし[^29]。実際の攻撃形態はディープフェイクより遥かに安価：

6月15日、「国家級警報突然大響」「高雄市緊急宣布了」等3波コンテンツがFacebookで洗版 — 383投稿、163重複なしファンページ、最密時5分で34件。セキュリティ研究者が中国河北のコンテンツファーム集団に帰属、2026年地方選認知戦の事前布石と判断[^29]。同月、メディア信頼格付け機関NewsGuardが中国ネットワークの5月からThreadsで294偽交友アカウント構築暴露、台湾男性と知り合いたいアジア女性装い — うち4割の命名パターンが2月民進党攻撃ネットワークと同一、選前アカウント育成・政治メッセージ転用準備と判断[^30]。

これら操作に共通する特徴：大量生産の「浅層偽造」（偽停班停課通知、偽防災公告、偽交友アカウント）で高コストのディープフェイクを代替。ファクトチェック組織にとってはディープフェイクより追跡困難 — 個別被害は闢謠に値しないレベルだが、総量で「公式発表は信頼できる」という前提自体を徐々に削ぐ。もう一つ注視ライン：韓国2026年6月地方選の「投票用紙不足」「投票率130%」デマが台湾SNSに移植、「選務は信用できない」ナラティブの越境複製兆候[^31]。

## 四、内部構造的議題：朝小野大、藍白協作、第三勢力

外部圧力に加え、2026年選挙は台湾内部に元々存在する代議民主主義の構造的張力と重なる。

### 朝小野大の継続

2024年立法院改選で民進党が過半数喪失、国民党が国会最大党も過半数届かず、民衆党がキャスティングボートに。立法院は2024年2月開議以来高度対立継続 — 国会改革法案、予算審議、人事同意権、釈憲手続き、すべて朝野間で反復攻防。

この朝小野大構図が2026年地方選に継続するか？ 地方有権者が地方票で中央政治対立への態度を表明するか？ それとも地方選は地方議題に回帰し、中央政治対立から脱鉤するか？ これは2026年結果後の最重要解釈戦場だ。

### 藍白協力協定：機制が一巡運転済み

2026年3月18日、両在野党が「連合治理暨地方選挙協力協議」締結、「先提名・後整合・共同推挙一人」原則明記、必要時全民調で人選決定 — 公開報道で新北市・嘉義市・宜蘭県3地が優先協調開始[^13]。この協定は台湾多党競合史上稀な選前正式制度化協力フレームワーク。

2026年7月時点で、この機制は実質一巡運転済み：嘉義市が4月初旬の整合民調で全国初の民衆党人選出線の共推人選輩出、新北（4月末）と宜蘭（5月初）は国民党人選出線、敗者側が公開輔選転任表明[^32]。嘉義県では変形も — 国民党が県長レベルで初の無所属人選に譲歩、両党協定を「在野大連合」へ延伸[^33]。機制は零摩擦ではない：彰化と金門で協調外の出馬動態、整合の境界線がこの協定実効性の真の試金石だ。

過去の多党協力は「在野整合」「政党協商」等非制度化呼称で現れ、選前には候補者個人意向で決裂が常。協力機制を党間協議文書化し、文書通り民調実施 — 最終選挙結果如何を問わず、制度レベルでの新たな試みだ。この試みが今後多党競争のモデルになるか、選挙結果と後続効果を待たねば評価不能。

### 2025年大罷免後の市民動能

130万人連署のエネルギーは罷免終了日に消滅しない。連署スタンド経験、街頭動員ネットワーク、跨組織協作プラットフォーム、SNS伝播鎖 — これらは市民社会の固定資本、2026年に異形で再出現。新市民団体、新選挙監督プラットフォーム、新議題提唱組織の可能性。この市民動能が政党競争とどう交織するか、2026年観察のもう一つの主線だ。

### 第三勢力の拡張試練

民衆党は2024年立委選で8不分区議席獲得、国会キャスティングボートに。2026年はこの第三勢力が「立院キー第三党」として初の地方選挑戦 — 過去民衆党の地方組織基盤は相対的に脆弱、2026年は中央レベル支持度を地方議席に転化できるかの重要試金石だ。

## 五、22県市の構造的議題

選挙は県市で起きるが、県市の政治版図は2026年に形成されたものではない。各県市は独自の派系構造、産業歴史、族群構成、地理的張力を持つ — これら構造が選挙の母題と張力場を決定し、候補者は表層、構造は底層だ。

**六都**共通議題：人口流動（非都会区から持続吸収）、都市治理（交通、住宅、大気汚染、ゴミ、長期介護）、産業転換（製造業からサービス業、伝統サービスからAI時代）。だが六都間の張力場は大きく異なる — 台北の房価と居住正義、新北の衛星都市治理、桃園の航空城と大型開発、台中の紅黒派系と中科拡張、台南の歴史保存と観光、高雄の石化転換と港都再生。

**16県（市）**の議題はよりローカル化：

- **新竹（県、市）** — 科学園区人口外溢、原住民族文化保存、客家庄と閩南聚落の政治版図差異
- **苗栗** — 鉱業から観光への産業転換、客家政治構造、人口流出
- **彰化** — 西部走廊老朽化議題、農業政治、海岸工業区（風力発電等）開発争議
- **南投** — 山地観光、921災後再建継続、原住民族部落自治
- **雲林** — 農業政治の派系構造（張家政治が省議会から延伸至今）、大気汚染、台塑六輕
- **嘉義（県、市）** — 高齢化社会、農業精緻化、阿里山観光と原住民部落
- **屏東** — 農漁業政治、原住民族議題、墾丁観光と環境
- **宜蘭** — 観光業飽和、移住人口、雪山トンネル後の双城効果
- **花蓮** — 地方派系と原民部落政治の二重構造、東部交通建設争議、地震後再建
- **台東** — 観光業閑散期、原民部落自治、周遊クルーズと環境
- **澎湖** — 観光業季節性、賭博住民投票歴史、人口流失
- **金門** — 両岸関係（小三通、軍事張力上下）、戦地政務転換後のアイデンティティ議題
- **連江（馬祖）** — 両岸関係、深刻な人口流出、馬祖列島群島治理
- **基隆** — 港務転換、衛星都市定位、北北基交通統合

各県市に固有の議題重力場がある。選挙結果はこの重力場のある瞬間のスナップショット、無から生じた結果ではない。

## 六、9職位の歴史的意義

「九合一」は単に9選挙を同日にまとめたように見えるが、各職位はそれぞれ制度史を持つ。

### 直轄市長：六都布陣安定後の4回目

直轄市長職は1967年北市昇格で誕生、1979年高雄昇格で拡大、2010年五都昇格で倍増、2014年桃園昇格で今日の六都布陣完成[^14]。2026年は六都布陣安定後4回目の同期改選 — 制度は安定期入りだが、有権者の六都への期待と16県（市）への期待は構造的に異なる：六都は「準中央レベル」と見なされ、候補者自体が2028年大選の潜在人選と見なされることが多い。

### 県市長：16非直轄市の政治版図

16非直轄市の県（市）長 — この数は1950年地方自治実施初期に大枠確定[^15]。2010年五都昇格調整を除けば、16県（市）の政治版図は半世紀以上大きな変化なし。この16職位の選挙結果は、六都よりむしろ台湾草の根政治の実態構造を反映することが多い — 地方派系、宗親脈絡、産業利益、宗教ネットワーク。

### 議員：複数選挙区単記非移譲制の継続

議員制度は立委と異なる。立法委員は2008年単一選挙区二票制（区域+不分区）に改革したが、県（市）議員・直轄市議員は今も**複数選挙区単記非移譲（SNTV）**制 — 1選挙区で複数当選、有権者は1票のみ、得票高い順に当選[^16]。SNTVは1992年定型の旧制度、立委は改革済みだが議員制度は追随せず。

この制度設計は候補者の「同党競争」を誘発 — 同党候補が同一選挙区で互いに票を奪い合う。有権者にとって独特の投票戦略生成：政党内で最も落選リスク高い「周縁候補」に票を投じるべきか？ これが議員選挙が総統・立委選と全く異なる感覚になる理由だ。

詳細：[[議員制度]]

### 村里長：台湾最基層の民選首長

全台7,748村（里）長 — 7-Elevenの6,600店舗より多い。この職位の歴史は日本統治時代の保甲制度に遡り、戦後直接改名継承[^17]。村里長は台湾選挙で**唯一無所属候補が優勢**な職位 — 派系と個人関係が政党より重要。

村里長選挙結果は全国メディアにほぼ登場しないが、台湾公共サービスの最基層接点だ。独居高齢者ケア、ゴミ収集車ルート争議、コミュニティ活動センター管理、隣里紛争調停、敬老金支給、政府情報伝達 — これら日常治理はすべて村里長の手にある。

詳細：[[村里長制度]]

### 原住民族区長：昇格で自治権犠牲にしない制度的応答

直轄市山地原住民区長は2014年桃園昇格時に新設された職位[^18]。元々山地郷の郷長民選地位は直轄市昇格で剥奪される（昇格後郷鎮は派任区長になるため）、原住民族自治権が都市改制で呑み込まれないよう、立法院が『地方制度法』修正案通過、この職位を新設 — 直轄市山地原住民区は依然自治選挙を維持。これは台湾が「昇格で原住民族自治を犠牲にしない」と応答した制度だ。

現在6直轄市山地原住民区（新北烏来、桃園復興、台中和平、高雄那瑪夏、高雄桃源、高雄茂林）が区長・区民代表選出。50区民代表定数は多くないが、この制度の存在自体が議席数以上に重要 — 台湾多民族民主主義構造の約束を体現している。

詳細：[[直轄市山地原住民區長]]

## 九、選戦はどこまで進んだか：已発生と将発生

2026年7月中旬時点から振り返ると、投票日まで残り4ヶ月強。選戦の骨格は大枠形成済みだ。

### 已発生：制度層の3つの新変数

**住民投票が大選に再結合の可能性**。2025年11月立法院三読で『住民投票法』第23条修正、「住民投票大選結合」復活 — 公告成立の住民投票案が3〜6ヶ月以内に全国性選挙と遭遇すれば同日投票[^34]。在野党が反廃死、鞭刑、核三再稼働、国内移転投票等5〜6住民投票提案を11月28日に結合狙うが、7月時点で全て「逕付二読交付協商」停滞、8月通過でなければ間に合わない。しかも前例が警告：2025年5月立法院通過の反廃死住民投票、中選会が『住民投票法』不適合と認定し実施困難[^35]。有権者が11月に受け取るのは9枚か9+N枚か、8月に答えが出る。

**原住民選挙人が移転投票可能に**。2025年12月立法院三読で『選罷法』修正、原住民選挙人投票が戸籍地制限を受けなくなり、2026年1月公布 — 台湾不在籍投票の最初の実質的突破口だが、汎用版『不在籍投票法』は未だ三読未了[^36]。中選会が公聴会で推算：選挙区×投票用紙種類組み合わせで全国**8,896種類**の異なる選挙用紙出現 — 移転投票の選務複雑度は、選務機関が倉促上路を最も懸念する点[^36]。

**立候補資格の門檻が直近改正**。2026年6月立法院三読で『選罷法』第26条修正、緩刑または易服社会労働宣告受けた者も立候補登記可能、7月1日公布施行[^37]。メディアが「高虹安条項」と呼ぶこの修正、登記日8週間前に立候補資格の法的ラインを書き換え — 支持派は無罪推定への回帰と称し、批判派は個案立法と疑う。直接的に誰が投票用紙に名を連ねられるかへ影響する。

### 已発生：提名版図大枠確定

三大党の提名作業は7月で大詰め：民進党は22県市中19提名済み、国民党は苦戦区・交棒区提名完了、現職執政者の徴召は7月下旬中常会で一括処理予定、民衆党徴召3人選のうち2人が藍白整合民調後に輔選転任[^38]。22県市中13市で現職が任期満了や法的制限で投票用紙に現れない — 大幅な世代交代選挙だ。藍白協力機制の実運転記録は上記[第四節](#四内部構造的議題朝小野大藍白協作第三勢力)参照。

Taiwan.mdは対称原則により本文で候補者名簿列記せず — 完全名簿は中選会11月公告準拠、選前提名動態は主流メディア整理と[中選会公告](https://web.cec.gov.tw/)参照。

### 将発生：法定日程上の6節点

**2026/08/20 中選会選挙公告発布** — 選務正式開始、投票時間・應選定数・住民投票同日可否がこの日全て確定。1年余りの「推測フェーズ」が法定手続きへ移行。

**2026/08/31-09/04 候補者登記** — 最終候補者名簿浮上。政党提名、整合協議、無所属出馬 — 全選前角力の結果がこの5日で明らかに。登記しなければこの日から戦場に立てない。

**2026/10/16前審定 + 2026/10/23 抽籤** — 番号抽籤で投票用紙上の並び順決定。台湾選挙文化における番号の微妙な影響（特に1番の「先発効果」）が一部有権者に影響する可能性。

**2026/11/18以降 — 選前10日世論調査禁令** — 『選罷法』規定で投票日前10日から、誰もいかなる方式でも世論調査資料公表不可[^39]。

**2026/10/29 → 11/28 — 選前30日**：

- Taiwan.md candidate-specific孢子freeze発動（自主規律、法定世論調査禁令より厳格）
- 検調選挙取締り最高戒備期
- 認知戦予想ピーク期（per OpenAI / DoubleThink Lab分析）

**2026/11/28 投票日** — 投票時間は選挙公告準拠（歴代慣例午前8時〜午後4時）、投票終了即開票。台湾選挙の開票伝統は「速いが雑ではない」 — 歴代経験では当夜主要結果統計完了、12月4日当選者名簿公告。

**2026/12以降** — 開票結果後の政治解釈戦場。具体的得票数の勝敗を超えて、2024年朝小野大構図がどう継続・再編されるか、2028年大選の版図予測、藍白協力の後続展開 — これら「選後ナラティブ」は選挙結果自体より重要かもしれない。

## 結び

2026年11月28日土曜日朝、台湾全土22県市が同時に投票所を開く。その瞬間から、台湾有権者は1日でこの世界でも稀な「9職位同日投票」民主主義儀式を完遂する。

だがこの儀式の真のストレステストは当日にない — 選前の毎日、AI認知戦エスカレート環境下で、朝小野大の政治対立の中で、市民監督ツールと政府オープンデータの接合部で、真偽判別困難な情報流の中で。
