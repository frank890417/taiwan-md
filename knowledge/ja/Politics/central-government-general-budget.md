# 中央政府総予算：3兆元どう配分し、立法院はどこを削ったか

> **30秒概観：** 114年度中央政府総予算は3兆1,325億元で編列され、2025年1月21日に三読成立、2,075億元の減額により歳出が2兆9,248億元となり、削減額は史上最高となった。115年度は3兆349億元で編列され、2026年8月14日にようやく三読成立、480億元の減額となったが、これは史上最も遅い総予算成立である。同一年度の国防経費が、異なる視点で9,495億元とも6,973億元とも報じられる。予算数字を読む前に、それがどの問いに答える数字かを確認する必要がある。

---

## 3兆元の配分表

行政院主計総処が2025年8月21日の行政院会議で示した115年度中央政府総予算案の説明資料によると、歳出は3兆350億元（30,350億元）で編列され、114年度比で1,100億元増、増加率約3.8%。114年度の追加予算を含めると、増加は222億円にとどまり、約0.7%となる。[^3]

約1年にわたる審査を経て、立法院は2026年8月14日夜に三読を行い、当初の歳出総額3兆349億7,437万元から480億元を減額し、歳出を暫定的に2兆9,869億7,437万元とした。[^2]

立法院長の韓国瑜（ハン・グオユー）氏は三読後、この予算が266日遅れたと述べた。[^2] 中央社の報道では、これは中華民国史上最も遅く成立した総予算とされている。[^2]

## 3つの数字：編列・法定・決算

114年度を例にとると、1つの予算には少なくとも3つの数字がある。

第1は行政院編列数：歳出3兆1,325億元、歳入3兆1,534億元、ともに過去最高。[^1]

第2は立法院三読後の法定数：2,075億7,425万元を減額し、歳出は2兆9,248億元に低下。削減額は史上最高、削減率は約6.6%。[^1]

第3は決算数。行政院主計総処の114年度中央政府総決算報告によると、歳入3兆1,776億元、歳出2兆9,340億元、歳出は予算数より729億元少ない。[^4]

ここには混同しやすい点がある。決算報告の比較表における「予算数」欄は30,069億元となっており、立法院三読の29,248億元とは異なる。どちらも公式の数字だが、答えている問いが違う：一方は立法院が可決した法定予算、もう一方は決算報告が比較基準として用いた数字である。本文では調和を図らないが、一点だけ注意を促す：予算数字を引用する前に、それがどの問いに対する数字かを確認すること。

## どこに多く流れたか

114年度決算の政策別支出を見ると、資金が主にどこへ行ったかが分かる。[^4]

| 政策別             | 決算数（億元） |
| ------------------ | -------------- |
| 社会福祉           | 8,184          |
| 教育科学文化       | 5,864          |
| 国防               | 4,627          |
| 経済発展           | 4,300          |
| 一般政務           | 2,605          |
| 退休撫卹           | 1,759          |
| 補助及其他         | 857            |
| 債務               | 848            |
| 社会発展及環境保護 | 296            |
| **合計**           | **29,340**     |

社会福祉が最大、次いで教育科学文化、国防が第3位。この表は決算数であり予算数ではないため、「最終的にどこに使われたか」を示すもので、「当初いくら編列されたか」を示すものではない。

表中の国防4,627億元は114年度決算の政策別分類である。次節で述べる2つの国防数字は115年度予算であり、年度も算出方法も異なるため、これら3つの数字を直接比較することはできない。

## 国防の2つの数字

115年度国防経費は行政院の説明資料において総額9,495億元、GDP比3.32%とされている。[^3]

この数字は単一科目ではない。4つの要素で構成される：公務予算8,841億元（うち総予算6,973億元、特別予算1,868億元）に加え、非営業特種基金654億元。資料には、この視点が「北大西洋条約機構（NATO）基準を参酌し、退輔会の退除役軍人退休給付と海巡署支出を含めたもの」と注記されている。[^3]

したがって、同年の国防費を9,495億元（特別予算・退輔会・海巡署含む）と報じることも、6,973億元（総予算のみ）と報じることも可能である。両方とも正しいが、「何を『国防』に含めるか」が異なる。

これは言葉遊びではない。国際比較では前者の視点が常用される。NATO加盟国がそう算出しているからである。一方、予算審査では後者が常用される。立法院が審査するのは総予算内の科目だからである。双方が異なる数字を持ち出し、共通の視点で対話しないまま議論が平行線になることが多い。

## 立法院はどこを削ったか

114年度の削減率は6.6%と、過去の年を大きく上回った。中央社の報道によると、具体的な項目として：通案による水道光熱費一律10%削減、特別費一律60%削減（行政院、大陸委員会、原住民族委員会、内政部等複数機関の特別費全額削除）、軍事装備及設備一律3%削減、メディア政策及業務宣導費一律60%削減、さらに経済部が台電（台湾電力公司）へ注資する1,000億2万元を全額減額。[^1]

115年度の削減率は1.58%（480億元）に戻ったが、削減項目は依然として集中している。三読で可決された通案には、首長特別費一律60%削減、軍事装備及設備一律2.5%削減、メディア政策及業務宣導費一律50%削減が含まれる。[^2]

文化部のメディア宣伝費はこの2年間の常設戦場となっている。115年度は4,738万元編列されたが、立法院教育及文化委員会が2026年7月2日に審査した際、中国国民党の翁曉玲（ウォン・シャオリン）委員が全額削除を提案し、過去に特定メディアへ流れた疑義があると指摘。台湾民衆党の蔡春綢（ツァイ・チュンチョウ）委員は減額を要求し、民主進歩党委員は削除に反対。文化部長の李遠（リー・ユエン）氏は、114年度のメディア宣伝費がゼロに削られたことを述べ、「決して特定メディアへの補助ではない」と強調。委員会段階では召集委員の羅廷瑋（ルオ・ティンウェイ）氏が800万元の凍結を裁定し、文化部が書面報告を提出し委員の同意を得てから動支可能とした。[^5]

8月14日の総予算三読では、文化部メディア宣伝費が2年連続で全額削除され、委員会段階での800万元凍結は最終結果とはならなかった。[^6]

## 予算は使い切られたか

決算報告のもう一つの機能は、「予算が執行し切られたか」を答えることである。[^4]

114年度歳出決算は2兆9,340億元、決算報告掲載の予算数3兆69億元（30,069億元）と比較すると729億元少なく、執行率は約97.6%。歳入決算は3兆1,776億元で、予算数より126億元多い。両者を相殺すると、歳入歳出剰余は2,436億元となり、予算数の1,581億元より855億元多い。

この数字群が示すのは：予算が削られたからといって必ずしも支出が少なくなるわけではなく、予算が多く編列されたからといって必ずしも使い切られるわけでもないということ。削減は審査段階で起こり、執行率は決算段階で生じる。両者は別の問題である。

## 4つの視点、4種類の問い

以上を整理すると、中央政府総予算を読むには最低限4つの視点を区別する必要がある。

編列数は「行政院はどれだけ欲しいか」を問い、法定数は「立法院はどれだけ認めるか」を問い、決算数は「最終的にいくら使ったか」を問い、特別予算は「総予算に含まれない資金は何か」を問う。4つの数字はいずれも「3兆」たり得るが、どれも単独では「政府は使いすぎか、使い足りないか」には答えられない。

これが毎年の予算ニュースが噛み合わない理由の一つである：一方は9,495億元の国防費を出し、もう一方は6,973億元の国防費を出し、双方とも間違ってはいないが、誰も共通の視点で対話していない。
