2026年5月17日、最後の試験科目の終了を告げる鐘が鳴り、台湾全土の中学3年生たちはその日の午後、2日間にわたる国中教育会考（以下「会考」）を終えた。成績は6月5日に発送され、台湾師範大学心理与教育測験研究発展センター（心測中心）が同時に統計を発表した。全国で16,293人が5科目すべてでA評定（5A）に達し、受験者全体の9.04%を占めた。最も人数の多い組み合わせは5B（5科目すべてB評定）で、40,598人、22.53%にのぼった。[^4]

この成績表の最も直感に反する点は、数値による点数をほとんど示さないことにある。受験生が受け取るのは5科目それぞれの「精熟（A）、基礎（B）、要強化（C）」という評定と、作文1本分の6段階評点だけで、総点もパーセンタイルも、全体順位も存在しない。[^2] 台湾最大規模のこの全国筆記試験は、比較するうえで最も便利なあの数字を、わざと取り除いているのだ。

さらに、その法的な身分はもっと知られていない。会考の身分は、「国民小学及国民中学学生学習評量辦法」に基づいて実施される**学力検定**のための仕組みであり、進学への使い道はあくまで各学区が後から積み上げてきた比序規則によるものにすぎない。[^2]

## 一、2つの半日、5科目と1本の作文

116年度（2027年）の会考は5月15日・16日に実施される予定で、土曜日は午後4時過ぎまで、日曜日は午前中で終わる。[^1][^3] 1日目の午前は社会と数学、午後は国語と作文試験の順。2日目の午前は自然科学、続いて英語読解と英語リスニングが行われる。休憩時間もかなり細かく決められており、社会の後には40分間の休みがあり、正午には1時間50分の昼休みが取られる。[^1]

| 科目       | 試験時間 | 問題数      | 問題形式                              |
| ---------- | -------- | ----------- | -------------------------------------- |
| 国語       | 70分     | 38〜46問   | 4択式                                  |
| 英語読解   | 60分     | 40〜45問   | 4択式                                  |
| 英語リスニング | 25分 | 20〜30問   | 3択式、2回放送                         |
| 数学       | 80分     | 25〜30問   | 選択23〜28問＋非選択2問                |
| 社会       | 70分     | 50〜60問   | 4択式                                  |
| 自然科学   | 70分     | 45〜55問   | 4択式                                  |
| 作文試験   | 50分     | 1問        | 作文1本                                |

この表に示された科目と出題形式の組み合わせそのものが、出題者が中学3年間の学びをどう見ているかを物語っている。作文試験、英語リスニング、そして数学の非選択式問題を除けば、他のすべての科目は一律4択式である。つまり会考における解答行為の大部分は、4つの選択肢から1つを選ぶことに尽きる。[^1]

英語科目は読解とリスニングを2つの独立した冊子に分け、2段階に分けて実施する。リスニングは1問につき2回放送され、2回の間には数秒の間が置かれる。[^1] この設計の理由は公式Q&Aにこう記されている。読解だけを測るのであれば、試験結果は「生徒の部分的な英語力しか限定的に説明できず、評価としての妥当性が著しく不足する」からだという。[^1]

## 二、412点から三段階評定へ

会考以前、台湾の中学生が受けていたのは国民中学学生基本学力測験、通称「基測」だった。両者の違いは名前が変わっただけではない。基測は相対評価（常模参照）で採点され、5科目それぞれ最高80点、作文12点、総点は412点だった。会考は絶対評価（標準参照）に切り替えられ、成績は3段階の評定に分かれ、作文は1〜6段階の評点となった。[^2]

| 項目       | 国中教育会考                                                | 国中基測                                              |
| ---------- | ------------------------------------------------------------ | ------------------------------------------------------ |
| 法的根拠   | 国民小学及国民中学学生学習評量辦法                            | 高級中等学校多元入学招生辦法                            |
| 主な機能   | 学力検定、教育調整と個別指導のための資料                      | 多元入学ルートの判定材料                                |
| 実施時期   | 民国103年（2014年）より、毎年5月に1回                         | 民国90〜100年は年2回、101年より年1回に変更              |
| 出題範囲   | 103〜110年度は九年一貫課程、111年度以降は十二年国民基本教育課程 | 九年一貫課程の能力指標                                  |
| 難易度設定 | 中程度                                                        | やや易しい                                              |
| 採点方式   | 標準参照（絶対評価）                                          | 常模参照（相対評価）                                    |

会考は民国103年（2014年）に始まり、出題、冊子編成、採点、評点のすべてを台師大心測中心が担っている。全国の試務業務はもともと6つの直轄市政府が持ち回りで担当していたが、教育部は108年（2019年）7月17日、108年8月1日以降は台師大に業務を一括委託すると発表した。[^2]

この設計についての公式な説明は率直だ。成績の等級を3段階に減らすことで「試験によるプレッシャーを適度に下げる」一方、標準参照方式を用いることで学力モニタリングとしての機能を保つ、というのである。[^2] これは台湾の教育改革にたびたび現れる同じ緊張関係——「プレッシャーを下げて学びを活性化する」ことと「質を確保して競争力を維持する」ことの間でバランスを取ろうとする試み——の一例である。[^2]

## 三、5科目は一体何を問うているのか

会考の出題原則は公式文書に記されており、かなり抑制的な内容になっている。試験問題は生徒の学習経験と生活経験から取材し、紙筆試験で評価できる学習上の重点のみを出題対象とし、特定の教科書版本に依存しないことを求めている。つまりどの版元の教科書を使っていても、該当する能力を身につけていれば解答できるように作られている。[^1]

社会科の説明が、この方向性を最もよく表している。公式の説明によれば、試験は理解力を重視し、単純な記憶力を測る問題は少なく、グラフや図表資料を読み取り、翻訳する力に重点を置いているという。生徒の生活圏や時代に近いことに加え、ジェンダー平等、人権、環境、原住民族教育といったテーマも適度に組み込まれ、生徒が自分自身の社会やグローバルな課題に関心を持つよう導くことを目的としている。[^1]

自然科学は「学習表現」と「学習内容」の2層に分かれる。学習表現は科学的認知、探究能力、科学的態度と本質を含み、学習内容は自然界の構成と特性、現象の法則と働き、持続可能な発展という3つの大きなテーマをカバーする。問われているのは、生徒が概念を実際に使えるかどうかであり、単に用語を覚えているかどうかではない。[^1]

数学は選択式に加えて非選択式の問題がある唯一の科目で、2問の非選択式問題は加重後、数学の総得点のうち15%を占める。選択式と比べて非選択式の出題数が少ないのは、採点に時間がかかるためで、公式側も「今後の必要に応じて比重を段階的に調整する」可能性を残している。[^1]

これらの原則を合わせて見ると、会考は教科書1冊をすべて網羅的に試そうとはしていないことが分かる。課程綱要の第4学習段階における学習上の重点を問うものであり、出題者自身も、生徒が本当にその能力を習得していれば、どの版本の教材を使っていても解答に支障はないはずだと認めている。[^1]

## 四、標準参照：比べるのは閾値、隣の受験生ではない

標準参照とは、まず各分野の教授陣と中学校教師で構成されたチームが各等級の能力の閾値を設定し、そこから逆算して各等級に達するために何問正解すればよいかを決める方式である。受験生は閾値と比べられるのであって、同じ回の受験生同士で比べられるわけではない。[^1] 公式による3段階の定義も明確だ。精熟とは「その科目について中学教育段階で学ぶべき知識と能力を十分に習熟していること」、基礎とは「基本的な学力を備えていること」、要強化（原語：待加強）とは「まだそれを備えていないこと」を指す。[^1]

ただし、3段階では進学の現場にとって粗すぎるため、さらに細かい標示が追加された。精熟と基礎の2等級はそれぞれ半分に分けられ、正解数の多い上位25%には「++」、26〜50パーセンタイルには「+」が付く。これによりA++、A+、B++、B+という4種類の表記が生まれ、要強化（C）にはそうした標示は付かない。[^1]

具体的には、115年度（2026年）の閾値は次の通りだった。国語で精熟に達するには少なくとも36問の正解が必要で、A++の閾値は40問、つまり誤答は最大2問まで。社会の精熟閾値は48問、A++は52問。自然科学の精熟閾値は43問、A++は47問だった。[^5]

英語と数学は加重計算があるため、ルールが他の科目より複雑である。英語は読解を80%、リスニングを20%として加重スコアを計算し、読解で精熟に達するには38問の正解が必要。リスニングは基礎と要強化の2段階しかなく、基礎の閾値は13問。全体として精熟に達するには加重スコアが90.7点に達する必要があり、A++は98.14点となる。数学は選択式を85%、非選択式を15%として加重し、全体の精熟閾値は77.10点、A++の閾値は91.60点だった。[^5]

心測中心の副主任、曾芬蘭は当時、中央社の取材に対し、会考は毎年ほぼ同じ難易度で冊子を組んでいるため、各科目の閾値は年ごとに大きく変わらず、「だいたい1問多い・少ないという程度」だと語った。[^5] この言葉は、会考の閾値が年々発表されても大きく変動しない理由を説明していると同時に、1問多く間違えるだけで標示が1段階下がってしまう理由も説明している。

## 五、なぜA++はちょうど4分の1にならないのか

標示のルールには「上位25%」と書かれているが、実際に発表される比率がちょうど25%になることはほとんどない。公式Q&Aは115年度の自然科学を例に説明している。その年、精熟に達するには少なくとも43問の正解が必要で、31,473人がこれを満たした。理論上、A++の人数は7,869人になるはずだった。しかし48問以上正解した人は7,194人しかおらず、675人足りなかったため、A++の閾値は47問に下げられた。「正解数が同じ者は同じ標示であるべき」という公平性の原則に基づき、47問正解した4,356人全員がA++に含まれ、合計11,550人、精熟等級全体の36.70%にのぼった。[^1]

つまり、標示の付け方はまず等級を区切り、その後に正解数の分布を見ながら比率を調整し、きれいに揃わない場合は比率がずれることを許容する、というものだ。この技術的な詳細はニュース報道にはほとんど書かれないが、少なくない受験生が最終的にA++を得るかA+になるかを左右している。

## 六、進学の現場：会考は比序のなかのひと枠にすぎない

会考の本当のプレッシャーの源は、試験そのものではなく、免試入学における超額比序（定員超過時の順位づけ）にある。教育部が定めた遵守事項では、会考を採用するかどうかは「各学区が地域の事情に応じて決める」とされているが、**唯一の判定項目にしてはならず**、他の比序項目と組み合わせて全体的に計画しなければならない。会考の総合標示（総積点）を採用する場合は、その順位は多元学習表現の総得点の後に置かれ、かつ会考の各科目別標示による比序より前に置かなければならない。[^6]

つまり制度設計上、会考は意図的に「多元学習表現」の後ろに置かれており、各学区もそれを一要素としてしか扱うことを許されていない。しかし、その一要素がどれほどの重みを持つかは、各学区が自分で決める。2026年5月の会考終了後、補習業界は基北区（台北・新北・基隆エリア）の比序規則に基づいて、建国高級中学の合格ラインを約34.6点、台北第一女子高級中学を約33.6点と推計した。[^8] こうした推計が成り立つこと自体が、その学区では会考の標示を積点に換算した段階で、実質的に大きな順位づけの機能を担っていることを物語っている。

成績全体の分布も、進学のプレッシャーが実際にはどこにかかっているかを示している。115年度は5Aが9.04%、5Bは最も人数の多いグループ（22.53%）だった。[^4] 「全部B」というその中間の大きな一塊の生徒たちは、名門高校をめぐる議論にも、要強化のための補習教育の議論にも入ってこない。

## 七、作文1本、ゼロ段階から6段階まで

作文試験は、会考で唯一選択式問題がなく、決まった題材も用意されていない科目である。115年度の題は「物事に新しい顔を与える」というもので、題本には3つの例が示された。学園祭で貨幣の代わりに物々交換を行う、古びた壁のタイルをコースターに作り直す、豊作になったバナナを加工して新しい製品にする、というものだ。受験生は自分自身の経験や見聞を結びつけ、自分が何に新しい姿を与えたいかを書くことが求められた。[^9]

この年、6段階の最高評点を得たのは1,262人、0.71%で、直近3年間で最も高い割合だった。心測中心副主任の曾芬蘭は、4段階以上に達すれば108課綱が求める基準を満たすことになり、今年は受験生の78%がこの基準に達したと述べた。[^9] その一方で、2,187人がゼロ段階の評点となり、1.23%を占めた。これは前年の753人から大きく増加している。採点担当であり文藻外語大学の教師でもある林雪鈴は、こうした受験生の多くは題本に示された3つの例をそのまま書き写すか言い換えるだけで、題意が求める自分自身の経験や感想を書いていなかったと分析した。[^9]

心測中心は毎年、サンプル答案を公表しており、ある意味で「模範解答」の代わりとなっている。115年度に選ばれたサンプル答案の1つでは、脳性麻痺のために子どものころから矯正靴を何度も履き替えてきた生徒が、大人になって倉庫の中で古びて臭いを放つその靴を見つけ、最初は捨てようと思ったものの、結局は1つずつ丁寧に洗って並べ、自分の努力の栄光の証とした様子が書かれていた。もう1つのサンプル答案は、父親と一緒に使い捨て箸を改造して諸葛連弩（連射式の弓）を作り、見事発射に成功した瞬間、子どものころの記憶がどっと押し寄せてきた様子を描いていた。[^9]

作文の評点はわずか6段階しかなく、5科目の3段階評定より細かく見えるが、実際にはもっと粗いものだ。「自分自身の経験に基づいて構成の整った文章を書けるかどうか」という能力を、1つの数字に圧縮してしまっているからだ。それでも、この項目こそが成績表全体の中で唯一、受験生個人の物語が見える場所として残っている。

## 八、誰が「要強化」に留め置かれるのか

会考のそもそもの目的は学力モニタリングであり、だからこそ「要強化」の比率はずっとこの試験のもっとも誠実な成績表だった。104年度（2015年）の会考には285,295人の受験生がいたが、台師大教育心理与輔導学系准教授の李俊仁は、国家教育研究院（TERIC）に掲載された論評で、その年の数学の要強化率は33%に達し、数学の非選択式問題では35.8%がゼロ点だったと指摘している。彼は「選択式は4択の答えだ」とはっきり述べ、緩やかな基準で見ても、25問中6問以下しか正解できないのはほぼ完全な当て推量に等しいとした。[^7]

英語リスニングの公平性についても、毎年おなじみの論争の種となっている。公式Q&Aは「へき地の生徒にとって不公平ではないか」という問いに丸ごと1セクションを割いて答えている。その理由として、課程綱要がもともと聞く・話す・読む・書くを同等に重視することを求めていること、教育部が検定承認した英語教材にはすべてリスニングCDが付属していること、そして過去の会考で使用されたリスニング再生機器は各中学校に移管されていることなどが挙げられている。[^1] この答弁が成り立つかどうかは、統計数字には絶対に記されない1つの事実、つまりそれらの再生機器が実際にスイッチを入れられていたかどうかにかかっている。

## 九、会考のあと

116年度（2027年）会考の日程はすでに公告されており、5月15日・16日の2日間の試験が終わった後は、免試入学のための志望校選択と合否発表が続く。[^1] 受験生とその保護者にとって、成績表以外に理解しておくべきことが3つある。自分が属する学区の比序規則がどう計算されるのか、各校の前年の合格ラインがどのあたりにあったのか、そして自分のその学区では会考の成績がどれほどの重みを持つのか、である。

会考は中学の授業が反復練習だけに終わらないよう、点数を隠している。しかし超額比序という仕組みが存在する限り、隠されたはずの点数は別の形で再び育ち、A++や積算ポイント、合格ライン予想として戻ってくる。制度の運用自体が間違っているわけではない。「プレッシャーを下げる」ことと「競争力を維持する」こと、この2つの目標はもともと、同時には一部分しか達成できないものなのだ。
