> **30秒概要**：エネルギー貧困は単に「電気を多く使っている」か「節電をしない」という問題ではない。安全で負担可能かつ効率的なエネルギーサービスを得るための十分な資源を家庭が持っていないからだ。古いアパート、屋上の増築、換気の悪い部屋に住む家庭、または効率の低い中古エアコンを使用する家庭にとっては、エアコンをつけることは請求書の負担になり、つけないことは熱傷害のリスクを高める。台湾には全国的に一致したエネルギー貧困の定義が欠如しているが、民間調査では支援を受ける弱者家庭のエネルギー支出が可処分所得の明らかに高い割合を占めていることが判明している。[^1] 高温が政府によって部門を超えたリスクとして認識されるようになれば、エネルギー貧困は節電宣伝を超えて、住宅、社会福祉、衛生、気候調適の各分野で共同に取り組む公共の問題とならなければならない。[^2]

# エネルギー貧困は「節約ができない」問題ではない

エネルギー貧困は家庭が節電習慣を欠いていると誤解されやすい。エアコンを少し使わない、お湯を節約する、電気を消す習慣を身につければ請求書は下がる。しかし、このような説明は家庭が本当に選択できる範囲を無視している。隔熱性能が良く、日除けが施された窓、高効率のエアコンが設置された住宅に住む家庭と、西日が直接入り、漏水が発生し、換気が悪く、古い家電を使用する住宅に住む家庭では、室温が同じであってもエネルギー需要は異なる。

したがって、エネルギー貧困は少なくとも3つのレベルを含んでいる。第一は**支払能力**である。エネルギー請求書が所得の一定割合を超えると、家庭は食費、医療費、交通費、電気代の間で取捨選択を弫せなければならない。第二は**エネルギーサービスの品質**である。家庭が請求書を支払うことができたとしても、過熱したり、過冷したり、湿気が多い、換気の悪い空間に住んでいる可能性がある。第三は**アクセス能力**である。賃貸住宅者、一人暮らしの高齢者、身体障がい者、または前金のない家庭は、エアコンの交換、窓の改善、複雑な補助金の申請を自分で行うことができない可能性がある。

台湾青年気候連盟がまとめた過去の研究によると、台湾には公認されたエネルギー貧困の定義が存在しないことが指摘されている。工研院と家扶の協力調査を引用すると、支援を受ける弱者家庭のエネルギー支出は可支配所得の平均で18%に達する可能性がある。この数字を全国人口の比率に直接外挿してはならないが、この数字は我々に警鐘を鳴らしている。電気の総使用量で家庭が節電しているかどうかを判断すると、「住宅と設備が悪すぎて高額な支出を余儀なくされる」家庭を「浪費者」と誤認する可能性がある。[^1] 国立台湾大学の研究も、エネルギー負担を居住条件と弱者家庭の相互関係の中で理解している。個人の消費選択だけで問題を归咎してはならない。[^8]

# なぜ夏のエネルギー貧困が特に危険なのか

エネルギー貧困について論じる際、政策と研究は冬の暖房を主な想像対象としてきた。台湾は別種の季節的リスクに直面している。夏の高温だ。弱者家庭は「エネルギー需要がない」のではなく、「需要があるが使用することが怖い」状況にある。室温が上昇すると、家庭はエアコンの使用時間を短縮したり、エアコンの温度設定を高くしたり、子供や高齢者だけがエアコンのある部屋に入るようになる。これらはすべて請求書の負担の下での適応行動であり、単なる消費嗜好ではない。

国民健康局は明確に警告している。室内空気が循環せず、熱が排出できない場合、室内でも熱傷害が発生する可能性がある。高齢者と子供は体温調節能力が弱く、特に室内の高温に注意する必要がある。公式の推奨事項では、定期的に水分補給をし、換気を保ち、エアコンを使用する際は温度を26〜27°Cに設定することが推奨されている。[^3] このような推奨は、エアコンがあり、適切に換気が可能で、電気代を支払う能力のある家庭にとっては比較的容易に実践できるが、屋上に住んでいる家庭、鉄板の増築をしている家庭、窓を開けることができない家庭にとっては、建築と設備の投資がなければ本当に実践することはできない。

高温リスクは累積的である。建物は昼間に熱を吸収し、夜間に放熱できない場合、高齢者は睡眠中に高温にさらされ続ける。エアコンのフィルターが詰まっていたり、室外機の放熱が悪い場合、同じ冷却効果を得るにはより多くの電力が必要になる。つまり、「熱安全」はある一時の気温で測定できるものではなく、建物が一日の間にどのように熱を吸収し、蓄積し、放散するかを見る必要がある。

# 古い住宅はどのようにして高温を高請求書に変えるのか

古い住宅のエネルギー問題は通常、単一の設備によるものではない。壁面と屋上の隔熱性能が不足すると、エアコンの負荷が増える。日除けが施されていない窓では、西日の熱が直接室内に侵入する。古いエアコンは効率が低く、起動しても一定の冷却効果を発揮できない。フィルターと室外機が長期間清掃されていないと、設備の消費電力と故障リスクが増加する。家庭に前金がなければ、高額な運転コストを継続的に支払わなければならないが、そのコストの根本的な原因を改善する能力はない。

エネルギー貧困は住宅権、賃貸権、建築治理と密接に関連している。建物の所有者は窓の交換、日除けの追加、外壁の改善を決定できる。賃貸住宅者は、改造費用を回収できないことを心配するだけでなく、施工の権限もない可能性がある。補助金が設備の購入者だけに与えられると、最も改善が必要な家庭、建物の決定権を持たない家庭を排除してしまう可能性がある。

宜蘭県は住宅節電・居家隔熱改造補助を推進したことがある。日除け、隔熱ガラス、屋上と外壁の隔熱を補助対象に含め、地方政府が既に住宅外殻を節電と冷却の一部としていることを示している。この計画は過去の年度の計画であり、現行の全国政策として直接評価してはならないが、重要な方向性を提供している。熱快適性の改善は、必ずしも大きなエアコンを購入することから始まる必要はない。建物の吸熱を減らすことから始めることもできる。[^4]

# 補助金が必ずしもアクセス可能になるとは限らない

中央と地方は近年、家電のリプレース、住宅の節電、隔熱補助を提供してきた。政策の設計は通常、有限の予算で節電、脱炭素、家庭支出の削減を実現することを目指している。しかし、「資格を満たす」ことと「申請を完了できる」ことの間にはギャップが存在する。

経済部エネルギー局の住宅家電補助申請ページを例にすると、申請人は身分証明書、通帳、電気請求書または使用証明書、レシート、保証カード、廃棄家電回収連票を準備する必要がある。補助金は年度予算と審査条件によって制限される。[^5] 銀行口座が安定しており、新しい機器の費用を前払いでき、必要な書類を保存できる人にとっては、これは処理可能な手続きである。前金がなく、家電は所有者が所有しており、社会福祉士や親しい知人と一緒に生活している人にとっては、実質的な障壁となる可能性がある。

2026年の台北市住宅地域新エネルギー蓄電および節電補助は、比較的包括的な地域的事例を提供している。地域新エネルギー、蓄電、ガラス隔熱膜に加え、低所得世帯に対して1級エネルギー効率の冷蔵庫とエアコンのリプレースを補助している。上限を設定していることから、地方政府は既に弱者家庭の設備効率をネット・ゼロと公正な転換の一部としていることがわかる。[^6] しかし、このような計画では3つの問題を解決する必要がある。補助金は賃貸住宅者をカバーするか、設置と撤去の費用を支払えるか、計画の予算が満たされるか、または期限が切れると、次回の支援はいつ来るのか。

桃園市の高温感受性者向け冷却・節電補助は、0〜6歳の幼稚園児と65歳以上の高齢者を対象に、エアコンの清掃、ガラス隔熱膜、古いエアコンのリプレースを補助している。このような政策の意義は、低所得基準だけで需要を判断するのではなく、年齢と高温感受性を使用して、見逃されている家庭を見つけ出そうとしていることにある。[^7] しかし、福祉の断絶を避けるには、年齢、所得、住宅条件、健康リスクが社会福祉と衛生システムの間で適切に連携できるようにする必要がある。家庭が自分が助けを受ける資格があることを証明するために何度も証明しなければならない。

# 節電宣伝から居住熱安全へ

従来の節電宣伝の核心メッセージは「少し使う」ことである。エネルギー貧困政策は、別の問題を追加しなければならない。「どのようにすれば、より少ないエネルギーで十分な安全と快適さを得られるのか？」これらは矛盾するものではないが、政策ツールは異なる。

| 政策レベル | 従来の節電方法                                   | 居住熱安全方法                                                       |
| ---------- | ------------------------------------------------ | -------------------------------------------------------------------- |
| 設備       | 電気を消すことを勧める、エアコンの温度を高くする | 高消費電力エアコンのリプレース、フィルターの清掃、室外機の放熱改善   |
| 建築       | 日除けと換気を宣伝する                           | 窓の日除け、隔熱フィルム、屋上と外壁の隔熱を補助する                 |
| 社会福祉   | 低所得基準で補助金を配布する                     | ソーシャルワーカー、保健所、地域が高温リスクの家庭を積極的に特定する |
| 情報       | 節電知識を提供する                               | 簡略化された申請、訪問エネルギー診断、使用電気の改善提案を提供する   |
| 評価       | 何kWh節約したかを計算する                        | 熱傷害、室温、請求書の負担、生活の質を同時に測定する                 |

最初の転換は**事後補助から前工程診断へ**である。ソーシャルワーカー、地域事務所、居宅サービス員、保健所の人員は、訪問時に住宅が屋上であるか、西日が直接入るか、換気ができないか、エアコンが故障しているか、家電が古いかを記録できる。これらのデータはラベリングのために使用されるべきではなく、エネルギー診断と改善の順序を決定するために使用されるべきである。

二番目の転換は**個別設備から住宅と地域の規模へ**である。高効率のエアコン1台で使用電気を削減できるが、建物全体の屋上の吸熱、公共エリアの蒸熱、電力容量不足を解決することはできない。地域が遮陽、屋上、エレベーター、公共使用電力を共同で改善すれば、家庭が自分で投資するよりも効率的かもしれない。

第三の転換は**高温を災害と健康治理に組み込む**である。環境省は2025年に初めて「抗高温調適対策演習」を試行した。2日間連続で38°Cを超えるシナリオ、赤信号警告を発信するシナリオを想定し、中央各省と地方政府が重点人口のケア、民生エネルギー、地域調適を共同で処理する。[^2] この演習は、高温がまだ《災害予防法》の自然災害の範疇に完全には含まれていないことを指摘している。制度は明確化されなければならない。いつ起動するのか、誰が一人暮らしの高齢者に連絡するのか、どの場所が冷却拠点になるのか、停電時にこれらのサービスを維持する方法は何か。

# エネルギー転換で最も弱い者に費用を転嫁してはならない

エネルギー転換は脱炭素、電力供給の安定、産業競争力で測定されることが多い。しかし、低所得家庭が電気代、設備、住宅条件によって基本的な熱安全を維持できない場合、転換は新しい不平等を生み出す可能性がある。これは節電やエネルギー効率の向上に反対することではなく、政策が同時に「誰が最初に改善を受けるのか」と「誰が転換のコストを負うのか」という問題に答える必要がある。

台湾青年気候連盟がまとめたエネルギー貧困の議論は、政策は客観的指標と主観的指標を組み合わせる必要があることを指摘している。電気代の割合や総使用量だけで判断してはならない。建築条件、設備効率、人口構造、熱快適性、福祉も含める必要がある。[^1] 公共テレビの特集報道は、エネルギー負担を弱者家庭の実際の生活の文脈に置き、エネルギー転換が分配設計を欠くと、元々居住と設備のコストが高い人に新しい負担を課す可能性があることを説明している。[^9] このアプローチは台湾に特に重要である。ある家庭は熱を恐れて高額な電気代を支払う可能性がある。また、電気代を払えないために異常に低い電気使用量を示す可能性もある。どちらも請求書だけで判断できない。

地方政府の高温演習と節電補助は、政策実験の空間を提供している。中央政府は、弱者家庭の熱安全指標、補助金申請のアクセシビリティ、賃貸住宅者と所有者の責任分担、エネルギー診断データのプライバシー保護を含む、共通の最低基準を確立する必要がある。各県市が短期的な計画を立てるだけでは、家庭は戸籍、申請時期、情報能力の違いによってまったく異なる保護を受ける可能性がある。

# 実行可能な台湾のソリューション

台湾は最初に複雑な単一のエネルギー貧困スコアを確立する必要はない。操作可能なサービスプロセスから始めることができる。中央政府は過去に県市と協力して商業・住宅節電プログラムを推進し、これによりエネルギー診断、社会福祉の紹介、住宅改善を既存の行政ネットワークに接続する制度的入口を提供した。[^10] 第一歩は地方政府が「居住熱安全紹介」を確立することである。ソーシャルワーカー、保健所、消防、居宅ケア、地域組織が高温リスクの家庭を発見した場合、エネルギー診断に紹介できるようにする。一時的な電気代補助を提供するだけでは不十分である。

第二歩は、改善措置を3つのコストレベルに分類することである。低コストにはエアコンの清掃、日除けの調整、換気の改善、温度計の提供が含まれる。中コストには隔熱フィルム、カーテン、室外機の放熱、節電家電が含まれる。高コストには屋上、外壁、窓、地域公共空間の改造が含まれる。このようにすることで、すべての家庭が高額な設備の購入を求める必要はなく、有限の予算で最も危険な住宅を優先的に処理できる。

第三歩は、成果を「何kWh節約したか」から「リスクを減少させたか」に拡大することである。政府は室内の高温時間、熱傷害の病院受診、家庭のエネルギー支出負担、設備故障率、住民の主観的な熱快適性を追跡できる。総節電量だけでプログラムの成功を判断してはならない。節電量が減少しても熱傷害が増加した場合、成功とは言えない。家庭の電気使用量がわずかに増加しても、高効率の設備によって安全に冷却されている場合、失敗とは言えない。

この制度には、地方の担当者が使用できる最小限のデータセットも必要である。家庭はすべての消費の詳細を開示する必要はないが、同意を得た上で、住宅の階層、屋上の種類、主要な熱源、エアコンと冷蔵庫の年齢、室内の換気、居住者の中に高温感受性者がいるかどうか、最近1季のエネルギー支出が生活上の取捨選択を引き起こしたかどうかを記録する必要がある。データはサービスの改善を目的として使用されるべきであり、社会福祉の個別データとは分離して保存されるべきである。家庭はどのデータが誰に使用されるのかを知るべきである。データが「補助金を受ける価値があるかどうか」を判断するためにのみ使用される場合、スティグマが増加する。データが清掃、修理、隔熱、紹介に使用される場合、エネルギー政策を予防的な公共サービスに変えることができる。

地方政府は「熱安全サービスパック」を確立することもできる。熱波警報が発信される前に、地域の拠点、居宅サービス、保健所が高リスクの家庭に連絡する。警報期間中に、徒歩でアクセス可能な冷却場所、飲水、充電設備、緊急連絡先を提供する。警報後に、エアコン、扇風機、窓、電気請求書の負担に新しい問題が発生していないかを確認する。このサービスは災害や救急外来後にのみ開始されるべきではなく、夏季の地域ケアの定期的な一部になるべきである。偏遠地域と離島地域では、サービスパックに修理人材、部品の輸送、停電時の備えを含める必要がある。そうしないと、最良の補助金でも設備の故障時に効果を失う可能性がある。

# 結論：安全な冷却を基本的な生活能力にする

エネルギー貧困の核心は、弱者家庭により多くの意志力を求めることではなく、居住条件とエネルギーサービスそのものの不平等を認めることである。古い住宅が吸熱し、高消費電力の家電があり、前金購入のコストがかかり、補助金申請の障壁があり、極端な高温が重なると、1枚の電気請求書が所得、住宅、健康、気候のリスクを同時に示すことになる。

台湾は既に地方の隔熱補助、家電のリプレース、高温演習、地域の節電の政策ツールを蓄積してきた。次のステップは「電気を節約してください」という言葉をもう1つ追加することではなく、これらのツールを人間中心の居住熱安全制度につなぎ合わせることである。リスクのある家庭を積極的に見つけ、最も消費電力の高い住宅条件を改善し、補助金が賃貸住宅者や前金のない人々にも使用できるようにし、健康と生活の質でエネルギー転換が公平であるかを検証する。

ある家庭が高温の中でエアコンをつけることに安心でき、健康と請求書の間で選択を弫さなければならない場合、エネルギー政策は「供給管理」から公共福祉へと真に移行したと言える。

政策評価も住民の声を残すべきである。地方政府はサービス前後に、室内がより簡単に冷却されるようになったか、電気代のためにエアコンの使用時間を短縮しなければならなくなったか、設備がより信頼性が高くなったか、次回の高温警報時にどこに助けを求めることができるかを尋ねることができる。これらのフィードバックはエネルギー支出と健康データに代るものではなく、定量的指標と並んで使用されるべきである。政府は計画が実際に生活を改善したのか、それとも単に購入と精算を完了したのかを知ることができる。補助金によって家庭が設備を取得したが、賃貸の制限、修理の責任、将来の電気代が解決されていない場合、政策は再設計される必要がある。結果を住民の不協力に归咎してはならず、公に検討と修正を続けるべきである。
