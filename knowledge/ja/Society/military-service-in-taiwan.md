> **30秒概観：** 台湾の兵役制度は、この島が半世紀以上にわたって刻んできた最も深い社会的な印です。戒厳令下の「三年兵」から現代の1年制義務役への回帰まで、これは単なる期間の数字的変動ではなく、地政学的な圧力に直面する台湾の現実的な姿を映し出しています。本稿では、抽選現場での「金馬獎（キンマー・ジャー）」に対する驚きから、スーパーマーケットさえ訓練対象となる現代の戦備現場である漢光演習までを辿り、免役基準、新兵訓練のスケジュール、各種代替役、そして実戦化への転換といった側面を深く分析します。

### 抽選現場での集団的息止め：誰が「金馬獎」を引き当てたのか？

台湾において、すべての男性が19歳に達すると、「運命を変える抽選」を迎えます。郷鎮公所（地方行政機関）の礼堂内では、空気が凝縮しているかのようです。兵役中の若者やその両親を最も青ざめさせるのは、金門島か馬祖島を引き当てること、すなわち「金馬獎」です。

「金馬獎」という言葉は1980年代に由来し、当時両岸関係が高度な対峙状態にあったため、外島への配属は数百キロメートル離れた孤独を耐え忍ぶ必要があっただけでなく、突発的に勃発する可能性のある戦火に直面することを意味しました[^1]。たとえ今日の両岸情勢が「グレーゾーン」の衝突へと移行していても、外島での過酷な日々や三ヶ月に一度しか実家へ帰れない郷愁は、抽選現場で響き渡る最も大きなため息です。

📝 企画者のメモ：台湾において、抽選は確率の問題ではなく、「運命」と「宿命」に関する国民儀式なのです。

### 兵役制度の振り子：3年から4ヶ月を経て1年へ

台湾の徴兵制度は1945年、日本統治末期に始まりました。これは太平洋戦争を支えるためでした[^2]。国民政府が台に移った後、陸軍の服役期間は最大2年にも及び、海空軍や特殊部隊（陸戦隊など）は満3年を要し、「陸一特」と呼ばれていました。

地政学的な変化に伴い、2013年には「4ヶ月間の軍事訓練役」へと移行しました。しかし、台海情勢の緊張が高まる中で、政府は「2005年1月1日以降に生まれた男性は義務服役期間が1年に戻る」と発表しました[^3]。国民の73.2%が「兵役延長は必要な代償である」と認識していることが示されています[^4]。

### 新兵訓練：民から軍への8週間の洗礼

新兵訓練（入伍訓）はすべての兵士にとって最初の関門であり、通常成功嶺や官田などの新訓センターで行われます。この8週間にわたる訓練の目的は、平民を合格した戦闘員へと変貌させることです。体力訓練に加え、最も核となるのが「実弾射撃」であり、現代の新式入伍訓練では、照準合わせ射撃、基礎鑑定射撃、実距離射撃など射撃回数が大幅に増加しています[^5]。

新訓期間中の「懇親会」は兵役中の若者が最も楽しみにする時間です。両親がインスタント食品や家庭料理を持参して部隊を訪れる光景は、多くの男性にとって一生で最も忘れられない記憶となることがしばしばあります。

### 兵士の一日：分単位での集団的スケジュール

「諸君起床、現在時刻05時30分、部隊起床！」部隊内では、時間は「分」を単位として進行します。以下に典型的な国軍新訓のスケジュールを示します[^6]。

| 時間      | 項目                 | 詳細                                                 |
| :-------- | :------------------- | :--------------------------------------------------- |
| **05:30** | 起床・身だしなみ整理 | 10分以内に「豆腐塊」毛布と蚊帳を畳むこと             |
| **05:50** | 点呼・朝練           | 人数確認、開合跳またはランニングを実施               |
| **07:00** | 朝食・装備受領       | 急速に食事後、銃器や防弾服などの装備を受け取る       |
| **08:00** | 午前訓練             | 単兵戦闘教練、模擬射撃、的当て訓練など               |
| **12:00** | 昼食・昼休憩         | 部隊での昼食後、「ベッドで横たわる」という貴重な時間 |
| **14:00** | 午後訓練             | 体力測定、手榴弾投擲、戦術行軍など                   |
| **18:00** | 夕食・入浴           | 給水所での「戦闘シャワー」という集団的な記憶         |
| **19:00** | 夜間活動             | 莒光日課後の討論、装備の手入れ、携帯電話の使用時間   |
| **21:00** | 就寝準備             | 次日の装備整理、最終点呼                             |
| **21:30** | 消灯就寝             | 会話は厳禁、部隊内は絶対的な静寂に包まれる           |

📝 企画者のメモ：このスケジュールは単なる体力訓練ではなく、心理的再構築でもあります。集団生活の中では、個人の意志は最低限に抑えられ、合図への絶対的な反射が求められるのです。

### 研究開発と各種代替役：もう一つの戦場

すべての兵役中の若者が銃を扱うわけではありません。台湾では多様な「代替役」制度が発展しています。

- **研究開発代替役**：修士・博士課程の学生がTSMCや聯發科などの企業で勤務し、研究開発エネルギーを国防競争力へと転換させます[^7]。

- **一般代替役**：警察役（交通支援）、消防役（災害救助支援）、社会役（介護支援）などを含みます[^8]。

- **補充兵**：家庭の特殊事情や特定の体格により、訓練を受ける必要が12日間のみで免除されるケースです。

しかし、1年制への復帰に伴い、政府は代替役の枠を大幅に圧縮し、常備軍源の確保を優先させています[^9]。

### 免役条件の全解析：誰が「免役令」を受け取れるのか？

台湾には、免役の可否を判断するための厳格な「体格区分基準」が存在します[^10]。

1. **BMI指数**：BMIが15未満または35を超える者は免役対象と判定されます[^11]。
2. **視力基準**：両眼の矯正視力がいずれも0.1未満である場合、または高度近視による網膜病変など。
3. **特定疾病**：心臓疾患、精神機能障害、甲状腺疾患、癌、重度の傷病など。
4. **身長制限**：身長が155cm未満の者も免役対象となります。

### 現代演習と教召：スーパーマーケットも戦場となる

漢光演習では近年初めてスーパーマーケットを訓練に組み込むようになり、戦争時の物資配給の重要性を反映しています[^12]。また、退役軍人に対する「教召（きょうしょう）」は全面的にアップグレードされ、14日間の「新式教召」となり、10キロメートル以上の戦術行軍と2倍以上の実弾射撃回数を確保することで、後備戦力がいつでも「平時から有事への転換」ができるようになっています[^13]。

### 結語：健康保険証の裏側にあるもう一つの守護

台湾の兵役制度は、「責任」と「現実」についての長期的な対話なのです。次にあなたが台湾の街中で迷彩服を着た若者を見かけたとき、それは単に服役中の兵士というだけでなく、この島が自由を維持するために払っている最も静かで最も真実な代償なのです。
