# 封面圖與內文視覺健檢（2026-11-19）

## 〇、一句話結論

1,189 篇中文文章，有封面的 277 篇（23.3%），沒有的 912 篇；讀者實際點進來的文章裡，四次點擊有三次落在沒有封面的那一批。沒有封面的文章有 729 篇連內文圖、資訊模組、嵌入影片都沒有，整頁只有字。能補的量比想像多：133 篇內文已經放了 Wikimedia 的圖，另外 184 篇在中文維基有同名條目、主圖是比例合適的自由授權照片。估計可以把封面覆蓋率從 23% 拉到 51% 到 57%，補不到的那一半主要是抽象議題與找不到授權肖像的人物。

## 一、怎麼量的

逐篇資料來自既有的普查儀器 `scripts/tools/article-census.py`（規則住在 `scripts/tools/lib/article_health/census.py`），沒有另寫掃描器。這次只在儀器上補了三個欄位：授權三欄分開記、模組依種類計數、資料類模組數。逐篇明細在 [`reports/cover-image-health/2026-11-19-articles.tsv`](cover-image-health/2026-11-19-articles.tsv)（1,189 列，依讀者點擊排序）。

範圍是 `knowledge/<分類>/*.md`，不含 `_` 開頭的 hub 與各語言譯本。

## 五、為什麼沒有封面

912 篇照處理成本由低到高分成三型（沿用 11/04 普查的 C1／C2／C3），最大的那一型再用中文維基探測往下拆。

### 5.1 內文有本地圖，只是沒設封面：5 篇

11/04 的普查找到 22 篇，當時用 `cover-promote.py` 升格了 16 篇。剩下的 5 篇是工具刻意跳過的：

| 文章              | 跳過原因                                       |
| ----------------- | ---------------------------------------------- |
| 彰化縣            | 圖說抄不到作者與授權，原 Commons 圖已下架      |
| 1935 新竹臺中地震 | 圖說抄不到作者或允收授權，也沒有「圖片來源」段 |
| 歡樂無法黨        | 同上                                           |
| 電網韌性          | 同上                                           |
| 李宗盛            | 圖的比例 0.67，當卡片會裁掉主體                |

這 5 篇要先回頭查那張內文圖的出處，查得到才升格。

### 5.2 內文有圖，但圖是外站熱連結：133 篇

圖是作者寫文章時已經挑好的，全部在 Wikimedia。要做的是核授權、下載進庫、去 EXIF、轉 WebP，再設成封面。這一型沒有找圖成本，是第一批的主體。要留意三件事：

- 內文第一張不一定代表這篇文章。例：〈Ceylan〉第一張是八德路街景，〈陳思宏〉第一張是員林地圖，〈韓國人在台灣〉第一張是高雄天際線。每篇要從它的幾張圖裡挑，挑不到就不設。
- 9/05 收卡片圖時有 15 篇收不進來，留了 `imageNote`：10 篇是 Commons 原檔已下架，2 篇圖與主題不符，1 篇只有 GFDL 授權，1 篇原圖太小，1 篇另有原因。內文的熱連結也會遇到同樣的狀況。
- 內文圖本身仍是熱連結。封面收進庫之後，內文那張是否一起換成本地檔，會動到正文，牽涉譯本要不要重翻，見 §七。

### 5.3 沒封面、內文也沒圖：774 篇

這一型要從頭找圖。用中文維基的 pageimages API 對全部 912 篇沒封面的文章做了一次低速探測（檔名當條目名、只收自由授權主圖），結果當成「有沒有現成候選」的估計，不是授權結論，落地前每一張都要再核一次。

| 維基探測結果                             | 912 篇 | 其中沒圖的 774 篇 | 意思                                                                 |
| ---------------------------------------- | -----: | ----------------: | -------------------------------------------------------------------- |
| 有同名條目，主圖是比例合適的自由授權照片 |    184 |               140 | 有現成候選，核過授權與代表性就能落地                                 |
| 有同名條目，主圖是直幅（比例低於 0.75）  |     47 |                42 | 多半是肖像。能裁就裁（要註明），不能裁就另找                         |
| 有同名條目，主圖寬度不到 800             |    112 |                89 | 多半是低解析度肖像。要到 Commons 分類頁找同一個人的其他圖            |
| 有同名條目，主圖是標誌、地圖或向量圖     |     28 |                23 | 不適合當封面，要另找                                                 |
| 有同名條目，沒有自由授權主圖             |    122 |               104 | 條目沒圖，或用的是合理使用的圖。人物類佔 53 篇                       |
| 沒有同名條目                             |    418 |               375 | 抽象議題、制度、文化現象，或標題是策展式的說法。要用主題關鍵字人工找 |
| 過寬（比例高於 2.5）                     |      1 |                 1 |                                                                      |

依題材看沒封面的原因：

- **人物（237 篇沒封面）**：218 篇有維基條目，但主圖可直接用的只有 37 篇。44 篇是直幅、83 篇太小、53 篇沒有自由授權圖、19 篇沒有條目（網路創作者、新興樂團、候選人）。這一類會留下最多「找不到授權圖」。在世人物只用授權清楚的肖像，找不到就留空。
- **抽象議題（Society、Economy、Politics、Technology、Lifestyle 共 286 篇沒封面）**：204 篇沒有同名條目，例如〈台灣的道德課去哪了〉〈來來來怎麼樣怎麼樣〉〈議員制度〉。可以用的是「場景圖」：立法院議場、投票所、補習街、KTV 招牌。要逐篇判斷那張圖是不是真的代表這篇，不能只是有圖。
- **有實體對象的題材（Food、Geography、Nature、History、Culture 共 320 篇沒封面）**：102 篇有現成候選，是 C3 裡最好補的。食物、地點、物種、建築在 Commons 幾乎都有照片。
- **藝術與音樂（64 篇沒封面）**：作品本身多半有著作權，能用的是人物肖像、展場外觀、表演現場的自由授權照片，候選只有 9 篇。

做完之後仍會有 510 到 580 篇沒有封面：沒有同名條目的議題類約 330 篇，找不到授權肖像的人物約 150 篇，其餘是作品有著作權的藝術與音樂題材。這些不用程式生成的圖頂替，也不拿不相干的圖充數；主視覺識別定案後，再決定要不要有一套不靠照片的封面。

每一批不超過 50 篇，各自一個 PR，PR 說明附「文章、圖、來源網址、授權、作者」表。進度寫在本報告附錄 A。

## 七、既有流程與已知的坑

補圖走既有工具，不另造：

- **落地**：`node scripts/tools/image-ingest.mjs ingest --src <Commons 檔案頁> --cat <分類> --name <檔名> --role hero`。下載、嗅探檔頭、去 EXIF 與 GPS、縮到寬 2400 以內、轉 WebP、壓到 600KB 以內，存 `public/article-images/<分類>/`。
- **比例**：封面當卡片用，收 0.75 到 2.5（`cover-promote.py` 的範圍）；`image-ingest` 的 hero 檢查更窄（0.9 到 2.0），落在兩者之間的會印警告。文章頁內文不裁切，image-health 收 0.4 到 3.5。
- **授權**：卡片圖只收 CC BY、CC BY-SA、CC0、公有領域，以及 9/17 起納入的政府資料開放授權（OGDL-Taiwan-1.0，待決佇列 #50 已到期執行）。只有 GFDL 的不收，合理使用的不收。用 Commons API 的 `extmetadata` 查，一次可查五十個檔名。中文維基本地上傳的圖不等於 Commons 授權，要另外看。
- **限流**：Wikimedia 連續請求會回 429。這次探測每批五十個條目、間隔 1.2 秒，19 批裡有一批連撞兩次，等待後重試通過。下載原檔比查 API 更容易撞，每張之間要留間隔。
- **封面必填**：image-health 在 rewrite-stage-4 把「沒有封面」當 HARD，在 ci-deploy 與 pre-commit 是 WARN。frontmatter 有授權欄位卻沒有 `image` 會被擋。
- **同一張圖不重複**：image-health 會擋同一篇裡同一張圖出現兩次。模板端在正文已有同一張圖時，文章頂部會讓位（`heroImageInBody`），但比對的是路徑；封面是本地檔、內文是同一張圖的熱連結時算不算同一張，試點時要實際看渲染頁。
