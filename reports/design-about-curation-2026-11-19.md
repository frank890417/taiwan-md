# 「關於」頁：Taiwan.md 發展故事的策展

> 哲宇 11/19 17:3x：「我覺得旁邊好像不需要這個東西，而且版面好像左右被壓縮的蠻多的，這樣反而更少東西可以呈現。也幫我重新深度的想 UI UX 視覺視覺化的東西，還有什麼可以讓關於的頁面是真的更好看的？我們有這麼多視覺化的模組，然後這麼多媒體素材跟報道，還有我們發生過的事情，我覺得關於的頁面應該可以是一個對於台灣.md 發展故事的策展才對。」
>
> 同日稍早：「Taiwan.md的誕生的各種故事，我覺得這才是這個關於頁面最主要的一個大重點。幫我不要藏起來這麼多資訊，以及讓UIUX更自然。」「是活的那個部分……東西不夠圖像化，跟 U I U X 也不夠有組織……不像有被規劃過的好的網頁。」

## 0. 一句話

「關於」頁改成一場有展間的展覽，講 Taiwan.md 從一個問題長成今天的樣子。時間軸 27 則全部攤開，分進六個展間；每一間有一件主展品（真資料畫的圖、現場照片、報導或一句話），讓讀者用看展的節奏讀完這個專案的故事。

## 3. 兩個結構

### 方案 A：六個展間（推薦）

依時間分成六間，每一間是一個全寬的段落：開場有展間編號、名稱、日期區間、一句導語，接著一件主展品，再接這段時間的時間軸條目（全部攤開）。展間之間用底色交替區隔，「巴別塔」那一間用深色。

### 方案 B：一條會長的曲線

頁面頂端固定一條橫跨全寬的成長曲線（篇數、語言、點擊三條），讀者往下捲，曲線跟著畫到故事走到的那一天，時間軸條目在下面依序出現，主展品插在對應日期。

```
┌──────────────────────────────────────────────────────────────┐
│ ▁▂▃▅▆▇█  ←固定在頂端，畫到目前讀到的日期        3/17 … 11/19 │
├──────────────────────────────────────────────────────────────┤
│ 3/17　Taiwan.md 誕生 ……                                        │
│ 3/18　[報導卡] ……                                              │
│ …（27 則與展品交錯）                                           │
└──────────────────────────────────────────────────────────────┘
```

### 對照

|        | A 六個展間                               | B 一條會長的曲線     |
| ------ | ---------------------------------------- | -------------------- |
| 故事感 | 強，有章節、有起伏                       | 強，連續             |
| 手機   | 好，就是往下讀                           | 差，固定曲線佔掉螢幕 |
| 技術   | 伺服器端畫好，零或極少前端程式           | 要捲動驅動的動畫     |
| 無障礙 | 好                                       | 要額外處理           |
| 13 語  | 時間軸已有 13 語；新增的展間導語只有中英 | 同左                 |
| 風險   | 頁面變長                                 | 動畫效能、手機體驗   |

**推薦 A。** 會讓我改主意的情況：他想要一個有強烈互動感、像作品一樣的頁面，寧可在手機上退化。那就 A 為底，桌機版在「陸　現在」加一段 B 的捲動曲線。

## 4. 設計原則

| #      | 原則                                                                                                                                                                   |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 一     | 時間軸每一則全部攤開，文字一個字都不改                                                                                                                                 |
| 一之一 | 起源講「在國外很多人問過、希望台灣有一個入口」，不放大威尼斯那一句或任何單一事件（哲宇 11/19 18:06：「不要強化這個故事～ 就是我在國外很多人問過 也希望台灣有個入口」） |
| 二     | 每一間只有一件主展品，主展品要大（全寬或接近全寬），其他東西退後                                                                                                       |
| 三     | 版面放寬：展品用寬容器（1,280–1,400px），閱讀文字維持舒服行長（中文 28–38 字）                                                                                         |
| 四     | 圖都用真資料，每張圖印資料日期與來源                                                                                                                                   |
| 五     | 報導、演講只列打開過的網址，標題照原文，不用媒體標誌                                                                                                                   |
| 六     | 人用名字與公開數字，不加形容                                                                                                                                           |
| 七     | 沒有側欄。頂端一條細的進度列，顯示目前在第幾間（可選，試作時看效果再決定）                                                                                             |
| 八     | 深色、手機、右到左、減少動態，每一間都要過                                                                                                                             |
