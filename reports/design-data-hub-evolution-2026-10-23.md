# 資料台灣 v2：台灣資料策展中樞設計報告

## 〇、一句話結論

把 `/data` 從「七個彼此無關的展示區塊」改成三層的資料中樞：**數字之間的線**（跨主題的問題，把歷史、地理、社會、經濟、飲食串起來）、**台灣的數字**（每個數字都附官方出處、期間、下載的指標總表）、**資料從哪裡來**（官方、民間、學術、國際資料庫的導覽，加上 Taiwan.md 自己的機器介面）。底下接一張自動長出來的「站上的圖」索引，把 114 篇文章裡的量化圖表連回故事。全部 build 時產生語意 HTML 與 inline SVG，另外輸出 CSV／JSON 與 schema.org Dataset，讓人、搜尋引擎、LLM 都讀得到用「台灣」這個名字存在的數字。

## 一、目標（哲宇原話拆解）

> 「台灣資料的策展，要能夠從資料的切入的視角來去了解台灣的所有相關的資料以及敘事跟議題，還有各種社會經濟的層面，還有我們所有的主題、歷史、地理、文化、美食等等，所有的主題有什麼樣子的關聯，然後從數字怎麼看出在後面深度的洞察……試圖讓我們這個站變成大家找到開放資料或是台灣資料 data 跟分析的時候會來找我們的工具跟所有的洞見。」

拆成四個要回答的需求：

1. **讀懂**：從數字看出背後的洞察，數字要帶「為什麼值得注意」，不是數字清單。
2. **連結**：主題之間的關聯，一個數字要能把讀者帶到另一個分類的故事。
3. **查找**：要查某個台灣數字的人，在這裡找得到值、期間、出處、下載。
4. **工具**：要找原始資料的人，在這裡知道該去哪個平台、用什麼格式、有什麼坑；要程式化取用的人，有 CSV／JSON／API／MCP。

同步支線（哲宇指定派分身）：`/budget` 補到 116 年度預算案、`/companies` 市值快照更新、`/opendata` 更新。

## 三、研究摘要

> 七份研究原檔在 `reports/research/2026-10/data-hub-r*.md`。下面只收對設計有決定性的發現。

### 3.1 國際標竿（R3）

- **OWID 的核心是可引用的物件模型**：每張圖一個永久網址，加副檔名就是 CSV／metadata，每頁附引用字串、來源取得日、CC BY。它自己的讀者調查顯示只有約 1.6% 的 session 下載資料、約 16% 跟視覺化互動——**價值主要來自搜尋進來的閱讀與少量高影響力引用**，所以敘事加可引用是主力，API 是配角。
- **問題式入口**：OWID 的台灣健康國家檔案 H2 全是問句（「What is Taiwan's life expectancy at birth?」），荷蘭 CBS《The Netherlands in Numbers》是 35 個問題＝35 張圖的年度出版。
- **指標卡構造**：ABS、SingStat、e-Stat Dashboard、KOSIS 的首頁都是「數值＋參考期間＋更新日＋看資料表」。
- **信任層**：Eurostat Statistics Explained 頁首寫「Data extracted」與「Planned article update」，OWID 每張圖列來源取得日。
- **台灣的命名**：世界銀行 WDI 不單列台灣（官方說明直接請讀者去看台灣政府網站），Statista 台灣頁的 Region 欄寫「Taiwan, Province of China」，OWID 與 Google Data Commons 是獨立的 Taiwan／TWN。
- **機器介面已經是國家統計的標配**：SingStat 有官方 MCP、Data Commons 有 MCP server、data.gov.tw 介接 TAIDE 小幫手。
- **反例**：Statista 付費牆把下載擋在年約後面；FiveThirtyEight 2025-03-05 被母公司關閉，公開資料庫跟著停更——資料中樞的最大風險是「被鎖」與「養不起」，所以資料與產線都要開源可 fork。

### 3.2 台灣官方開放資料（R1）

- **量很大、入口很多、品質不齊，而且沒有一個地方替公眾整理成「找得到、讀得懂、可比較」的樣子。** data.gov.tw 有 52,556 個資料集（平臺前端 JSON 端點與整份清單 CSV 兩路交叉，一致），但只有 78 個是 API 服務（全是交通部 TDX）；把標題裡的民國年抹掉再去重，只剩約 43,527 個不同標題（同一張表一年一份）。
- **工程摩擦**：約 10% 資料集含 Big5 編碼、1,187 個只有 PDF、29.3% 標題帶民國年、65% 更新頻率寫「不定期」；證交所 OpenAPI 同一筆回應裡民國年（`1151022`）與西元年（`19501229`）並存；主計總處網站沒送中繼憑證，程式抓不到；國發會、經濟部統計處對腳本回 403；司法院裁判書 API 只在每天 0–6 時服務；疾管署 2026 年 8 月一次下架 234 個病例統計資料集。
- **授權是強項**：99.92% 用政府資料開放授權條款第 1 版，條款明寫與 CC BY 4.0 相容；但沒有標示原提供機關就「視為自始未取得授權」，比 CC BY 嚴格。
- **政府做給大眾看的儀表板集中在少數幾個**：主計總處的普查平臺與薪情平臺、教育部教育統計視覺化、臺北城市儀表板（開源）。主計總處自己的「統計視覺化」頁是一張各部會入口的連結清單。**沒有任何一個跨部會的「台灣總覽」**。
- **國際評比的轉折**：Global Open Data Index 2015、2016 連兩屆第一（2016 年 90%，英國、澳洲 79%）；Global Data Barometer 2022 台灣總分 51（全球平均 33），但「使用與影響」只有 23 分，報告寫「there is limited proof of impact of data use」。資料的「公開面」台灣早就是冠軍，缺的是「被用起來」那一面，**這是資料中樞存在的理由**。
- **民眾實際在用什麼**（下載次數前十）：地震報告、股價、桃園停車、台電發電成本與太陽光電、雨量；瀏覽多下載少的是央行與財稅報表。兩種需求要兩種產品：即時資料給開發者，常用數字給讀者。

### 3.3 民間公民科技、資料新聞與彙整平台（R2）

- **公民科技的重心從視覺化移到 API、AI 輔助審議與封存**。2013 年的 budget.g0v.tw 還打得開，但 repo 最後推送是 2020-08-15，介面仍寫「2013 預計舉債」，資料端點回 404。接棒的是歐噴 OpenFun（data.openfun.tw 3,445+ 份資料集、CC BY 4.0、附 AI 說明書與 llms.txt；LYAPI 立法院 API）與 READr／公民監督國會聯盟的預算審查監督平台（逐筆提案）。**兩者都沒有十年趨勢**，Taiwan.md 的總預算十年是少數的長期序列。
- **資料新聞幾乎不放資料**：報導者、中央社、公視、端傳媒的圖表多半沒有說明底層資料是否開放，只有 READr 有 GitHub 資料承諾。報導者那篇淡江大橋事故分析把警政署 240 萬筆整理成橋上 1,249 筆，那張表沒有放出來。
- **私人彙整平台幾乎只做財經**（財報狗、MacroMicro、Goodinfo、CMoney、TEJ），人口、教育、健康、能源、交通的彙整仍停在政府入口與新聞稿。**這是最大的結構性缺口。**
- **口徑問題沒有人在回答**：同一年台灣人口 CEIC 寫 2,330 萬、Worldometers 寫 2,311 萬；104 的薪資跟主計總處不能直接比；ADIZ 次數三個來源三種數字。「為什麼兩個數字不一樣」沒有民間頁面專門解釋，這是策展者的價值。
- **搜尋版圖**：「台灣 統計 資料」「台灣 人口 統計」「台灣 開放資料」「Taiwan statistics」「Taiwan data」「Taiwan economy data」六組不帶品牌的查詢，前十名都沒有 Taiwan.md。中文前排是 data.gov.tw、圖書館指南與 Taiwan News 的月度戶口新聞稿；英文前排是 CEIC、Statista、Trading Economics。Taiwan.md 的 `/en/data/`、`/en/budget/` 等頁有被索引，只是沒進前排。
- **可學的做法**：Cofacts 在 README 第一行寫「Latest dataset snapshot: 2026-10-18」（資料截至日寫在最前面）；Pew 用一句結論式標題加三行方法；歐噴把「授權＋資料限制」寫進每一次回答；民間 git 封存（例如台電發電資料每小時封存）補上了政府網站不留歷史的缺口。

### 3.4 台灣在國際資料庫（R4）

26 個國際資料庫逐一用 API 或原始檔查證：

| 處理方式                      | 數量 | 例子                                                                                                                                             |
| ----------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 標示為 Taiwan                 | 9    | Penn World Table、OWID、Google Data Commons、V-Dem、Freedom House、RSF、TI CPI                                                                   |
| 名稱帶「Province of China」   | 6    | IMF（`Taiwan Province of China`）、UN WPP（`China, Taiwan Province of China`）、ITU、Maddison、World Happiness Report、ISO 3166-1                |
| Taiwan, China／Chinese Taipei | 5    | ILOSTAT、WTO、OECD、PISA、IMD（`Taiwan (Chinese Taipei)`）                                                                                       |
| 整個缺席                      | 6    | 世界銀行 WDI 與 Data360、UNDP HDR、WHO GHO、UNESCO UIS、UN SDG 資料庫（代碼 158 寫成 `Other non-specified areas in Eastern Asia`，底下沒有資料） |
| 台灣數字被併入中國            | 0    | 世界銀行反而註明中國資料不含台灣                                                                                                                 |

- 健康（WHO）、教育（UNESCO）、人類發展（UNDP）這幾個最常被引用的國際資料庫，**台灣都不在裡面**。查台灣的這些數字，只能用台灣官方統計。
- 台灣官方自己依國際公式編算來補洞：主計總處依 UNDP 公式算出 2023 年 HDI 0.934、排名第 21；行政院性別平等處依 UNDP 公式算 GII 2023 年 0.040（173 國第 13）、依 WEF 公式算 GGI 2025 年 0.766（148 國第 35）。這些不是原機構的正式榜單，引用時要寫明。
- **定案的標註政策**：頁面一律稱台灣；資料庫原始標籤逐字照抄放在另一欄（不翻譯、不替它命名背書，也讓讀者能追溯）；缺席就寫缺席，不補零、不留白；自算指標寫明編算機關與方法；不同來源的數字不拼成同一條時間序列。

### 3.5 指標查證（R5a／b／c）

三組研究分身各自回到官方原始頁面（政府站多數憑證有問題，改用 curl 取原檔、pdftotext／openpyxl 讀出），每個數字附原文逐字、期間與網址。主 session 再抽驗（能源署發電結構那段、央行 9 月底外匯存底、證交所 10/22 台積電收盤、行政院 116 年度預算案新聞稿 PDF），四項全部對上原文。

- **R5b 經濟、科技、能源、土地、自然**：30 筆，全部 ✅。2025 年經濟成長 8.76%（2013 年以來最高）、名目 GDP 9,225 億美元、每人 GDP 39,515 美元；出口 6,407.5 億美元年增 34.9%，美國占 30.9% 首度超過中國大陸與香港的 26.6%（財政部：「為 26 年來首見」）；燃氣發電 47.7% 已超過燃煤 35.3%，再生能源 13.3%，核能 2025 全年 1.1%（不是 0）；森林覆蓋率 60.71%；物種 66,470 種、特有種 9,881 種（TaiCOL 即時計數）。
- **R5c 政治、歷史、文化、飲食、生活、運動**：35 筆，22 筆 ✅、5 筆只有媒體轉述、8 筆查不到（照實留空）。2024 總統大選投票率 71.86%；古蹟 1,063 處、歷史建築 1,786 處；稻米每人每年 42.4 公斤（較 2004 年少 12.7%）；糧食自給率 30.7%；高鐵 2025 年 8,207 萬人次；網路族行動支付使用率 51.0%，首度過半。
- **R5a 人口與社會**：34 筆，33 筆 ✅。2026 年 9 月底人口 23,213,251 人（2019 年底高點後少約 39 萬）；2025 年出生 107,812 人，約是 2015 年的一半，總生育率 0.695；65 歲以上在 2025 年 12 月底首次超過 20%；來自高中的大學生源十年從 30.2 萬降到 19.2 萬；移工 86.6 萬（本站加總勞動部資料集）。房價所得比 9.89 只見於媒體轉述，依收錄規則不收。

**收錄規則**：只收 ✅；🔍（只有媒體轉述）一律不收，除非主 session 自己回官方源核到原文；業界估計（工研院半導體產值、TrendForce 晶圓代工市占）收，但標「業界估計」；即時計數（TaiCOL 物種數）收，期間寫查詢日；舊資料（內政部寺廟數只到 2015 年底）若收，期間照實寫年份。

## 九、後記（實作摩擦）

- **一個欄位混了兩種週期**（REFLEXES #38）：指標的 `cadence` 原本把「這個值是年度總數」跟「官方每月也有發布」混在一起，過期檢查第一次跑就把 2025 全年出生數判成逾期 296 天。改成 cadence 只描述這個值本身多久換一次，期限＝下一個參考期間＋發布時滯；修完逾期從 23 個降到 1 個（房貸負擔率真的停在 2025 第 2 季）。

- **PageHero 寫死淺色墨色**：頂端數字在深色模式看不見，指回 `--color-ink` 修掉。
- **「關於」分類的圖不是台灣的資料**：站上的圖索引原本收進 23 張 Taiwan.md 寫自己的圖（產線、孢子瀏覽數），排除前是 80 篇文章、172 張，排除後是 75 篇、149 張。

## 十、v2.1：從數字櫃到一篇讀得下去的台灣（2026-10-23 22:1x，哲宇第二道指令）

### 10.1 哲宇這次說了什麼

v2 上線後哲宇讀完，資料完整度可以，但有四件事不對：

1. **只有數字，沒有意義**：「除了講數字之外，要講它的意義跟對於我們台灣的社會跟整個各種層面的影響」「在講解各種數字的時候，要講說為什麼重要，這件事情代表什麼」。
2. **缺一個宏觀的視角**：要有敘述性、策展性的文字，「從縱觀去了解台灣的完整歷史」，看懂台灣為什麼是今天這個樣子。
3. **提到文章就用文內嵌入卡**（`tw-article`，共用 ArticleCard `embed` 密度），不是一排純文字連結。
4. **視覺**：每個主要區塊要有比數字卡更好的視覺化；整頁白到底，要回到深色 header，往下按識別系統 v2 規劃區塊節奏（直角、細線、留白；黑潮墨深底、紙色三階、臺灣青只做小面積）。

### 10.2 現況診斷

- 七條線各是一個問題、兩段文字、四張數字卡、一排純文字連結，**文字在描述數字，沒有往外接到社會的其他層面**。
- 指標的 `insight` 欄寫的是「這個數字說了什麼」（2019 年底到頂之後起伏往下），沒有「所以呢」。
- 年度序列只有 2015 年之後的 24 筆，沒有任何一條能撐起「七十五年」的尺度；站上 149 張圖多是單一題目的局部。
- 視覺上整頁是同一個白底，區塊之間只靠標題分隔；卡片頂端粗色條是 v1 的語彙，識別系統 v2 規定卡片用 1 px 線、8 px 圓角。
- 單位錯：總生育率顯示成「0.695 人」。

### 10.3 發散

| 方案                | 做法                                                                                       | 優點                                                         | 缺點                                                             |
| ------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------ | ---------------------------------------------------------------- |
| A. 時代章           | 依時代分章（戰後、加工出口、解嚴、民主化與科技島、少子與晶片）                             | 歷史感最強                                                   | 指標與議題被切碎在不同時代，讀者要找「人口」得翻四章             |
| B. 主題章加長序列   | 七條線改成七章，每章往前拉到 1950 年                                                       | 跟既有的線、指標、文章分類一一對得上                         | 少了一個總覽，讀者看不到各主題同時在變                           |
| C. 一張總覽＋主題章 | 開頭一段「七十五年」總覽（共用時間軸的多條時間帶＋時代標記），往下七章各自拉長、各自講後果 | 宏觀與細節都有，總覽負責「同時發生」，章節負責「為什麼重要」 | 工作量最大：要補長期序列研究、寫八段策展文字、做兩個新的視覺元件 |

**定案 C**。哲宇要的「縱觀」需要一個地方讓讀者同時看見人口、錢、制度在同一條時間軸上變動，A 做得到但會打散指標，B 留住指標但沒有總覽。

### 10.4 每一章的固定骨架

每章回答同一組問題，順序固定，讓讀者讀過一章就知道下一章怎麼讀：

1. **這個數字現在是多少**（章首大字＋一句話）。
2. **它怎麼變成今天這樣**（長期序列的主圖，tw-\* 模組 build 時畫成 inline SVG，附資料表 fallback）。
3. **為什麼重要：它推動了什麼**（影響鏈，4–6 環，每環一個社會層面＋一個有年份的事實＋站內文章出處，用新元件畫成橫向連鎖）。
4. **接下來看什麼**（一兩句，盼望而不粉飾：講方向，不賣焦慮）。
5. **相關數字**（既有指標卡，每張加一行「為什麼重要」）。
6. **延伸閱讀**（2–3 張 `tw-article` 嵌入卡，只放正文真的講到的那幾篇）。

### 10.5 指標卡加「為什麼重要」

`indicators.json` 每筆新增 `why`（在地化物件），寫這個數字推動或限制了什麼，必須是具體後果（誰、哪一年、多少），不寫「具有重要意義」這類任何國家都套得上的句子。`insight` 保留，回答「數字說了什麼」，`why` 回答「所以呢」，兩行在卡上分開標示。

### 10.9 實作紀錄（v2.1）

- **研究**：R6a 人口（戶政司 XLS 原檔，1950–2025 每五年一點）、R6b 經濟（主計總處、財政部）、R6c 民主土地與日常（中選會、檔案管理局、戶政司開放資料、農業部、高鐵年報）、R7 從站內文章挖影響鏈（只收有腳註的事實）。原始下載檔 111MB 不進 repo。
- **證偽到的事**：出生數 1963 年 427,212 人最高成立；總生育率歷史最低是 2025 年 0.695，不是 2010 年；人口最高峰在 2019 年底到 2020 年初；「薪資停滯二十年」若指名目被推翻（+41%），若指實質則 2000–2020 幾乎持平成立（+4.1%）；2024 年糧食自給率有初公布 30.7% 與修正序列 30.8% 兩個官方值，站上改用現行序列並更新到 2025 年 30.36%；颱風「每年 3 至 4 個」是氣象署原文，不能自己轉寫成「平均 3.5 個」。
- **口徑接縫照實標**：1970 年以前人口不含金門、連江；1985 年以前產業結構是舊制國民所得口徑；實質薪資（CPI 平減）與實質每人 GDP（國民所得平減）只比方向。這些都寫在圖的來源列，不藏在報告裡。
- **磚圖改長條圖**：`tw-tiles` 的磚上固定顯示中文縣市名，放在十種非中日韓語言頁會讓漢字外漏，第六章的人口密度改用排序長條圖。要根治得讓 renderer 顯示各語言的縣市名，那是全站模組的改動，不在本次範圍。
- **正文與影響鏈分工**：正文講脈絡與意義，影響鏈放具體後果與出處，同一個數字不在兩處重複。
- **檢查器**：`data-hub-check.py` 加上章節骨架檢查（正文中英文、主圖模組、影響鏈 3–5 環且出處存在、延伸閱讀文章存在）；`data-hub-i18n.py` 加上主圖形狀檢查（譯文的資料列欄數與數字必須跟原文一致）。
