# 首頁與「關於」頁的進化：分析與建議

> 哲宇 11/19：「怎麼改版 taiwan.md 的首頁，然後寫一份深度分析的跟建議的報告跟我討論。我的目標是，因為現在其實專案長蠻大的。你從一個怎麼樣讓首頁進化，但是不失去專案的原始風味跟品質，是我最在乎的。還有很棒的視覺化跟 UI UX。」同日補充：「關於頁面也幫我一起評估。」

## 0. 先講結論

1. **首頁的角色已經變了。** 4 月它是大門，佔全站瀏覽 28.5%。現在只有 4.9% 的人從首頁進站，68% 直接落在文章頁。會來首頁的多半是直接輸入網址或被別的網站介紹來的人。它現在的工作是當這件作品的門面，讓人很快看懂這是什麼、相信它、想走進去。
2. **原味的一半埋在沒人到的地方。** 首頁桌機 22.6 個螢幕高。引語時間軸有 54% 的人看到，四展廳的策展散文 26.5%，繁體中文宣言 8.4%，讀者的聲音 4.6%。
3. **長大的東西首頁完全沒帶到。** 選舉專區、用語轉換器、企業版圖、五個專題、工具，首頁內文一個入口都沒有。5/26 之後首頁內文只加過兩顆按鈕。
4. **我的建議是分三期。** 第一期修缺陷並重排，不動結構。第二期把首頁變成「大廳」，四個展廳各自成頁，散文一字不刪搬進去，長大的東西住進對應的展廳。第三期等主視覺定案後，再做大廳的主視覺化。
5. **「關於」頁比首頁還長（32.7 個螢幕），但讀的人很認真。** 互動率 84%，有 111 人停留超過十分鐘。它該做的是加一個三十秒版本、把人往上移、把十四個螢幕的時間軸收成里程碑。
6. **有一題要先問他。** 「首頁是策展、散文不能動」這句話，紀錄裡找不到他的原話，只有歷次 session 的轉述。哪些才算原味，請他親自圈。

## 1. 怎麼讀這份報告

- **數據時間窗**：GA4 是 2026-10-22 至 11-18，Search Console 是 10-21 至 11-17。GA4 的數字一律用「排除中國與新加坡」的版本，因為那兩地的流量互動率只有 6–9%，疑似機器。
- **畫面量測**：11/19 用 1440×900 與 375×812 兩種視窗實際打開線上首頁與關於頁量的。
- **沒有改任何頁面**。照專案的設計進化流程，報告先於實作。首頁屬於對外的門面，要他拍板。
- **標「推論」的是我的判讀**，沒有直接數據。標「我的延伸」的，是把他在別處講過的話套到首頁上，還沒問過他。
- **建議都是我的看法**。每個建議後面附「什麼情況會讓我改主意」。

推論：直接輸入與被介紹來的人，多半是已經聽過這個專案的人，例如回訪的讀者、看了報導的人、評審、想參與的人。這是從管道推的，沒有直接證據。

### 2.4 視覺與重量

- 首頁有 187 個 SVG 圖示、4 張圖片。沒有照片、沒有地圖、沒有任何資料圖表。站上其實有很多視覺化（台灣的形狀、地圖、時間軸、知識圖譜、企業泡泡圖、預算、生命體生態圖），首頁一個都沒用上。
- 讀者從英文首頁送來的回饋（issue #2010、#2012）要的正是這個：首頁多一些圖、放一張台灣地圖、分類入口更好找。當時維護者自己回了一句：首頁沒有盡到告訴你它們在那裡的責任。
- 中文首頁 HTML 484 KB。其中 180 KB（36%）是最底下那 104 則留言輸出了兩份，而那一區只有 4.6% 的人滑得到。
- 11/04 的健檢量到手機 Lighthouse 55 分。之後做過按需載入的修正，沒有重量。右下角的聊天泡泡在首頁載入三支各三百多 KB 的第三方程式。
- 手機開場畫面上同時浮著五個小按鈕：意見回饋、字級、`.md`、聊天泡泡、招手。
- 各語言首頁：12 個非中文首頁的展廳散文是同一份英文。日文、韓文首頁的標題與按鈕有翻，散文沒翻。

## 7. 三個方向

三個方向的差別在同一條軸上：策展散文與長大的東西住在哪裡。

### 方向 A：一條長卷，收斂重排

結構不變，還是一頁到底。重排順序、合併重複、補上入口。散文全文留在首頁。

```
開場（主視覺待定）
如何理解台灣（八句引語，壓成一個螢幕）
四扇門 ＋ 現在能直接用的（選舉、轉換器、企業、專題）
分類格（上移）
四展廳散文（全文，每廳加一張視覺化縮圖）
人：讀者的聲音、讀者教我們的事（上移，精選）
這個月：有意義的變動
為什麼用繁體中文
生命體一格 ＋ 參與、訂閱
```

預估桌機約 14 個螢幕。

### 方向 B：大廳與展廳

首頁變成大廳，約 7 個螢幕。四個展廳各自成頁，散文一字不刪搬進去，每廳配自己的視覺化。長大的東西住進對應的展廳。

```
大廳（首頁）
├ 開場（主視覺待定）                                   1
├ 如何理解台灣（八句引語）                             1
├ 四展廳入口：每廳的開場那一段散文、縮圖、三篇、住戶   2
├ 這個月：有意義的變動                                 1
├ 直接能用的：選舉、轉換器、企業、形狀                 0.5
├ 人：讀者的聲音、讀者教我們的事、寫作者               1
└ 為什麼用繁體中文、生命體一格、參與與訂閱             1

展廳頁（四頁，各語言一份）
壹 這座島長什麼樣   → 散文全文 ＋ 台灣的形狀、地圖、聲景 ＋ 地理、自然、生活
貳 這座島怎麼來的   → 散文全文 ＋ 時間軸、用語庫 ＋ 歷史、文化、社會
參 這座島的人在做什麼 → 散文全文 ＋ 人物、生命樹、名字專題 ＋ 人物、藝術、音樂
肆 這座島往哪裡去   → 散文全文 ＋ 企業、預算、產業、選舉、醫療、薪資、房地產 ＋ 科技、經濟、政治
```

這個方向就是 7/06 稽核提過、沒做的那一個，再加上「長大的東西住進展廳」。

### 方向 C：一座島當介面

開場之後，首頁的主體是一個可以互動的台灣。文章、專區、工具都掛在它上面，四展廳變成看這座島的四種視角（地形、時間、人、資料）。散文變成每個視角的導語。

```
開場
一座可以操作的台灣（切換四種視角；點一個地方、一個年代、一個人，走進文章）
這個月 ／ 人 ／ 參與
```

## 8. 我的建議

**分三期，先 A 的修補，再走到 B，C 只取一個元件。**

## 9. 「關於」頁的建議

首頁與「關於」頁的分工：首頁講台灣，是展間。「關於」頁講這個專案，是誰做的、怎麼做的、可不可信。

| --- | -------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 1   | 最上面加一個三十秒版本：這是什麼、誰做的、怎麼運作、怎麼參與、哪些是 AI 寫的而哪些有人看過。旁邊放一排章節錨點 | 手機讀者九成沒滑過第一個四分之一                     |
| 2   | 人往上移：創辦人、寫作者、贊助者移到時間軸前面                                                                 | 現在排在第 21 個螢幕之後，桌機約兩成的人到得了       |
| 3   | 時間軸從 14.7 個螢幕收成十個左右的里程碑，做成橫向的視覺化。完整的故事交給「關於」分類底下已經有的長文         | 時間軸佔全頁 45%；〈緣起故事〉等九篇已經在講同一件事 |
| 4   | 首頁那四張價值卡搬到這裡                                                                                       | 它們在首頁點擊率 1.8%，內容本來就是在講這個專案      |

## 14. 要跟他討論的題目

一次一題，照他的回答決定下一題。

1. **原味是哪幾樣？** 第 4 節那張清單，哪些是不能動的，有沒有漏掉的。
2. **策展散文住哪裡？** 全文留在首頁，還是首頁留每廳的開場、全文搬進展廳頁。
3. **首頁是給誰看的？** 回訪的人、第一次被介紹來的人、評審與媒體，還是想參與的人。
4. **長大的東西要露多少？** 一條帶就好，還是每樣都要有家。
5. **「網站即時更新」與器官分數要不要離開首頁？** 換成有意義的變動。
6. **主視覺用哪一套？** 行島、花磚、沿用現況。這題可以晚一點。
7. **非中文首頁的散文要不要翻？**
8. **「關於」頁的時間軸要多長？**
9. **導覽列要不要一起整理？** 八個下拉選單，這是全站的事，建議另案。
