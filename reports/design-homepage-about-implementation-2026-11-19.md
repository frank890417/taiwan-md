# 首頁與「關於」頁進化：實作報告

> 哲宇 11/19 14:17：「完整處理『分三期，先 A 的修補，再走到 B』你來驗收，ui ux 視覺標準提高到世界級。C 的主視覺下個階段處理。」同日：「關於頁面也寫實作報告後做進化。」

分析與方案對照在 [design-homepage-about-evolution-2026-11-19.md](design-homepage-about-evolution-2026-11-19.md)。這一份是動手前的規格。

## 0. 這次做什麼、不做什麼

| 做                                             | 不做                                 |
| ---------------------------------------------- | ------------------------------------ |
| 第一期：修 12 項缺陷，首頁重排                 | 開場的主視覺（等識別定案，下個階段） |
| 第二期：首頁變大廳，四個展廳各自成頁，散文搬家 | 導覽列的整理（全站的事，另案）       |
| 「關於」頁進化                                 | 行島或花磚識別的任何套用             |
| 12 個語言補翻展廳散文                          | 改任何文章內容                       |

**不能違反的三件事**

1. 中文策展散文搬家時一字不改。只有事實查核查出錯的數字例外，而且每一處都要列出來給哲宇看。
2. 深綠開場、站名、「策展島嶼的深度敘事」原樣保留。
3. 沒有東西被刪掉。從首頁移走的內容都有新的家，並且從首頁連得到。

## 1. 視覺與體驗標準

「世界級」在這裡的意思是：一個做設計的人打開它，挑不出粗糙的地方。具體到可以驗收的條件如下。

### 1.1 版面

- 沿用 `src/styles/tokens.css` 的容器寬度、間距、圓角、顏色 token。不新增色相，不寫死色碼。
- 區塊之間的垂直間距只用三級：大（區塊之間）、中（區塊內分組）、小（元素之間）。同一級在整頁一致。
- 每個螢幕一個主要念頭。一個區塊裡最多一個主要行動。
- 內文行長：中文 28–38 字，拉丁文字 60–75 字元。
- 所有網格在 1440、1024、768、375 四個寬度都對齊，沒有孤字、沒有只剩一張卡的殘列。

### 1.2 字

- 襯線顯示字只用在：站名、展廳名、引語、頁面大標。內文與介面一律無襯線。沿用現有的字體載入方式，不新增字體檔。
- 字級只用一套階梯（大標、區塊標、卡片標、內文、註記），用 `clamp()` 隨寬度縮放。
- 策展散文：行高 1.8 以上，段距明確，數字與中文之間的間距照現況。
- 中文標點不出現在行首。標題不超過兩行。

### 1.3 顏色與深色模式

- 深色模式完整支援，跟文章頁用同一套機制。每個新區塊都要在深色下看過。
- 文字對比 4.5:1 以上，大字 3:1 以上。現有的淺藍標籤（對比 3.37）順手修掉。
- 顏色有語意：品牌色只用在站名的 `.md`、連結的強調、視覺化的重點。不拿來鋪大面積。

### 1.4 動態

- 只有兩種動態：內容進場的淡入與位移（200–400 毫秒，一次），以及視覺化本身。
- `prefers-reduced-motion` 開啟時全部關掉。
- 不做捲動劫持、不做視差、不做自動輪播。留言不再跑馬燈。

### 1.5 視覺化

- 每一個都用真實資料，資料來自 repo 既有的檔。
- 每一個都點得進去，去的是對應的完整頁面。
- 每一個都有文字替代（`aria-label` 加上一句看得見的說明）。
- 優先用行內 SVG。需要程式庫的延後到滑到才載入。
- 畫台灣的形狀一律用 repo 裡既有的 SVG，不重新畫。

### 1.6 互動與無障礙

- 所有可點的東西觸控區至少 44×44。鍵盤走得到，focus 外框看得見。
- 標題階層正確：一頁一個 `h1`，區塊用 `h2`，不跳級。
- 連結文字說得出去處，不用「點這裡」。
- 手機首屏看得到站名、主張、一個行動。浮動按鈕在首頁最多留兩個。

### 1.7 效能預算

| 項目                   | 現在         | 上限                                 |
| ---------------------- | ------------ | ------------------------------------ |
| 中文首頁 HTML          | 484 KB       | 200 KB                               |
| 首屏的第三方程式       | 聊天泡泡三支 | 零。聊天泡泡延後到閒置或滑到底才載入 |
| 版面位移（CLS）        | —            | 0.05 以下                            |
| 首頁正式頁裡的程式註解 | 20 KB        | 0                                    |

### 1.8 多語

- 13 個語言都要能建置。阿拉伯文版面方向正確，用邏輯屬性（`margin-inline`、`padding-inline`），不寫死左右。
- 新增的介面字串 13 語都要有。先給中文與英文，其餘語言在第二期補翻；補翻完成前退回英文，不能出現空白或鍵名。

### 1.9 一致

- 文章卡用既有的 `ArticleCard.astro`，不另外手刻。
- 追蹤照既有做法：區塊加 `data-ga-view`，可點的東西加 `data-ga-section` 與 `data-ga-label`。新的區塊名登記進追蹤的設定檔。
- Tailwind 的寫法與既有首頁元件一致。

### 2.3 新區塊的規格

**直接能用的**

- 六張卡，桌機一列六張或兩列三張，手機兩欄。每張：一個小視覺化或圖示、名稱、一句說明、去處。
- 選舉那張帶到期日。2026-11-29 起自動換成「時間軸」。到期日寫在資料裡，建置時判斷。
- 卡片順序照搜尋實際帶來的人數。
- `data-ga-view="tools_band"`。

**引語時間軸**

- 一條有刻度的橫線，八個點對應八句引語的年代。桌機一次看到全部，點或滑到哪個點就顯示哪一句。手機改成直向，預設全部展開。
- 引語用襯線字。出處小字。最後一條是 Taiwan.md 自己的那句。
- 高度從 2.2 個螢幕降到 1 個螢幕以內。
- 八句的文字不動（1584 那條依查核結果統一）。

**四展廳的視覺化縮圖（第一期先放縮圖，第二期成為展廳頁的頭圖）**

| 展廳                  | 縮圖                                   | 資料                   |
| --------------------- | -------------------------------------- | ---------------------- |
| 壹 這座島長什麼樣     | 台灣的輪廓與由北到南的地形剖面         | repo 既有的台灣 SVG    |
| 貳 這座島怎麼來的     | 一條年代帶，標出歷史類文章落在哪些年代 | 文章的 frontmatter     |
| 參 這座島的人在做什麼 | 人物類文章依出生年代排成的點陣         | 文章的 frontmatter     |
| 肆 這座島往哪裡去     | 市值前幾大公司的區塊圖                 | `/companies/` 用的資料 |

拿不到乾淨資料的那一張，改用該展廳三個分類的篇數做簡單的比例條，不硬畫。

**人**

- 讀者的聲音：精選六則，靜態卡片，不跑馬燈。104 則全文移到 `/voices/`（新頁，只有中文），首頁放「看全部 104 則」。
- 「讀者教我們的事」四條原文不動，移到這一區的右側或下方。
- 寫作者：頭像牆，資料來自 `contributors.json`，連到貢獻者頁或 GitHub。
- 非中文首頁：沒有留言時，只顯示寫作者牆。
- `data-ga-view="people"`。

**最近**

- 左：最近新進的四篇文章，用 `ArticleCard`，顯示作者名與日期。資料用既有的最新文章來源。
- 右：最近改好的讀者勘誤（如果資料來源做不到自動，就先不放這一欄，只放文章）。
- 不放器官分數，不放 commit 清單。底下一行小字連到儀表板與更新紀錄。
- `data-ga-view="recent"`（沿用 `recent_updates` 的話，數據接得上前後對照；兩者擇一並在報告後記寫清楚）。

## 4. 「關於」頁

分工：首頁講台灣。「關於」頁講這個專案，誰做的、怎麼做的、可不可信。

### 4.1 新的順序

```
1 頭       「為什麼叫 Taiwan.md？」三張卡與活的數字（保留）
2 三十秒版  新增。五句話：這是什麼、誰做的、怎麼運作、哪些是 AI 寫的而哪些有人看過、怎麼參與
           旁邊一排章節錨點（桌機固定在側邊，手機是橫向可滑的一排）
3 人       創辦人與協作團隊（上移）
4 為什麼需要  首頁搬來的四張價值卡，重新設計成兩欄的說明，不再是四張小卡
5 可信度    新增。有人看過的文章數與比例、讀者勘誤怎麼處理、資料與程式碼在哪
6 誕生     時間軸收成里程碑（見 4.2）
7 是活的    「是活的」與「再往裡面看一層」併成一區，連到生命體頁
8 支持     贊助與合作夥伴
9 問答與聯繫 常見問題、聯繫、訂閱與參與的入口
```

### 4.2 時間軸

- 現在 14.7 個螢幕。挑出約十個里程碑預設顯示，做成一條橫向可滑的時間線（手機直向）。
- 其餘條目收在「看完整的時間軸（共 N 則）」底下，展開後就是現在的樣子，文字不動。內容留在頁面原始碼裡，搜尋引擎讀得到。
- 里程碑的挑選：開站、Semiont 誕生、各次語言擴張、第一場工作坊、媒體報導、App 上架這類對外看得見的事。挑選清單列在本報告後記，給哲宇看。
- 每個里程碑可以連到「關於」分類底下對應的長文。

### 4.3 其他

- 全頁加埋點：每一區 `data-ga-view`，站內連結 `data-ga-section`。頁面類型 `about`。
- 手機：三十秒版與章節錨點要在第一個螢幕看得到。
- 13 語：新增字串先中英，其餘第二期補翻，補翻前退回英文。
- 目標高度：預設狀態桌機 14 個螢幕以內（現在 32.7）。
