# 地瓜球 — 正文結構編輯室審查（Step 2.5-R）

> 席位：一隻 fresh Opus sub-agent（兩席合併），乾淨 context，只讀藍圖 v2、正文與 EDITORIAL 相關節。主編＝主 session。同 round 平行跑 Stage 3 事實查核三隻 Sonnet（分段），結果併入下方必改清單與研究報告 §audit。

### 正文結構主編

- verdict: revise
- findings:
  - H2 序列照藍圖動作序列走，七個 H2 都還原得出主–述–賓；但壓→紮實派、車庫→名字、名字→只學一天三處接縫只靠 H2 撐，拿掉 H2 讀不通
  - 「名字」一節六段都由一家媒體加年份領頭，讀起來像剪報，跟「手」的關係只剩段尾一句，可隨意搬位置
  - 藍圖欄位（扣回主軸／全局功能）被抄成每節最後一句總結，形成一整族寫作動機洩漏（EDITORIAL 後台洩漏形狀二），段尾都是死的
  - 孤島：737 夜市鄰居人情味段、2025 甘藷漲價段
  - 「中正橋」節轉軸講了五遍，作者跳出來拆解故事結構；「X 兩個字」近讀出現三次（形狀一）
  - 正文「記者」13 次、「圖說」7 次，信度標註住進正文
  - 作者補的畫面寫得像事實（「一咬就扁的空殼」「同一支漏勺」「比例一變口感就跟著變」等），交事實室對原文
- evidence:
  - 「這則故事把開頭交給長者，把後半段交給『改良』兩個字。……中間那一步，故事留給了後來的人。」
  - 「同一個在油鍋邊壓出來的小球，到了不同城市被叫成不同的名字」對照藍圖 section 5 扣回主軸，幾乎逐字
  - 「一天之後的事，都得他自己補上。壓幾下，代班那天由朋友點破。……」重講 section 2、4

### 論點兌現

- verdict: revise
- findings:
  - 論點沒有在中段消失，反而每節段尾蓋章；中段真正的推進（紮實派、竹東「搓得剛剛好」、料不篩乾淨反而卡滋）證據已夠，總結句讓論點讀起來像口號
  - 前半句「故事的改良＝今天這些攤販」講過頭：劉在泓 2019 年前後才入行、跟已在賣的攤子學，空心球在他之前就有；正文證明得了的是「每一顆空心每一晚還得用手重新壓出來」，結尾那句是站得住的寫法，概覽、description 與策展人筆記要對齊
  - 結尾有閉環（七、八下 → 重焊兩次的柄、盛產季），讀完想去買一包、站在攤前數老闆壓幾下，不焦慮；弱點是最後一句收在出處交代
  - description 153 字、第一句接住「地瓜球的由來」、三段式俱全；缺具體年份錨
- evidence:
  - 策展人筆記「『改良』兩個字底下沒有寫名字，站在那裡的是一整排夜市攤販」
  - 「跟他一起去學的哥哥和朋友，營業額卻都是他的兩、三倍」與「朋友……要不斷壓個2、30下」顯示手藝在他之前已存在

## 必改清單（≤ 7）

1. 段尾蓋章句整族刪或改成替下一節鋪路的句子；只留「空心是其中一種選擇」與結尾兩處論點錨。
2. 刪策展人筆記（0 則合法；「自家車庫」事實錯，應為岳父家）；概覽末句與 description 改成「故事沒說誰把炸地瓜做成空心小球，今天每一顆空心攤販還得一鍋一鍋重新壓出來」，description 補年份錨。
3. 補三處 narrative bridge；名字一節改由原味派「真正炸很好的地瓜球是不需要撒粉的！」開場（吃的人評炸工），AmCham 轉述鏈壓兩句、細節進腳註；紮實派一節從攤子與碾法寫起。
4. 孤島處理：737 鄰居段壓成子句；甘藷漲價移到番薯背景段末一兩句；「攤子就得跟著別人的貨走」改事實層寫法。
5. 「記者／圖說」證據狀態進腳註，正文留範圍限定；結尾兩句對調，收在「數一數老闆壓了幾下」。
6. 事實室 ❌ 5 條全修：[^9] 掛錯（He 2021 掛在三立做法句）、「一咬就扁的空殼」無出處、策展人筆記「自家車庫」、加盟案「2025 年 11 月判」（原文只有報導日）、延伸閱讀珍珠奶茶說明無依據（換台灣鹽酥雞）。
7. 刪完補字數只准用已在桌上的材料長場景：主 session 另以 curl 補存食尚玩家 331099（公館素食地瓜球人工分切、細心挑著壓；高雄朱爺爺 QQ 蛋）、329798（鳳山阿力長條形 QQ 蛋、用器具壓讓空氣跑出）、337383（竹東蕃薯潘 50 元硬幣兩倍大、搓得剛剛好）三篇原文給寫手。

## 建議不擋 ship（≤ 5）

1. 「名字」一節 H2「台南叫地瓜球，高雄叫 QQ 蛋」出自單一網友推文，正文第一處明講是網友推文即可保留。
2. 「想通以後」可保留（原文是廟裡師父當頭棒喝），不必展開算命段。
3. 「北部多半叫地瓜球」前加「從網友推文粗略看」。
