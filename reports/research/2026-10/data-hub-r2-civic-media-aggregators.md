## 1. 總覽

民間版圖現在可以分成四種活法，對 Taiwan.md 的啟發各不相同。

**第一種：還活著、而且正在換代的公民科技。** g0v 社群本身 2026 年很活躍（5/23–24 在中研院人社館辦 g0v Summit 2026 ✅，github.com/g0v 組織下 2026 年有 40 幾個 repo 在推送），但活躍的重心已從「視覺化」轉到「API、AI 輔助審議、資料封存」。2013 年的明星專案 budget.g0v.tw 還打得開，但 repo 在 2020-08-15 之後就沒再動，介面仍標著「2013 預計舉債」（✅ 瀏覽器實際看過）。真正接棒的是歐噴 OpenFun（`data.openfun.tw` 3,445+ 份資料集、CC-BY 4.0、附 AI 說明書 ✅）與 READr／公民監督國會聯盟的預算審議平台（`watchmoney.ccw.org.tw` ✅）。

**第二種：資料新聞把「圖」做成報導的一部分，但資料幾乎不放出來。** 報導者、READr、中央社、公視新聞實驗室、端傳媒都有很好的圖表與互動地圖；但在我打開的報導裡，只有 READr 有明確的開放資料承諾（GitHub `readr-media/readr-data`、`budget-data`），其餘多半「文字 CC 授權，資料／圖表未說明」。這是 Taiwan.md 最明顯的差異化空間：我們可以把圖背後的表直接放出來。

**第三種：私人彙整平台賣的是「加工過的時間序列與選股工具」。** MacroMicro（訂閱制）、財報狗（免費為主＋加值）、Goodinfo（股豐資訊，條款禁商業使用 ✅）、TEJ（機構資料庫，頁面未列價格 ✅）、591 實價登錄（把官方資料再清洗到門牌層級，✅ 2020 年報導）。它們幾乎全部是**財經與房地產**；一般性的「台灣社會、人口、教育、環境」統計幾乎沒有私人彙整者，這是結構性缺口。

**第四種：學術與國際智庫給的是「方法嚴謹的長時間序列」，但取用門檻高。** 中研院 GIS 中心的百年歷史地圖 WMTS 免帳號介接（🔍 搜尋摘要稱 50 項服務、2,500 圖層）；SRDA 與 TEDS／TSCS 資料要註冊申請；國家文化記憶庫的 Open API 要申請 API Key＋固定 IP ✅；政大選研中心的趨勢圖到 2026/06 ✅；國際上則是 CSIS ChinaPower 的 ADIZ 表單（Google Sheets）、George Mason 的 Taiwan Security Monitor、Duke TNSS、Pew 提供「台灣」這一個主題的深度。

**搜尋版圖一句話**：中文「台灣 統計 資料」被 data.gov.tw 與圖書館指南占前排，「台灣 人口 統計」被 Taiwan News 占 6／10 個位置，英文「Taiwan statistics／data／economy data」被 CEIC、Statista、Trading Economics、Worldometers、FocusEconomics 占前排；Taiwan.md 在這六組不帶品牌的查詢前 10 名都沒出現（只在加了 `taiwan.md` 字樣或限定網域時才出現）。

## 3. 最好的十五個案例深度剖析

### 案例 1：歐噴資料庫（OpenFun）——把「整理好的公共資料」直接做成 AI 能讀的 API

- **網址**：https://data.openfun.tw ✅；`llms.txt` ✅；AI 外掛 repo `openfunltd/openfun-database-ai-plugins`（v0.1.0 測試版，Claude Desktop `.mcpb` 與 Codex）✅
- **做對什麼**
  - **呈現**：不先做圖，先做「資料集目錄」。3,445+ 份資料集、3,441 份附 AI 說明書（欄位說明、查詢指南）。搜尋回傳兩類：資料集，以及真實人物／公司／機關出現在哪些資料集。
  - **可下載性／授權**：CC-BY 4.0；工程師可直接串接 `/api/v1/search`，文件在 `/api-docs.md`。
  - **可信度**：AI 查詢結果必須附資料集名稱、網址、授權與資料限制；沒收錄就要老實說沒有。
  - **更新**：同一組織旗下 LYAPI（2026-10-21）、CCAPI 地方議會（2026-10-22）、標案（2026-09-21）仍在推送。
- **弱點**：實際查詢要 Token、有效 24 小時；「2026 全站免費試用」之後價格未知。
- **Taiwan.md 可以學**：Taiwan.md 的 `/data/` 若定位成「策展中樞」，第一步是**資料集卡**（名稱／機關／授權／更新頻率／欄位說明／限制），不是圖表牆。歐噴把「授權＋資料限制」寫進每一次回答的做法，和 Taiwan.md 的出處標示紀律一致。另外，歐噴針對 AI 代理人提供 `llms.txt`，Taiwan.md 的 MCP 與 `llms.txt` 路線與他們同向，但歐噴偏機器可讀資料、Taiwan.md 偏策展敘事，兩者互補而不是衝突。

### 案例 2：READr／公民監督國會聯盟「中央政府總預算案審查監督平台」

- **網址**：https://watchmoney.ccw.org.tw/ ✅；製作人筆記 https://www.readr.tw/post/3056（2025/12/10）✅
- **做對什麼**
  - **敘事與互動**：把「立委刪減或凍結哪些預算」做成可瀏覽的提案紀錄，並追蹤審議進度；讀者能用「贊同／憤怒」心情按鈕表態。
  - **群眾協作**：撤案與併案的內容要等一個月後的公報、而且多是圖片檔，所以做了 LINE 機器人讓民眾幫忙把圖片提案單轉文字。這是資料缺口的解法，不是裝飾。
  - **開放性**：repo `congress-budget-watch-platform`（2026-08-14 推送）、`budget-data`（2025-11-25，MIT）；導覽有「開放資料」「開放原始碼」。
  - **可信度**：主要資料來自立法院議事錄（會議後一週內公布文字檔）；歷屆資料來自會議紀錄解析與整理過的大型表格。
  - **外部認可**：入圍 2025 卓越新聞獎新聞創新獎（READr 官方新聞，`readr.tw/post/3048` ✅）。
- **弱點**：首頁沒標資料屆期與最後更新日；2025 年底才推 2.0。
- **Taiwan.md 可以學**：Taiwan.md 已有「Budget Decade」十年預算頁；這個平台做的是**逐筆提案**，粒度更細，我們不必也不該重做，而是在預算頁上**指過去並說清楚分工**（我們看十年趨勢，他們看每一筆刪減）。更值得學的是「承認資料缺口並邀請協作」的敘事：每個數據頁都應該有一小段「這份資料哪裡缺、誰能補」。

### 案例 3：報導者的資料新聞——事故地圖、音樂 DNA、政治獻金

4. 值得注意的相鄰區塊：「台灣 開放資料」的前 10 筆裡沒有任何公民科技專案的主頁，只有新聞與政府；`g0v.tw` 本身也沒出現。

## 5. 缺口

以下是我從這輪盤點中可具體說出來的缺口，按可行性排序。「缺口」指本輪查不到有人在做，或做了但停更；已盡量標示證據，**不等於全國沒有**。

1. **g0v 預算視覺化停在 2013 年介面與 2019 年資料，2020-08-15 最後推送。** 現行年度預算的民間視覺化由 OpenFun（budget.openfun.app，116 年度）與 READr（watchmoney，114 年度審議）接手，但**兩者都沒有「十年趨勢」**，Taiwan.md 的 Budget Decade 目前是少數長期序列（我只驗證了搜尋摘要，詳細內容另有分身處理）。
2. **立法院國會大代誌 ly.g0v.tw 只剩日曆；倉庫 2021-01-23 最後推送。** API 由 LYAPI 接手（議案 147,465 筆），但沒有給一般讀者的「立委表決查詢」入口出現在本輪搜尋中（沃草國會無雙舊站已跳轉，新站狀況❓）。READr 有一篇 2025/07/24 的歷屆表決分析，但文章未說明資料是否公開。
3. **資料新聞的底層資料沒有統一帳本。** 報導者、中央社、READr 的圖表幾乎不附原始表；只有 READr 有 GitHub 資料承諾，且 `readr-data` 最後推送是 2024-04-01，更新並不頻繁。
4. **財經以外的台灣統計沒有同級的彙整與比較工具。** 財報狗、MacroMicro、Goodinfo、CMoney、TEJ 都是財經；人口、教育、健康、能源、交通的彙整仍多是政府入口或新聞稿。
5. **英文世界沒有一份台灣時間序列的「單一入口」。** 英文搜尋被 CEIC、Statista、Trading Economics 占據，且數字互不一致；OWID 雖正確使用「Taiwan」，但沒有獨立的台灣專頁。
6. **歷史資料沒人留。** 政府網站很多只給即時值，kiang 的封存群在補（台電、淹水、水情、颱風），但缺資料字典、授權與一致的更新說明；也只是一個人。
7. **學術調查資料要申請才能用**（SRDA、TEDS、TSCS 皆要註冊或申請；「🔍」），政大選研趨勢圖是少數可直接看到的序列；Duke TNSS 是少數開放下載的。
8. **文化資料的開放度有階梯**：國家文化記憶庫的 Open API 要 API Key＋固定 IP，開放資料集僅限圖像類與共通欄位；百年歷史地圖服務頁沒有授權條款。一般創作者想直接引用幾乎會卡在授權與申請。
9. **公民科技的 2023–2026 新專案偏 AI／審議／API**，而不是視覺化：vTaiwan 重構、Civic Talk、事實查核 API、Sensemaker、歐噴 AI 外掛。沒有找到本輪仍在維護的 g0v 空污、水情視覺化專案（LASS／空氣盒子本輪搜尋**查不到**）。這可能是真缺口，也可能是我的搜尋不足，**需另外確認**。
10. **口徑解釋缺口**：同一組 ADIZ 次數三個來源三種數字；人口數字 CEIC 與 Worldometers 差約 19 萬；薪資 104 與主計總處口徑不同。**「為什麼兩個數字不一樣」目前沒有民間頁面專門回答**，這正是策展者能提供的價值。
11. **選舉資料**：2026 九合一投票在 2026-11-28 前後（日期以中選會為準，本輪未驗），本輪看到的民間資料有 kiang/vote2026 與 READr `openrelation-elections`，中央社也有 22 縣市長名單圖。選後歷史對照（歷屆開票）的完整民間視覺化本輪未驗證。
