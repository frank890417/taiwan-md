# 張艾嘉 巡邏查核（2026-10-23）

來源：維基百科〈張艾嘉〉（zh-tw，2026-10-23 擷取，前 10 萬字元）＋〈愛的代價〉。

## 初稿與維基對不上的地方

| 初稿說法                                           | 維基                                                                    |
| -------------------------------------------------- | ----------------------------------------------------------------------- |
| 17 歲因瓊瑤電影《夢中人》踏入演藝圈                | 16 歲電台 DJ、17 歲歌手與主持，首部電影《飛虎小霸王》1972；無《夢中人》 |
| 與秦漢、秦祥林合作多部愛情文藝片                   | 維基無此載述，刪除                                                      |
| 與楊德昌、侯孝賢合作                               | 無侯孝賢合作載述；只保留《海灘的一天》                                  |
| 《童年》羅大佑 1981 作詞作曲                       | 維基頁面未載創作者，改為只寫「作品含《童年》」                          |
| 《外婆的澎湖灣》整段                               | 稻草人段落，刪除                                                        |
| 《相愛相親》「金馬八項提名」                       | 維基只列她本人四項（女主角、導演、原著劇本、劇情片），總數無載          |
| 「多次擔任金馬獎評審主席」                         | 維基只有 2014–2018 臺北金馬影展執委會主席，非評審團主席                 |
| 金馬只寫 1986《最愛》                              | 實為 1976 配角、1981、1986、2022 四座                                   |
| 出生地嘉義市共和路 191 巷                          | 維基正文與資訊框互相矛盾（嘉義市 vs 嘉義縣大林鎮），並陳                |
| 「極少數女性做到」「溫柔卻不妥協」「中間人」等詮釋 | 無來源，全刪                                                            |

錯誤率約三成。處置：重寫為年表為骨的短篇，全文單一來源（維基）。

## 待補（需另找來源）

- 《童年》的作詞作曲與首唱年份
- 《某年某月某一天》是 1979 還是 1981 年執導
- 維基後 87,000 字元（獎項細目、家庭）未讀
