## 5. A 勞保老年年金

**A-1 給付公式（兩式擇優）**｜自 2009-01-01 年金施行起，迄今｜「依下列 2 種方式擇優發給：平均月投保薪資×年資× 0.775% + 3,000 元。平均月投保薪資×年資× 1.55% 。」｜https://www.bli.gov.tw/0019825.html（頁面更新 2024-09-26）；條文 https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0050001 第 58-1 條｜2026-11-10｜A1、LAW-N

**A-2 平均月投保薪資（年金）**｜現行｜「『年金給付』：按被保險人加保期間最高60個月之月投保薪資予以平均計算。」；條文第 19 條「參加保險未滿五年者，按其實際投保年資之平均月投保薪資計算」｜https://www.bli.gov.tw/0019816.html｜2026-11-10｜A3、LAW-N4

**A-3 年資算法**｜2009 起｜「保險年資未滿1年者，依其實際加保月數按比例計算；未滿30日者，以1個月計算（計算至小數第二位，第三位四捨五入）。」年金年資無上限（勞動部 2013 新聞稿：「勞保年資則無計算的上限，是計算到退保當日止」）｜https://www.bli.gov.tw/0019818.html；https://www.mol.gov.tw/1607/1632/1640/18415/post｜2026-11-10｜C2（A-3 年資算法原文在 bli 0019818，已在本節引用，全文見網址）

**A-4 請領要件與年齡時程**｜法定請領年齡自 98 年起｜「年滿60歲，保險年資合計滿15年，並辦理離職退保者。」「上開請領年齡自98年至106年為60歲，107年提高為61歲，109年提高為62歲，111年提高為63歲，113年提高為64歲，115年以後為65歲。」｜https://www.bli.gov.tw/0019821.html（頁面更新 2022-10-25）｜2026-11-10｜A2

「是否已到 65 歲」：以此表，**目前（2026-11）65 歲是 51 年次以後的法定年齡；50 年次（114 年滿 64 歲）已是 64 歲**。條文依據：「第一項老年給付之請領年齡，於本條例中華民國九十七年七月十七日修正之條文施行之日起，第十年提高一歲，其後每二年提高一歲，以提高至六十五歲為限。」（第 58 條，LAW-N）。見衝突 X1。

**A-5 展延與減給**｜現行｜「每延後 1 年請領，依原計算金額增給 4 ％，最多增給 20 ％。」；「被保險人保險年資合計滿 15 年，未符合老年年金給付法定請領年齡提前請領者，最多得提前5年請領，每提前 1 年，依原計算金額減給4%，最多減給20%。」｜https://www.bli.gov.tw/0019825.html；第 58-2 條｜2026-11-10｜A1、LAW-N

**A-6 最低年資 15 年；不足的處理**｜現行｜「保險年資合計滿十五年者，請領老年年金給付。」「保險年資合計未滿十五年者，請領老年一次金給付。」；另：「勞工之勞工保險年資未滿15年，但併計國民年金保險之年資滿15年，於年滿65歲時，得選擇請領勞保老年年金給付。」｜條文第 58 條；https://www.bli.gov.tw/0019821.html｜2026-11-10｜LAW-N、A2

**A-7 老年一次金給付標準**｜現行｜「其保險年資合計每滿一年，按其平均月投保薪資發給一個月；其保險年資合計超過十五年者，超過部分，每滿一年發給二個月，最高以四十五個月為限。被保險人逾六十歲繼續工作者，其逾六十歲以後之保險年資，最多以五年計，合併六十歲以前之一次請領老年給付，最高以五十個月為限。」｜第 59 條｜2026-11-10｜LAW-N（第 59 條原文含於 LAW-N 擷取範圍，全文見網址）

**A-8 一次請領老年給付（非年金）條件**｜1998 年修法前有年資者適用｜「本條例中華民國九十七年七月十七日修正之條文施行前有保險年資者，於符合下列規定之一時，除依前項規定請領老年給付外，亦得選擇一次請領老年給付，經保險人核付後，不得變更：一、參加保險之年資合計滿一年，年滿六十歲或女性被保險人年滿五十五歲退職者。二、參加保險之年資合計滿十五年，年滿五十五歲退職者。三、在同一投保單位參加保險之年資合計滿二十五年退職者。四、參加保險之年資合計滿二十五年，年滿五十歲退職者。五、擔任具有危險、堅強體力等特殊性質之工作合計滿五年，年滿五十五歲退職者。」；一次請領的平均月投保薪資：「按其退保之當月起前三年之實際月投保薪資平均計算」｜第 58、19 條｜2026-11-10｜LAW-N、LAW-N4

**A-9 其他**：年金依 CPI 累計成長 ±5% 調整（「當消費者物價指數累計成長率達正負5％時，勞保年金給付金額即隨同調整」，https://www.bli.gov.tw/0019828.html，A 附錄未收全文，網址可查）；特殊工作（高壓室內、潛水）55 歲可領（A2）。

## 6. B 勞保費率、負擔、分級表

**B-1 法定機制**｜現行條文｜「普通事故保險費率，為被保險人當月投保薪資百分之七點五至百分之十三；……自百分之十當年起，每兩年調高百分之零點五至上限百分之十三。但保險基金餘額足以支付未來二十年保險給付時，不予調高。」｜勞保條例第 13 條｜2026-11-10｜LAW-N2

**B-2 2025、2026 費率**｜114-01-01 起（115 年續用）｜勞動部：「依照前開規定，115年為12.5%(其中1%為就業保險費率）。」勞保局分擔表附註：「勞工保險普通事故保險費率自114年1月1日起由12%調整為12.5%，適用就業保險法之勞工保險被保險人，其勞工保險普通事故保險費率依該法41條第2項規定調降1%，亦即表列保險費金額係依現行勞工保險普通事故保險費率11.5%，就業保險費率1%」｜https://www.mol.gov.tw/1607/28690/2282/2340/2344/7416/post（更新 2026-03-17）；https://www.bli.gov.tw/Files/25696｜2026-11-10｜RATE2、RATE5

## 13. I 所得替代率（標清楚假設；沒有可比官方數字就寫沒有資料）

**I-1 勞保年金的公式替代率（由公式導出，非官方宣稱數字）**：第二式＝年資×1.55%，年資 30 年＝46.5%。這是我用條文公式計算，**不是任何官方文件寫出的「所得替代率」**，若引用請標為「公式推導」。

**I-2 勞保＋勞退（雇提 6%）**｜假設：平均月投保薪資 37,000、年資 30 年｜勞動部長許銘春 2024-03-13 立法院說法（工商時報）：「若以平均月投保薪資3萬7000元、工作年資30年試算，勞保平均請領約1萬7000元，與此同時如果其為受僱勞工，光僱提的部分每月約可領1萬元，所得替代率約為68％。」｜https://www.ctee.com.tw/news/20240313700999-431401｜I2（**媒體轉述部長口頭說法，非勞動部書面文件**；勞退「約 1 萬」的假設報酬率沒有說明）。

### D6 同試算表前端程式（trial.js）內的累計公式，逐字

- 註：這是官方網頁公開 JavaScript 原始碼；`getSalaryMonth(salary)` 即把薪資對應到勞退月提繳分級表（程式內未展開）。

```
function calculateAnnity(formData) {
    let {salary, salaryMonth, salaryWithdraw, salaryGrow, investReturns, startAge, retireAge, oldAmt} = formData;

    let revenue = (salaryMonth * salaryWithdraw * 5.5 + oldAmt) * investReturns; // 累計收益
    let yWithdraw = Math.round(salaryMonth * salaryWithdraw) * 12; // 年提繳數
    let withdrawTotal = yWithdraw + oldAmt; // 累計提繳本金
    let annuity = withdrawTotal + revenue; // 累計本金及收益

    const result = [];
    const years = retireAge - startAge;
    for (let i = 0; i < years; i++) {
        result.push({
            year: i + 1,
            salary: Math.round(salary),
            revenue: Math.round(revenue),
            yWithdraw: Math.round(yWithdraw),
            withdrawTotal: Math.round(withdrawTotal),
            annuity: Math.round(annuity),
        });

        salary += Math.round(salary * salaryGrow);

        salaryMonth = getSalaryMonth(salary);
        yWithdraw = Math.round(salaryMonth * salaryWithdraw) * 12; // 年提繳數

        withdrawTotal += yWithdraw;
        revenue += (salaryMonth * salaryWithdraw * 5.5 + annuity) * investReturns;
        annuity = withdrawTotal + revenue;
    }

    return result;
}

第 58 條
年滿六十歲有保險年資者，得依下列規定請領老年給付：
一、保險年資合計滿十五年者，請領老年年金給付。
二、保險年資合計未滿十五年者，請領老年一次金給付。
本條例中華民國九十七年七月十七日修正之條文施行前有保險年資者，於符合下列規定之一時，除依前項規定請領老年給付外，亦得選擇一次請領老年給付，經保險人核付後，不得變更：
一、參加保險之年資合計滿一年，年滿六十歲或女性被保險人年滿五十五歲退職者。
二、參加保險之年資合計滿十五年，年滿五十五歲退職者。
三、在同一投保單位參加保險之年資合計滿二十五年退職者。
四、參加保險之年資合計滿二十五年，年滿五十歲退職者。
五、擔任具有危險、堅強體力等特殊性質之工作合計滿五年，年滿五十五歲退職者。
依前二項規定請領老年給付者，應辦理離職退保。
被保險人請領老年給付者，不受第三十條規定之限制。
第一項老年給付之請領年齡，於本條例中華民國九十七年七月十七日修正之條文施行之日起，第十年提高一歲，其後每二年提高一歲，以提高至六十五歲為限。
被保險人已領取老年給付者，不得再行參加勞工保險。
被保險人擔任具有危險、堅強體力等特殊性質之工作合計滿十五年，年滿五十五歲，並辦理離職退保者，得請領老年年金給付，且不適用第五項及第五十八條之二規定。
第二項第五款及前項具有危險、堅強體力等特殊性質之工作，由中央主管機關定之。
 第 58-1 條
老年年金給付，依下列方式擇優發給：
一、保險年資合計每滿一年，按其平均月投保薪資之百分之零點七七五計算，並加計新臺幣三千元。
二、保險年資合計每滿一年，按其平均月投保薪資之百分之一點五五計算。
 第 58-2 條
符合第五十八條第一項第一款及第五項所定請領老年年金給付條件而延後請領者，於請領時應發給展延老年年金給付。每延後一年，依前條規定計算之給付金額增給百分之四，最多增給百分之二十。

第 29 條
被保險人、受益人或支出殯葬費之人領取各種保險給付之權利，不得讓與、抵銷、扣押或供擔保。
依本條例規定請領保險給付或申請第六十七條第一項第四款之貸款者，得檢具保險人出具之證明文件，於金融機構開立專戶，專供存入保險給付或貸款本金之用。
前項專戶內之存款，不得作為抵銷、扣押、供擔保或強制執行之標的。
被保險人已領取之保險給付，經保險人撤銷或廢止，應繳還而未繳還者，保險人得以其本人或其受益人請領之保險給付扣減之。
被保險人有未償還第六十七條第一項第四款之貸款本息者，於被保險人或其受益人請領保險給付時逕予扣減之。
本保險之保險費、滯納金及前項未償還之貸款本息，不適用下列規定；貸款本息並溯自中華民國九十二年一月二十二日施行：
一、公司法有關債務免責之規定。
二、消費者債務清理條例有關債務免責之規定。
三、破產法有關債務免責之規定。
四、其他法律有關請求權消滅時效規定。
第四項及第五項有關扣減保險給付之種類、方式及金額等事項之辦法，由中央主管機關定之。
保險人應每年書面通知有未償還第六十七條第一項第四款貸款本息之被保險人或其受益人之積欠金額，並請其依規定償還。
本條例中華民國一百十四年十二月三十日修正之條文施行前，有未繳清保險費及滯納金之事實者，應適用第六項規定，保險人並依第十七條第三項或第四項規定，暫行拒絕給付；經繳清欠費後，保險人應依規定發給。
第 29-1 條
