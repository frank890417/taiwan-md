# subcategory 漂移普查

維護班在修〈江賢二〉的讀者勘誤時，順手看到閘門對那一篇印了一行警告：`subcategory: '當代藝術家'` 不在 Art 的合法值裡。那一篇改掉只要一行。但這個警告不會擋任何東西，所以值得先問它在全庫有多少同伴。

答案是 **233 篇、159 種寫法、12 個分類**。

## 為什麼這件事不會自己被發現

`subcategory-valid` 是 warn 級。warn 不擋 commit、不擋 CI、不擋部署。閘門每天對這 233 篇印同一行字，沒有任何流程被它打斷，所以它累積了多久沒有人知道。

真正的損害寫在閘門自己的訊息裡：**「填了不存在的值不會報錯但會靜默壞掉分類」**。分群與導覽讀這個欄位，一篇填了表外值的文章不會消失，它只是不會出現在任何一個 subcategory 的集合裡。讀者看不到缺口，因為缺口長得像「這一類本來就只有這些」。

## 三種形狀，三種修法

逐條看完 159 種寫法之後，它們不是同一個病。

### 形狀一：近義詞漂移（約七成）

寫的人知道該填什麼，只是沒去抄表上的字。

| 填了                                     | 表上是                       | 篇數 |
| ---------------------------------------- | ---------------------------- | ---- |
| `音樂`（People）                         | `音樂與表演`                 | 12   |
| `流行人物`（People）                     | `音樂與表演` 或 `數位與媒體` | 10   |
| `政治人物`（People）                     | `政治與民主`                 | 9    |
| `小吃` / `台灣小吃` / `地方小吃`（Food） | `經典小吃`                   | 3    |

這一類機械對映得掉，但對映表本身需要人看一眼：`流行人物` 到底該落在 `音樂與表演` 還是 `數位與媒體`，是策展判斷不是字串比對。

### 形狀二：把欄位當自由標籤用

| 例                         | 問題                   |
| -------------------------- | ---------------------- |
| `歷史街區 / 台北市大安區`  | 一格塞了分類與地點兩層 |
| `文學與詩人 / 客家文化人`  | 一格塞了兩個身分       |
| `重金屬 / 台灣史`（Music） | 一格跨了兩個分類       |
| `當代樂團 / 出海樂團`      | 一格塞了兩個描述       |

斜線在這個欄位沒有語意，所以這些值對分群來說等同亂碼。修法是挑一個主值，另一層如果重要就移到 `tags`。

### 形狀三：根本填錯層（約二十篇）

`Society`、`Economy`、`Culture`、`Technology` 直接把 category 名字填進 subcategory；`Internet`、`digital-art`、`LocalSpecialty`、`Taiwan history` 填了英文。這些是最容易修也最沒有爭議的一批。

### 例外：`縣市` 22 篇不是漂移，是表缺一列

Geography 底下 22 篇填 `縣市`，而合法值是「地形與地質、水文與水資源、氣候與溫泉、島嶼與海洋、生態地理、城市與人文地理、交通與基礎設施、地標」。

那 22 篇是刻意寫成一個系列的 22 縣市條目。**它們不是填錯，是表上沒有它們的位置。** 把它們改成 `城市與人文地理` 會讓這個系列在導覽上散掉，而那正是這個欄位存在的目的。

這一條的修法方向跟前三種相反：改表，不是改文章。

## 跟 issue #1831 的關係：同一個病的另一半

投稿者 tboydar 在 [issue #1831](https://github.com/frank890417/taiwan-md/issues/1831) report 過 Politics 分類沒有 taxonomy 表，而且附了負控制實測（填 `'完全不存在的鬼分類XYZ'` 照樣 `hard=0 warn=0`）。10-15 那班補了表，缺口補掉。

補表那一班的做法值得注意：**照 `knowledge/Politics/` 19 篇的現用值收斂**，所以補完之後零篇轉紅。

其他十二個分類的表不是這樣來的。它們寫在庫存長出來之前，是理想的分類法；庫存後來自己長成另一個形狀，而沒有人回頭把兩邊對齊。於是同一支檢查器，對 Politics 是「表貼著庫存」、對其他十二類是「庫存貼不上表」，233 篇就停在警告層。

這是 [REFLEXES #83](../docs/semiont/REFLEXES.md)「checker 兩把尺 divergence」在 taxonomy 這一層的形狀：尺沒有兩把，是尺跟它要量的東西之間的關係有兩種，而報表上看不出差別。

## 要決定的事
